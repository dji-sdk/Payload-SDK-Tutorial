## Overview

Payload devices can access the internet through the onboard network. When the drone is equipped with a DJI Enhanced Transmission module, Manifold 3 mounted on the EPort can utilize the Enhanced Transmission module's 4G network capability to access the internet, enabling use cases such as remote data transmission and cloud communication.

By default, the payload network access function is enabled and no additional operations are required (this depends on the Enhanced Transmission module being installed on the aircraft and the 4G network function being normal).

:::tip Note:
* This function is currently supported only by Manifold 3.
* Environment Preparation: Requires Matrice 400 aircraft, Manifold 3, DJI Enhanced Transmission module, and DJI remote controller. The Enhanced Transmission module must be installed on the aircraft with the 4G network function working properly. Manifold 3 must be connected to the EPort of the Matrice 400 (supports E1/E2/E3).
:::

## Basic Concepts

### Supported Aircraft

| Aircraft | Description |
|----------|-------------|
| Matrice 400 | Requires Enhanced Transmission module and Manifold 3 |
| Matrice 4TD / Matrice 4D | Requires Enhanced Transmission module and Manifold 3 |
| Matrice 4T / Matrice 4E | Requires Enhanced Transmission module and Manifold 3 |

### Enhanced Transmission State

The Enhanced Transmission module's switch state can be queried via the API. The return values are as follows:

| Value | Enum | Description |
|-------|------|-------------|
| 0 | DJI_ENHANCEED_TRANSMISSION_STATE_DISABLED | Enhanced Transmission is disabled |
| 3 | DJI_ENHANCEED_TRANSMISSION_STATE_ENABLED | Enhanced Transmission is enabled |

## Implementation

:::warning Note:
The following code samples are reference examples intended to help developers understand the calling process and implementation approach of each function. Developers should adapt and adjust according to the actual hardware characteristics and application scenarios of their payload devices.
:::

### Query Enhanced Transmission State

Use the `DjiAircraftInfo_GetEnhancedTransmission()` API to query the Enhanced Transmission module's switch state:

```c
E_DjiEnhancedTransmissionState state;
T_DjiReturnCode returnCode;

returnCode = DjiAircraftInfo_GetEnhancedTransmission(&state);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get enhanced transmission state failed, error code: 0x%08X", returnCode);
}

if (state == DJI_ENHANCEED_TRANSMISSION_STATE_ENABLED) {
    USER_LOG_INFO("Enhanced transmission is enabled.");
} else {
    USER_LOG_WARN("Enhanced transmission is disabled.");
}
```

### Network Status Alert

Based on the obtained Enhanced Transmission state, you can use custom HMS messages to display alerts on Pilot. For example, if you find that the network quality is poor while Enhanced Transmission is enabled, you can inject an HMS alert to notify the user. For specific usage, refer to <a href="../basic-function/hms-customization.html" target="_blank" rel="noopener noreferrer">Custom HMS Function</a>.

HMS text configuration example:
```json
{
    "hms_error_code": "0x1E020004",
    "hms_interface": {
        "message_title": "Payload Network Poor",
        "message_content": "Please check the network around the aircraft or disable Enhanced Transmission"
    },
    "fpv_interface": {
        "message_on_the_ground": "Payload network is poor. Please check the network around the aircraft or disable Enhanced Transmission",
        "is_keep_history_on_the_ground": true,
        "message_in_the_sky": "Payload network is poor. Please check the network around the aircraft or disable Enhanced Transmission",
        "is_keep_history_in_the_sky": true
    }
}
```

## FAQ

### How to troubleshoot when the payload device cannot access the internet through the onboard network?

1. Ensure that the aircraft is connected to the Enhanced Transmission module and the 4G network is normal. The dongle module's green light should be constantly on (you can also check the network configuration on the remote controller).
2. Ensure that the aircraft is connected to Manifold 3 and the connection is good. If the connection is poor, reconnect it.
3. Restart the aircraft and Manifold 3 and try again.
4. If the above steps do not solve the issue, please consult DJI Technical Support.
