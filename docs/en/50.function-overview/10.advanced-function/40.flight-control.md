## Overview

Using the aircraft flight control function of PSDK, you can set and obtain various basic parameters of the aircraft, control the aircraft to perform basic flight actions, control the aircraft to perform complex flight actions through the Joystick function, and use the FlyTo command flight function to have the aircraft autonomously fly to a target point.

:::tip Note:
* For Matrice 400, Matrice 4, Matrice 4D, and future models, this feature requires Manifold 3.
:::

## Basic Concepts

### Aircraft Basic Information

PSDK provides interfaces for setting the basic parameters of the aircraft. By setting and obtaining these parameters, developers can achieve precise control of the aircraft:
* Enable or disable RTK function and obstacle avoidance functions (horizontal obstacle avoidance, upward visual obstacle avoidance, downward visual obstacle avoidance)
* Set the aircraft's home point and return-to-home altitude
* Set fail-safe behavior (Matrice 30/30T, Mavic 3 Enterprise Series)
* Obtain the aircraft's [country/region code](https://en.wikipedia.org/wiki/ISO_3166-1) to adapt products to different national regulatory requirements

An application with the <a href="../basic-function/fc-subscription.html" target="_blank" rel="noopener noreferrer">Data Subscription</a> function can help users obtain information about the aircraft's basic parameters:
* Get the status of RTK function and obstacle avoidance functions (horizontal obstacle avoidance, upward visual obstacle avoidance, downward visual obstacle avoidance)
* Get the aircraft's home point and return-to-home altitude

### Joystick Function
Joystick is a comprehensive flight control function for the aircraft. When using the Joystick function, developers need to call the Joystick interfaces according to actual application needs and **simultaneously set the coordinate system, horizontal control mode, vertical control mode, yaw angle control mode, and hover mode** used by the aircraft to design the flight control logic that meets their requirements.

#### Set Coordinate System
* Body Coordinate System  
The body coordinate system takes the center of gravity of the aircraft as the origin. The forward direction of the aircraft nose is the X axis, the right side of the nose forward direction is the Y axis, and the Z axis intersects perpendicularly with the X and Y axes at the center of gravity and points downward from the aircraft (following the "Right-Hand Rule"). In body coordinates, the flight actions when the aircraft rotates around the X, Y, and Z axes are called roll (rotation around X axis only), pitch (rotation around Y axis only), and yaw (rotation around Z axis only).

* Geodetic Coordinate System  
The geodetic coordinate system is also called the world coordinate system or the local horizontal coordinate system. In this coordinate system, the direction pointing to true north is the X axis, the direction pointing to true east is the Y axis, the X and Y axes are perpendicular to each other, and the Z axis points vertically downward from the aircraft. Under the premise of satisfying the "Right-Hand Rule", the Z axis will adjust its angle according to the actual flight situation, hence this coordinate system is also called the "North-East-Down (N-E-D) coordinate system".

#### Set Horizontal Control Mode
* Attitude angle control mode: In this mode, the horizontal command is the attitude angle of the aircraft. (In body coordinate system, this angle is roll and pitch)
* Speed control mode: In this mode, the horizontal command is the speed of the aircraft
* Position control mode: In this mode, the horizontal command is the position of the aircraft
:::tip Note:
 When the modulus of the position command is not 0, the aircraft will fly forward at the specified speed; otherwise, the aircraft will hover at the specified position.
:::

* Angular velocity control: In this mode, the horizontal command is the rotational angular velocity of the aircraft

#### Set Aircraft Hover Mode
Only in the **speed control** mode of the horizontal control mode, developers can set the aircraft's hover mode:
* Enable stable mode: After enabling stable mode, the aircraft will hover at the specified position
* Disable stable mode: After disabling stable mode, the aircraft will fly according to the speed command. When the forward speed of the aircraft is 0, the aircraft may drift with the wind

#### Set Vertical Control Mode
* Speed control mode: Controls the vertical speed of the aircraft
* Position control mode: Controls the vertical position of the aircraft, which is an absolute position relative to the takeoff point
* Throttle control mode: Controls the throttle of the aircraft

#### Set Yaw Angle Control Mode
* Angle control mode: In this mode, the yaw rotation command is the yaw angle
* Angular rate control mode: In this mode, the yaw rotation command is the yaw angular rate

### Control Authority

Before invoking the aircraft control interface, you need to call the `DjiFlightController_ObtainJoystickCtrlAuthority` interface to obtain control authority over the aircraft. Until the control authority takes effect, the aircraft control command interfaces will not function.

Control Authority: Refers to the current permission to control the aircraft. The controlling entities include MSDK, PSDK, the remote controller, DJI Dock, etc. Control authority allows seizure and voluntary release.

Fail-Safe Behavior: When the aircraft enters an uncontrollable state during flight due to various unexpected factors (such as remote controller disconnection, PSDK program crash, low battery, etc.), it enters fail-safe mode. In this mode, the aircraft's control authority may change (on certain models) and the corresponding pre-set fail-safe behavior will be executed (such as return-to-home, landing, hovering).

#### Flight Control Authority Strategy

Overall Strategy: There is no priority order for flight control authority; any entity can seize control at any time. Whether to seize control can be determined based on the current control authority status and business-specific decisions.

The current business strategy designs mainly involve FlightHub, the remote controller, and PSDK. The specific strategies are as follows:
- FlightHub Flight Control:
  - If it detects that the remote controller has flight control, it will not attempt to seize control and will proactively relinquish the flight task.
  - For waypoint missions, FlightHub will seize flight control only once. If control is seized during the mission (e.g., if PSDK obtains control authority), the waypoint mission will be canceled.
  - For cockpit manual flight control, FlightHub will continuously seize control authority for flight control.

- Remote Controller Flight Control: Whenever there is a flight task to execute, whether it is a waypoint mission or manual flight, the remote controller will acquire control authority and execute flight control.

- PSDK Flight Control: PSDK provides an interface to acquire control authority. Since there is no priority design for control authority, it can acquire control at any time and execute its flight operations. If the remote controller or FlightHub has an active flight task, control authority may be seized.

## Implementation

:::tip Note:
When using PSDK to control the aircraft without a remote controller, you must subscribe to key data from the aircraft and strictly check whether the aircraft's current state allows flight control. Be sure to check critical flight parameters such as current battery level, home point, fail-safe behavior, RTK switch, obstacle avoidance switch, etc., and strictly comply with local aircraft regulations (e.g., RID information must be reported in the United States). During flight missions, monitor the aircraft's status and alert information in real time. Refer to <a href="../basic-function/fc-subscription.html" target="_blank" rel="noopener noreferrer">Data Subscription</a> and <a href="../advanced-function/hms-management.html" target="_blank" rel="noopener noreferrer">HMS Function</a>.
:::

:::warning Caution:
The following code samples are reference examples intended to help developers understand the calling flow and implementation approach for each function. Developers should adapt and adjust according to the actual hardware characteristics and application scenarios of their payload devices.
:::

### Initialization

Before using the flight control function, you need to initialize the flight control module first. At the same time, initialize the data subscription module and subscribe to key information such as flight status and display mode. You also need to register the control authority switch event callback.
<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/flight-control/fc_init_en.svg" width="30%" alt="Initialization Flow"/></span></p>
</div>

```c
T_DjiFlightControllerRidInfo ridInfo = {0};
ridInfo.latitude = 22.542812;   // Aircraft current latitude, unit: rad
ridInfo.longitude = 113.958902; // Aircraft current longitude, unit: rad
ridInfo.altitude = 10;          // Aircraft current altitude, unit: m

returnCode = DjiFlightController_Init(ridInfo);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Init flight controller module failed, error code:0x%08llX", returnCode);
    return returnCode;
}

// Initialize data subscription module
returnCode = DjiFcSubscription_Init();

// Subscribe to flight status
returnCode = DjiFcSubscription_SubscribeTopic(DJI_FC_SUBSCRIPTION_TOPIC_STATUS_FLIGHT,
                                              DJI_DATA_SUBSCRIPTION_TOPIC_10_HZ, NULL);

// Subscribe to display mode (used to determine takeoff/landing/return-to-home status)
returnCode = DjiFcSubscription_SubscribeTopic(DJI_FC_SUBSCRIPTION_TOPIC_STATUS_DISPLAYMODE,
                                              DJI_DATA_SUBSCRIPTION_TOPIC_10_HZ, NULL);

// Register control authority switch event callback
returnCode = DjiFlightController_RegJoystickCtrlAuthorityEventCallback(
    DjiTest_FlightControlJoystickCtrlAuthSwitchEventCallback);
```

Deinitialization:

```c
DjiFlightController_DeInit();
DjiFcSubscription_DeInit();
```

### Set Aircraft Parameters

Before controlling the aircraft, it is recommended to set and confirm key flight parameters, including RTK switch, obstacle avoidance switch, return-to-home altitude, fail-safe behavior, etc.

```c
// Enable horizontal visual obstacle avoidance
returnCode = DjiFlightController_SetHorizontalVisualObstacleAvoidanceEnableStatus(
    DJI_FLIGHT_CONTROLLER_ENABLE_OBSTACLE_AVOIDANCE);

// Get current horizontal visual obstacle avoidance status
E_DjiFlightControllerObstacleAvoidanceEnableStatus horizontalVisualObstacleAvoidanceStatus;
returnCode = DjiFlightController_GetHorizontalVisualObstacleAvoidanceEnableStatus(
    &horizontalVisualObstacleAvoidanceStatus);

// Enable horizontal radar obstacle avoidance
returnCode = DjiFlightController_SetHorizontalRadarObstacleAvoidanceEnableStatus(
    DJI_FLIGHT_CONTROLLER_ENABLE_OBSTACLE_AVOIDANCE);

// Enable RTK positioning
returnCode = DjiFlightController_SetRtkPositionEnableStatus(
    DJI_FLIGHT_CONTROLLER_ENABLE_RTK_POSITION);

// Set fail-safe behavior (M30 series only)
returnCode = DjiFlightController_SetRCLostAction(DJI_FLIGHT_CONTROLLER_RC_LOST_ACTION_GOHOME);
```

:::tip Note:
The obstacle avoidance function of FlyCart 100 and FlyCart 200 differs from other models. Use the following dedicated interface to control all directional obstacle avoidance switches uniformly:
:::

```c
// Enable omnidirectional obstacle avoidance (FlyCart 100 and FlyCart 200)
returnCode = DjiFlightController_SetAllAvoidAction(DJI_FLIGHT_CONTROLLER_ENABLE_ALL_AVIOD);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Turn on set all avoidance failed, error code: 0x%08X", returnCode);
    goto out;
}

// Get current omnidirectional obstacle avoidance status
uint8_t allAvoidStatus;
returnCode = DjiFlightController_GetAllAvoidAction(&allAvoidStatus);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get all avoidance status failed, error code: 0x%08X", returnCode);
    goto out;
}
USER_LOG_INFO("All avoidance status: %d", allAvoidStatus);
```


### Obtain and Release Control Authority

Before calling any flight control command (takeoff, landing, Joystick, etc.), you must first obtain Joystick control authority. After completing control tasks, you should actively release control authority so that other devices can take over.

```c
// Obtain control authority
returnCode = DjiFlightController_ObtainJoystickCtrlAuthority();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Obtain joystick authority failed, error code: 0x%08X", returnCode);
    goto out;
}
s_osalHandler->TaskSleepMs(1000);

// ... Execute flight control ...

// Release control authority
returnCode = DjiFlightController_ReleaseJoystickCtrlAuthority();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Release joystick authority failed, error code: 0x%08X", returnCode);
}
```

Control authority switch event callback example:

```c
static T_DjiReturnCode DjiTest_FlightControlJoystickCtrlAuthSwitchEventCallback(
    T_DjiFlightControllerJoystickCtrlAuthorityEventInfo eventData)
{
    switch (eventData.joystickCtrlAuthoritySwitchEvent) {
        case DJI_FLIGHT_CONTROLLER_MSDK_GET_JOYSTICK_CTRL_AUTH_EVENT:
            USER_LOG_WARN("MSDK obtains joystick control authority.");
            break;
        case DJI_FLIGHT_CONTROLLER_OSDK_GET_JOYSTICK_CTRL_AUTH_EVENT:
            USER_LOG_INFO("PSDK obtains joystick control authority.");
            break;
        case DJI_FLIGHT_CONTROLLER_RC_LOST_GET_JOYSTICK_CTRL_AUTH_EVENT:
            USER_LOG_WARN("RC lost, joystick control authority transferred.");
            break;
        default:
            USER_LOG_INFO("Joystick ctrl authority event: %d", eventData.joystickCtrlAuthoritySwitchEvent);
            break;
    }
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

### Basic Flight Actions

For flight safety, it is recommended to perform closed-loop status checks on flight status through data subscription to ensure that flight actions are correctly executed.

**Takeoff Example** (with status monitoring):

```c
// Request takeoff
djiStat = DjiFlightController_StartTakeoff();
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Request to take off failed, error code: 0x%08X", djiStat);
    return false;
}

// Check if motors have started
if (!DjiTest_FlightControlMotorStartedCheck()) {
    USER_LOG_ERROR("Takeoff failed. Motors are not spinning.");
    return false;
}
USER_LOG_INFO("Motors spinning...");

// Check if aircraft has left the ground
if (!DjiTest_FlightControlTakeOffInAirCheck()) {
    USER_LOG_ERROR("Takeoff failed. Aircraft is still on the ground.");
    return false;
}
USER_LOG_INFO("Ascending...");
```

**Return-to-Home Example**:

```c
// Start return-to-home
returnCode = DjiFlightController_StartGoHome();

// After descending to low altitude, confirm landing
returnCode = DjiFlightController_StartConfirmLanding();
```

### Joystick Flight Control
To use the Joystick function, you need to set the control mode first, then send control commands in a loop.

<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/flight-control/fc_joystick_en.svg" width="30%" alt="Joystick Control Flow"/></span></p>
</div>

The following example uses **position control mode** to fly to a target point:

**1. Set Joystick Mode**

```c
T_DjiFlightControllerJoystickMode joystickMode = {
    DJI_FLIGHT_CONTROLLER_HORIZONTAL_POSITION_CONTROL_MODE,  // Horizontal: position control
    DJI_FLIGHT_CONTROLLER_VERTICAL_POSITION_CONTROL_MODE,    // Vertical: position control
    DJI_FLIGHT_CONTROLLER_YAW_ANGLE_CONTROL_MODE,            // Yaw: angle control
    DJI_FLIGHT_CONTROLLER_HORIZONTAL_GROUND_COORDINATE,      // Coordinate system: geodetic
    DJI_FLIGHT_CONTROLLER_STABLE_CONTROL_MODE_ENABLE,        // Enable stable mode
};

DjiFlightController_SetJoystickMode(joystickMode);
```

:::tip Note:
If the Joystick settings do not change during flight, you only need to set the Joystick mode once at the beginning of the flight mission.
:::

**2. Send Control Commands in a Loop**

```c
// The z-axis position is the absolute altitude relative to the takeoff point
while (elapsedTimeInMs < timeoutInMilSec) {
    T_DjiFcSubscriptionPositionFused currentGPSPosition = DjiTest_FlightControlGetValueOfPositionFused();
    T_DjiFcSubscriptionQuaternion currentQuaternion = DjiTest_FlightControlGetValueOfQuaternion();
    dji_f32_t currentHeight = DjiTest_FlightControlGetValueOfRelativeHeight();

    float yawInRad = DjiTest_FlightControlQuaternionToEulerAngle(currentQuaternion).z;

    // Calculate offset between current position and origin point
    T_DjiTestFlightControlVector3f localOffset = DjiTest_FlightControlLocalOffsetFromGpsAndFusedHeightOffset(
        currentGPSPosition, originGPSPosition, currentHeight, originHeightBaseHomePoint);

    // Calculate remaining displacement
    T_DjiTestFlightControlVector3f offsetRemaining = DjiTest_FlightControlVector3FSub(offsetDesired, localOffset);

    // Limit speed and send command
    T_DjiTestFlightControlVector3f positionCommand = offsetRemaining;
    DjiTest_FlightControlHorizCommandLimit(speedFactor, &positionCommand.x, &positionCommand.y);

    T_DjiFlightControllerJoystickCommand joystickCommand = {
        positionCommand.x, positionCommand.y,
        offsetDesired.z + originHeightBaseHomePoint,
        yawDesiredInDeg
    };
    DjiFlightController_ExecuteJoystickAction(joystickCommand);

    // Check if target position has been reached
    if (DjiTest_FlightControlVectorNorm(offsetRemaining) < posThresholdInM &&
        fabs(yawInRad / s_degToRad - yawDesiredInDeg) < yawThresholdInDeg) {
        withinBoundsCounter += cycleTimeInMs;
    }
    if (withinBoundsCounter >= withinControlBoundsTimeReqmt) break;

    s_osalHandler->TaskSleepMs(cycleTimeInMs);
    elapsedTimeInMs += cycleTimeInMs;
}
```

**Velocity Control Mode** example:

```c
T_DjiFlightControllerJoystickMode joystickMode = {
    DJI_FLIGHT_CONTROLLER_HORIZONTAL_VELOCITY_CONTROL_MODE,
    DJI_FLIGHT_CONTROLLER_VERTICAL_VELOCITY_CONTROL_MODE,
    DJI_FLIGHT_CONTROLLER_YAW_ANGLE_RATE_CONTROL_MODE,
    DJI_FLIGHT_CONTROLLER_HORIZONTAL_GROUND_COORDINATE,
    DJI_FLIGHT_CONTROLLER_STABLE_CONTROL_MODE_ENABLE,
};
DjiFlightController_SetJoystickMode(joystickMode);

// Fly upward at 5 m/s for 2 seconds
T_DjiFlightControllerJoystickCommand joystickCommand = {0, 0, 5, 0};
for (int i = 0; i < 200; i++) {   // 200 × 10ms = 2s
    DjiFlightController_ExecuteJoystickAction(joystickCommand);
    s_osalHandler->TaskSleepMs(10);
}
```

### FlyTo Command Flight

FlyTo command flight allows the aircraft to autonomously fly to a specified GPS target point with automatic path planning (obstacle avoidance) support.
<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/flight-control/fc_flyto_en.svg" width="30%"/></span></p>
</div>

**1. Register Callback Functions**

```c
// Register mission status callback (pushes mission progress/remaining distance/state machine)
T_DjiReturnCode DjiTest_FlightControlOpenMisInfoCallback(T_DjiFlightControllerOpenMis eventData)
{
    USER_LOG_INFO("Mission state: %d, distance remaining: %.1f m",
                  eventData.mission_state_machine, eventData.distance_remaining);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}

// Register future flight trajectory callback
T_DjiReturnCode DjiTest_FlightControlCoreTrajCallback(T_DjiFlightControllerCoreTraj eventData)
{
    USER_LOG_INFO("Trajectory push: %d points", eventData.point_num);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}

DjiFlightController_RegisterOpenMisInfoCallBack(DjiTest_FlightControlOpenMisInfoCallback);
DjiFlightController_RegisterCoreTrajCallBack(DjiTest_FlightControlCoreTrajCallback);
```

:::tip Note:
The `progress` and `success_rate` fields in the `T_DjiFlightControllerOpenMis` structure are reserved fields that are currently always 0. This is normal behavior.
:::

**2. Configure Parameters and Send Target Point**

```c
// Set path planning mode (1: manual altitude mode)
returnCode = DjiFlightController_SetPlanningAlgo(1);

// Set maximum flight speed (unit: m/s, range: 1–15)
returnCode = DjiFlightController_SetMaxVelocity(10);

// Set minimum flight height (unit: m, effective only in manual altitude mode)
returnCode = DjiFlightController_SetMinFlightHeight(100.0f);

// Send target point and start mission
T_DjiFlightControllerStartMissionReq req = {0};
T_DjiFlightControllerStartMissionRsp rsp = {0};

req.version = 1;
req.operation = 0;             // 0: new mission
req.mea = 1.0f;                // Minimum route altitude (m, relative to takeoff point)
req.fly_vel = 10;              // Maximum flight speed (m/s)
req.goal_num = 1;              // Number of target points (currently only 1 point is supported)
req.cmd_mode_point_info->lat = 0.394052f;   // Target point latitude (rad)
req.cmd_mode_point_info->lon = 1.989871f;   // Target point longitude (rad)
req.cmd_mode_point_info->alt = 10.0f;       // Target point altitude (m, ellipsoidal height)

returnCode = DjiFlightController_SetModeStartMission(req, &rsp);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Start FlyTo mission failed, error code: 0x%08X", returnCode);
} else {
    USER_LOG_INFO("FlyTo mission started, ret_code: %d", rsp.ret_code);
}
```

**3. Get Exit Reason**

```c
uint16_t exit_reason;
returnCode = DjiFlightController_GetExitReason(&exit_reason);
if (returnCode == DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_INFO("FlyTo exit reason: %d", exit_reason);
}
```

### Motor & Safety Control

#### Motor Unlock and Lock

```c
// Unlock motors (propellers start spinning at idle)
returnCode = DjiFlightController_TurnOnMotors();

// Lock motors (propellers stop spinning)
returnCode = DjiFlightController_TurnOffMotors();
```

#### Emergency Stop

`ArrestFlying` stops the propellers on the ground; in the air, it only shows a warning on the App and the aircraft continues flying:

```c
// Trigger emergency stop
returnCode = DjiFlightController_ArrestFlying();

// Cancel emergency stop (must be canceled before resuming flight)
returnCode = DjiFlightController_CancelArrestFlying();
```

#### Emergency Motor Stop

:::warning Caution:
Using `EmergencyStopMotor` while in the air will cause the aircraft to crash. Only use it on the ground or when safety is confirmed!
:::

```c
returnCode = DjiFlightController_EmergencyStopMotor(
    DJI_FLIGHT_CONTROLLER_ENABLE_EMERGENCY_STOP_MOTOR, "debug_msg");
```
