## Overview

The gimbal management function of PSDK supports the simultaneous management of gimbal payload devices mounted at different positions on the drone, including setting the gimbal mode, centering the gimbal, and controlling the gimbal rotation. Developers can design control logic based on the gimbal management interfaces to control a specified gimbal to rotate to the corresponding angle **during drone flight**.

:::tip Note:
For Matrice 400, Matrice 4, Matrice 4D, and future aircraft models, this feature requires Manifold 3.
:::

## Basic Concepts

### Gimbal Angle

#### Gimbal joint and gimbal joint angle

The joints of the gimbal are shown in Figure 1. The gimbal joint is the structural component on the gimbal that drives the payload device to rotate: the gimbal motor. The gimbal joint angle is the angle at which the gimbal motor rotates. This tutorial uses the body coordinate system to describe the joint angles of the gimbal.

#### Gimbal attitude and gimbal attitude angle

The attitude of the gimbal is shown in Figure 2. According to the user's control instructions, the gimbal can adjust its attitude. The gimbal attitude angle describes the angle of the **payload device** on the gimbal using the geodetic coordinate system (NED, North-East-Down coordinate system). This angle is also called the Euler angle.

#### Gimbal limit angle description

:::warning Note:
* When PSDK controls the gimbal yaw axis to rotate n degrees using absolute angle (the angle is based on the geodetic coordinate system, where 0 degrees is true north), if n > 0, the gimbal will rotate to n degrees clockwise from true north; if n < 0, the gimbal will rotate to n degrees counterclockwise from true north.
* When PSDK controls the gimbal yaw axis to rotate n degrees using relative angle (the angle is based on the current angle), if n > 0, the gimbal will rotate to n degrees clockwise from the current angle; if n < 0, the gimbal will rotate to n degrees counterclockwise from the current angle.
:::

### Gimbal Control

* Control Mode

  * Absolute angle control: The gimbal developed with PSDK will rotate from the **current position** to the specified position within the specified time according to the user's instructions.
  * Speed control: The user can control the rotation speed of the gimbal developed with PSDK.
  :::tip Note:
  * In the angle control mode, the rotation time of the gimbal is limited by the maximum rotation speed and maximum acceleration of the gimbal, and the actual rotation angle is limited by the gimbal limit angle.
  * In speed control mode, the gimbal rotates for 0.5s at the speed specified by the user. When the gimbal reaches the limit angle, it will stop rotating.
  :::


* Gimbal mode: Currently, the gimbal control function of PSDK **only supports** free mode. In this mode, when the attitude of the drone changes, the gimbal will not rotate.

### Gimbal Status Information

Applications developed using PSDK can obtain the current information of the specified gimbal. For details, please refer to the **PSDK API documentation**.

## Implementation


:::warning Note:
The following code samples are reference examples intended to help developers understand the calling process and implementation approach for each feature. Developers should adapt and adjust based on the actual hardware characteristics and application scenarios of their payload devices.
:::

### Initialization

If the payload device developed with PSDK needs to control the gimbal, it must first call the `DjiGimbalManager_Init()` interface to initialize the gimbal management module.

```c
returnCode = DjiGimbalManager_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Init gimbal manager failed, error code: 0x%08X", returnCode);
    goto out;
}
```

### Set Gimbal Mode

Before controlling the gimbal, you need to call the `DjiGimbalManager_SetMode` interface to set the working mode of the gimbal.

```c
returnCode = DjiGimbalManager_SetMode(mountPosition, gimbalMode);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set gimbal mode failed, error code: 0x%08X", returnCode);
    goto out;
}
```

### Control Gimbal Rotation

Control the gimbal to rotate to the expected angle by calling the `DjiGimbalManager_Rotate` interface. The `T_DjiGimbalManagerRotation` structure contains the rotation mode (relative angle / absolute angle), target angle for each axis, and the expected execution time.

```c
USER_LOG_INFO("Target gimbal pry = (30, 0, 0) in the body coordinate system");
rotation = (T_DjiGimbalManagerRotation) {DJI_GIMBAL_ROTATION_MODE_RELATIVE_ANGLE, 30, 0, 0, 0.5};
returnCode = DjiGimbalManager_Rotate(mountPosition, rotation);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Target gimbal pry = (30, 0, 0) failed, error code: 0x%08X", returnCode);
    goto out;
}

osalHandler->TaskSleepMs(1000);

USER_LOG_INFO("Target gimbal pry = (0, 30, 0) in the body coordinate system");
rotation = (T_DjiGimbalManagerRotation) {DJI_GIMBAL_ROTATION_MODE_RELATIVE_ANGLE, 0, 30, 0, 0.5};
returnCode = DjiGimbalManager_Rotate(mountPosition, rotation);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Target gimbal pry = (0, 30, 0) failed, error code: 0x%08X", returnCode);
    goto out;
}
osalHandler->TaskSleepMs(1000);

USER_LOG_INFO("Target gimbal pry = (0, 0, 30) in the body coordinate system");
rotation = (T_DjiGimbalManagerRotation) {DJI_GIMBAL_ROTATION_MODE_RELATIVE_ANGLE, 0, 0, 30, 0.5};
returnCode = DjiGimbalManager_Rotate(mountPosition, rotation);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Target gimbal pry = (0, 0, 30) failed, error code: 0x%08X", returnCode);
    goto out;
}
osalHandler->TaskSleepMs(1000);
```

### Gimbal Reset

Applications developed using PSDK support rotating the pitch and yaw axes of the gimbal to the neutral position by calling the `DjiGimbalManager_Reset` interface.

```c
USER_LOG_INFO("Target gimbal reset.\r\n");
returnCode = DjiGimbalManager_Reset(mountPosition, DJI_GIMBAL_RESET_MODE_PITCH_AND_YAW);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Reset gimbal failed, error code: 0x%08X", returnCode);
    goto out;
}
```

### Get Gimbal Status

Developers can use the subscription data items `DJI_FC_SUBSCRIPTION_TOPIC_GIMBAL_ANGLES` and `DJI_FC_SUBSCRIPTION_TOPIC_GIMBAL_STATUS` to obtain the attitude angles and status of gimbals at different positions.

```c
returnCode = DjiFcSubscription_SubscribeTopic(DJI_FC_SUBSCRIPTION_TOPIC_GIMBAL_ANGLES,
                                              DJI_DATA_SUBSCRIPTION_TOPIC_50_HZ, NULL);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Failed to subscribe topic %d, 0x%08X",
                   DJI_FC_SUBSCRIPTION_TOPIC_GIMBAL_ANGLES, returnCode);
    goto out;
}
```

### Parameter Settings

The gimbal management module also provides a set of parameter configuration interfaces for adjusting gimbal runtime parameters:

#### Set Pitch Range Extension

```c
returnCode = DjiGimbalManager_SetPitchRangeExtensionEnabled(mountPosition, true);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set pitch range extension enabled failed, error code: 0x%08X", returnCode);
}
```

#### Set Maximum Speed Percentage

Actual maximum gimbal rotation speed = Default maximum speed × Maximum speed percentage / 100. The value range is 1–100.

```c
returnCode = DjiGimbalManager_SetControllerMaxSpeedPercentage(mountPosition,
                                                              DJI_GIMBAL_AXIS_PITCH, 50);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set max speed percentage failed, error code: 0x%08X", returnCode);
}
```

#### Set Smooth Control Factor

The smooth control factor determines the maximum acceleration of gimbal rotation. The formula is: Maximum acceleration = 10000 × (0.8 ^ (1 + X)) deg/s², where X is the smooth control factor with a value range of 0–30. A higher value results in slower acceleration.

```c
returnCode = DjiGimbalManager_SetControllerSmoothFactor(mountPosition,
                                                        DJI_GIMBAL_AXIS_PITCH, 10);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set smooth factor failed, error code: 0x%08X", returnCode);
}
```

#### Restore Factory Settings

Restore the gimbal to factory settings, including fine-tuning angles, pitch axis range extension enable flag, and maximum speed, etc.

```c
returnCode = DjiGimbalManager_RestoreFactorySettings(mountPosition);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Restore factory settings failed, error code: 0x%08X", returnCode);
}
```
