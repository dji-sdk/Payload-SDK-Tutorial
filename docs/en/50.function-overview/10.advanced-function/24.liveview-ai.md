## Overview

PSDK provides AI recognition capabilities based on Manifold 3, supporting developers in obtaining decoded image data from camera streams, performing object detection using Manifold 3's AI processing power, and transmitting the recognition results back to DJI Pilot for rendering and display.

:::warning Note:
* Currently, this feature is only supported when the H30 camera is mounted on the Matrice 400 aircraft with DJI Manifold 3.
* Blocking time-consuming operations are not allowed in the encoding and decoding callback functions. It is recommended to create a separate thread for object detection and other functions.
:::

## Basic Concepts

### AI Recognition Flow

Manifold 3 supports obtaining real-time video streams (1080P/4K) from the H30/H30T camera mounted on the Matrice 400 drone, decoding the image data, and performing object detection using its onboard AI processing power. There are two ways to transmit the recognition results:

| Method | Description |
|--------|-------------|
| Encode into stream | Encode recognition result metadata into an H.264 stream via DjiLiveview_EncodeAFrameToH264, then push to Pilot via DjiPayloadCamera_SendVideoStream |
| Direct push | Directly push recognition results to Pilot via DjiLiveview_SendAiMetaToPilot, rendering on the H30 camera liveview page |

### Target Types

The SDK predefines the following target types (`E_DjiLiveViewTargetObjectType`):

| Type | Description |
|------|-------------|
| Person | Pedestrian |
| Car | Vehicle |
| Boat | Watercraft |
| Human Face | Human face |
| Bird | Bird |
| Beacon | Beacon |
| GPS | GPS marker |
| Moving Target | Moving target |

Developers can also register custom target categories via `DjiLiveview_RegUserAiTargetLableList`.

### Target Tracking State

Detected targets have tracking states (`E_DjiLiveViewTargetObjectState`), including: Tracked, Lost, Redetected, etc.

### Recognition Result Data Format

AI recognition results use the `T_DjiLiveViewStandardMetaData` format, containing a set of `T_DjiLiveViewBoundingBox` entries. Each bounding box includes target ID, type, state, and 2D coordinates (center point, width, height, distance).

### Target Category Registration

Call the `DjiLiveview_RegUserAiTargetLableList` interface to register user-defined target category information with DJI Pilot for AI recognition result rendering.

```c
returnCode = DjiLiveview_RegUserAiTargetLableList(YOLO_LABLES_NUM, s_classLables);
```

### Obtain Decoded Image Data

DJI PSDK supports users in obtaining image data in NV12, RGB PLANAR, and RGB PACKED formats after camera stream decoding. Call the `DjiLiveview_StartImageStream` interface, specifying the mount position, stream ID, pixel format, and callback function to subscribe to decoded image data.

```c
returnCode = DjiLiveview_StartImageStream(CameraPostion, MediaResource,
                                          PIXFMT_RGB_PACKED, DjiLiveview_RcvImageCallback);
```

### Initialize Hardware Encoder

Call the `DjiLiveview_RegEncoderCallback` interface to initialize the Manifold 3 built-in hardware encoder and register a callback function to receive the encoder output H.264 stream data.

```c
returnCode = DjiLiveview_RegEncoderCallback(DjiLiveview_EncoderUseCallback);
```

### AI Recognition Result Encoding

Fill the AI-recognized target information in `T_DjiLiveViewStandardMetaData` format. Use the `DjiLiveview_EncodeAFrameToH264` interface to encode the raw image combined with recognition results into H.264 stream data, then use `DjiPayloadCamera_SendVideoStream` to transmit the stream back to Pilot for rendering.

```c
returnCode = DjiLiveview_EncodeAFrameToH264(buf, len, imageInfo, metaData);
```

### AI Recognition Result Push

Alternatively, use `DjiLiveview_SendAiMetaToPilot` to directly push AI recognition results in `T_DjiLiveViewStandardMetaData` format to Pilot. The results will be rendered directly on the H30 camera liveview page.

```c
returnCode = DjiLiveview_SendAiMetaToPilot(metaData);
```

### Unregister and Cleanup

After use, unregister the target categories, stop image subscription, and unregister the encoder callback in order.

```c
DjiLiveview_UnregUserAiTargetLableList();
DjiLiveview_StopImageStream(CameraPostion, MediaResource);
DjiLiveview_UnregEncoderCallback();
```

## Sample Tutorial

In `samples/sample_c++/module_sample/liveview/dji_liveview_object_detection.cpp`, the `DjiUser_RunCameraAiDetectionSample` example demonstrates the following workflow:

1. Acquire and decode the 1080P real-time video stream from the H30T camera;
2. Perform object detection using the YOLO algorithm;
3. Fill the detection results into the `T_DjiLiveViewStandardMetaData` structure;
4. Push the results to the Pilot interface for rendering in two different ways.
