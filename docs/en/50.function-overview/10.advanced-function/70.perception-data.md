## Overview

To assist developers in achieving automated flight control of aircraft in scenarios without GPS or RTK satellites, enabling functions such as precise hovering and obstacle avoidance, DJI has opened up the aircraft's visual perception system, including the vision system, six-direction infrared sensing system, as well as the LiDAR sensing system and six-direction millimeter-wave radar sensing system equipped on the Matrice 400. Developers can use the APIs provided by PSDK to obtain perception grayscale image streams, LiDAR point cloud data, and millimeter-wave radar point cloud data. By combining perception and positioning algorithms, developers can create advanced applications that meet the needs of specific scenarios.

:::tip Note:
* Only applications developed on Linux and RTOS systems support the perception data acquisition feature.
* When using the perception data acquisition feature, you need to use a USB cable or Ethernet cable to receive the raw data from the aircraft's visual perception system.
* Developers can obtain the User Manual for the corresponding model from the [DJI Download Center](https://www.dji.com/cn/downloads?site=brandsite&from=nav) to view the composition of the visual perception system and camera positions.
* For Matrice 400, Matrice 4, Matrice 4D, and future models, this feature requires Manifold 3.
* To obtain the aircraft's perception data, you need to unlock and take off the aircraft, or connect to DJI Assistant 2 and unlock/take off the aircraft in the simulator.
:::

## Basic Concepts

### Aircraft Perception System

The visual perception system of DJI aircraft mainly consists of perception sensors and visual perception algorithms. During flight, the perception sensors acquire the status of the surrounding environment, assisting the aircraft in braking, obstacle avoidance, and precise hovering.

- Mavic 3E/3T, Matrice 30/30T, Matrice 300 RTK/350 RTK, Matrice 4D/4T/4E, and Matrice 400 all support acquiring grayscale image streams from all perception sensors.
- Matrice 400 additionally supports acquiring LiDAR point cloud and millimeter-wave radar point cloud data.

:::tip Note:
* If the aircraft experiences external interference during hovering, it will automatically return to the original hover point.
* When using the perception image acquisition feature, if the aircraft disconnects from the remote controller, it will hover.
:::

### Perception Image Types and Resolutions

| Model | Direction | Frame Rate | Resolution |
|------|------|------|--------|
| Matrice 400 | Down | 20 FPS | 512 × 640 |
| Matrice 400 | Front, Left, Right | 20 FPS | 704 × 704 |
| Matrice 400 | Rear | 20 FPS | 704 × 896 |
| Matrice 400 | Up | 20 FPS | 640 × 512 |
| Matrice 4D/4TD/4E/4T | Down | 20 FPS | 640 × 512 |
| Matrice 4D/4TD/4E/4T | Front, Rear, Left, Right | 20 FPS | 704 × 704 |

:::tip Note:
* Due to link bandwidth limitations, all models currently only support **subscribing to two streams simultaneously**, and the frame rate will decrease after subscribing to two streams.
:::

### Perception Image Metadata

Images generated by visual sensors contain the following metadata:
- **Timestamp**: All visual sensors share the same timer. For detailed information on time synchronization, please refer to <a href="../basic-function/time-syn.html" target="_blank" rel="noopener noreferrer">Time Synchronization</a>.
- **Frame Index**: After subscribing to perception grayscale images, the images will be accompanied by a frame index. Subscribing or unsubscribing will not change or interrupt the frame index sequence.

### LiDAR Point Cloud Metadata


After the aircraft takes off, PSDK can subscribe to LiDAR data frames (`T_DjiLidarFrame`) at a frequency of 10 Hz. Each frame contains:
- The current timestamp and aircraft attitude information
- Multiple LiDAR data packets (`T_DjiPerceptionLidarDecodePkg`), each consisting of a packet header (`T_DJIPerceptionLidarDataHeader`) and up to 96 points (`T_DJIPerceptionLidarPoint`)

:::tip Note:
The extrinsic parameters from the LiDAR to the body IMU are as follows:<br>
Rotation (quaternion w x y z): `[ 0.0124277, -0.7083339, -0.70558153, 0.01622773 ]`<br>
Translation (x y z, in meters): `[ 0.12922, 0, -0.234352 ]`
:::

## Implementation

:::tip Note:
- For perception-related code, please refer to the [GitHub sample](https://github.com/dji-sdk/Payload-SDK/tree/master/samples/sample_c/module_sample/perception).
- It is recommended to install OpenCV to display perception grayscale images.
- To avoid blocking the main thread with vision sensor image processing, please create a separate thread to handle the aircraft's vision sensor images.
:::


:::warning Warning:
The following code is provided as reference examples to help developers understand the calling workflow and implementation approach for each feature. Developers can adapt and adjust according to the actual hardware characteristics and application scenarios of their payload devices.
:::

### Initialization and Deinitialization

Call `DjiPerception_Init()` to initialize the perception module. This interface must be called after `DjiCore_Init()`:

```c
returnCode = DjiPerception_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Perception init failed, error code: 0x%08X", returnCode);
}
```

Call `DjiPerception_Deinit()` to release resources when finished:

```c
returnCode = DjiPerception_Deinit();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Perception deinit failed, error code: 0x%08X", returnCode);
}
```

### Get Camera Parameters

Call `DjiPerception_GetStereoCameraParameters()` to get the intrinsic and extrinsic parameters of all stereo cameras:

```c
T_DjiPerceptionCameraParametersPacket cameraParametersPacket = {0};
returnCode = DjiPerception_GetStereoCameraParameters(&cameraParametersPacket);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get stereo camera parameters failed, error code: 0x%08X", returnCode);
}

// Iterate through camera parameters for each direction
for (int i = 0; i < cameraParametersPacket.directionNum; i++) {
    // Left camera intrinsic matrix (3x3, row-major)
    float *leftK = cameraParametersPacket.cameraParameters[i].leftIntrinsics;
    // Right camera intrinsic matrix
    float *rightK = cameraParametersPacket.cameraParameters[i].rightIntrinsics;
    // Rotation matrix from left camera to right camera (3x3, row-major)
    float *R = cameraParametersPacket.cameraParameters[i].rotationLeftInRight;
    // Translation vector from left camera to right camera (x y z, in meters)
    float *T = cameraParametersPacket.cameraParameters[i].translationLeftInRight;
}
```

### Perception Image Subscription

When using the perception image acquisition feature, developers need to call the specified API to subscribe (or unsubscribe) to images from the camera vision sensors via USB or Socket interface during the application's runtime, and use a callback function to receive the subscribed images within a dedicated reading thread.

<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/perception-data/perception_image_en.svg" width="30%" alt="Perception Image Subscription Flow"/></span></p>
</div>

**Create a Perception Stream Processing Thread**

Create a perception stream processing thread for reading the raw stream from the perception sensor and decoding it into images:

```c
T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();
osalHandler->TaskCreate("user_perception_task", DjiTest_StereoImagesDisplayTask,
                        USER_PERCEPTION_TASK_STACK_SIZE, &s_stereoImagePacket, &s_stereoImageThread);
```

:::tip Note:
If the OpenCV library is installed, you can call `cv::imshow()` in the processing thread to display the decoded perception grayscale images.
:::

**Subscribe to Perception Images of a Specified Direction**

Subscribe to the perception image of a specified direction and register a callback function to process the received stream:

```c
// Taking the front-facing direction as an example
returnCode = DjiPerception_SubscribePerceptionImage(DJI_PERCEPTION_RECTIFY_FRONT,
                                                    DjiTest_PerceptionImageCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Subscribe perception image failed, error code: 0x%08X", returnCode);
}
```

Callback function example:

```c
static void DjiTest_PerceptionImageCallback(T_DjiPerceptionImageInfo imageInfo,
                                            uint8_t *imageRawBuffer, uint32_t bufferLen)
{
    // imageInfo.rawInfo.width  — Image width (pixels)
    // imageInfo.rawInfo.height — Image height (pixels)
    // imageInfo.timeStamp      — Timestamp
    // imageRawBuffer           — Raw image data pointer
    // bufferLen                — Data length (bytes)

    // Save image data to file or perform further processing
}
```

**Unsubscribe from Perception Images**

```c
returnCode = DjiPerception_UnsubscribePerceptionImage(DJI_PERCEPTION_RECTIFY_FRONT);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Unsubscribe perception image failed, error code: 0x%08X", returnCode);
}
```

**Destroy the Processing Thread**

```c
osalHandler->TaskDestroy(s_stereoImageThread);
```

### LiDAR Point Cloud Subscription

When using the LiDAR point cloud data acquisition feature, developers need to call the specified API to subscribe (or unsubscribe) to onboard LiDAR data via USB or Socket interface during the application's runtime, and use a callback function to receive the data. Point cloud data from the aircraft body can be subscribed to when the aircraft is in flight.

:::tip Note:
* Similar to perception camera data subscription, to avoid blocking the main thread with point cloud data processing, please create a separate thread to handle the aircraft's LiDAR point cloud data.
:::

Subscribe to onboard LiDAR point cloud data and register a callback function to receive the point cloud information:

```c
returnCode = DjiPerception_SubscribeLidarData(DjiTest_PerceptionLidarCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Subscribe lidar data failed, error code: 0x%08X", returnCode);
}
```

Parse point cloud frame data in the callback function:

```c
static void DjiTest_PerceptionLidarCallback(uint8_t *lidarDataBuffer, uint32_t bufferLen)
{
    T_DjiLidarFrame *lidarFrame = (T_DjiLidarFrame *)lidarDataBuffer;
    // lidarFrame->timeStampNs  — Timestamp of the first point in the frame (ns)
    // lidarFrame->frameCnt     — Frame count (incrementing from 0)
    // lidarFrame->pkgNum       — Number of valid data packets in the current frame
    // lidarFrame->naviPos      — Translation vector from aircraft IMU to navigation coordinate system
    // lidarFrame->naviQuat     — Quaternion from aircraft IMU to navigation coordinate system

    for (int i = 0; i < lidarFrame->pkgNum; i++) {
        T_DjiPerceptionLidarDecodePkg *pkg = &lidarFrame->pkgs[i];
        for (int j = 0; j < pkg->header.dotNum; j++) {
            // pkg->points[j].x / y / z — Point coordinates (in meters)
            // pkg->points[j].intensity  — Reflection intensity
            // pkg->points[j].label      — Noise filtering result (0: target point; 1: noise)
        }
    }
}
```

Unsubscribe:

```c
returnCode = DjiPerception_UnsubscribeLidarData();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Unsubscribe lidar data failed, error code: 0x%08X", returnCode);
}
```

### Millimeter-Wave Radar Point Cloud Subscription

After the aircraft takes off, PSDK can subscribe to millimeter-wave radar point cloud information at a frequency of 20 Hz. When using the millimeter-wave radar point cloud data acquisition feature, developers need to call the specified API to subscribe (or unsubscribe) to millimeter-wave radar data at a specified position via USB or Socket interface during the application's runtime, and use a callback function to receive the data.

:::tip Note:
Similar to perception camera data subscription, to avoid blocking the main thread with point cloud data processing, please create a separate thread to handle the aircraft's millimeter-wave radar point cloud data.
:::

Subscribe to millimeter-wave radar point cloud data at a specified position and register a callback function to receive the point cloud information:

```c
// Taking the front-facing millimeter-wave radar as an example
returnCode = DjiPerception_SubscribeRadarData(RADAR_POSITION_FRONT, DjiTest_PerceptionRadarCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Subscribe radar data failed, error code: 0x%08X", returnCode);
}
```

Parse millimeter-wave radar data frame in the callback function:

```c
static void DjiTest_PerceptionRadarCallback(E_DjiPerceptionRadarPosition radarPosition,
                                            uint8_t *radarDataBuffer, uint32_t bufferLen)
{
    T_DjiRadarDataFrame *radarFrame = (T_DjiRadarDataFrame *)radarDataBuffer;
    // radarFrame->headInfo.dataLen — Data length
    // radarFrame->headInfo.packNum — Total number of packets in the current rotation

    // Parse each point (azimuth / elevation / radius need to be converted using formulas)
    // azimuth (in rad) = radarFrame->data[i].azimuth / 1000 - 2π (subtract 2π if result > π)
    // elevation (in rad) = radarFrame->data[i].elevation / 1000 - 2π
    // radius (radial distance, in m) = radarFrame->data[i].radius * 0.01
    // velocity (m/s) = (radarFrame->data[i].base_info.velocity - 32767) / 100
}
```

Unsubscribe:

```c
returnCode = DjiPerception_UnsubscribeRadarData(RADAR_POSITION_FRONT);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Unsubscribe radar data failed, error code: 0x%08X", returnCode);
}
```
