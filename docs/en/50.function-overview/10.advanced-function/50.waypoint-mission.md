## Overview

Using the motion planning function of PSDK, developers can control the aircraft to fly autonomously along preset routes, enabling automated flight scenarios such as waypoint missions and point-of-interest (POI) orbiting. PSDK provides three sets of interfaces: Waypoint 2.0, Waypoint 3.0, and POI.

## Basic Concepts

### Waypoints

When using waypoint missions, the developer needs to specify the number of waypoints and the corresponding waypoint types.

* **Number of waypoints**: A mission requires a minimum of 2 and supports a maximum of 65535 waypoints.
* **Waypoint type**: Refers to the way the aircraft flies toward the waypoint, including:
  * **Curvature flight**: Fly with continuous curvature (optionally hovering at the waypoint), or hover at the waypoint with discontinuous curvature.
  * **Straight flight**: Straight entry or straight exit.
  * **Coordinated turn**: The aircraft begins turning before reaching the waypoint.

### Actions

When using waypoint missions, developers can add actions (such as taking photos, recording video, or hovering) to be performed by the aircraft at specified waypoints.

* **Action ID**: A globally unique action identifier.
* **Trigger**: The condition that triggers the aircraft to execute an action. Each trigger supports only one trigger type, including:
  * Timed trigger
  * Distance trigger
  * Action serial trigger
  * Action parallel trigger
  * Waypoint trigger: When the aircraft is flying along the waypoint route, end the waypoint mission at the Nth waypoint
* **Actuator**: The module that executes the user-specified action. Each actuator supports only one execution type.
* **Number of actions**: A maximum of 65535 actions can be added per mission.
* **Action management**:
  * Supports configuring camera focus and zoom actions to the ground station for automatic execution.
  * Supports gimbal angle increment control.
  * Supports configuring multiple gimbals and multiple cameras.

### Speed Control

PSDK provides developers with a speed control function, enabling developers to configure different speeds for specified waypoints (set multiple speeds for the same waypoint), and supports modifying or querying the global cruise speed of the aircraft during waypoint mission execution.

### Disconnection Control

Added support for configuring the function of continuing to execute the route mission after the remote controller is disconnected.
:::tip Note:
* When an application developed based on PSDK controls the aircraft to perform missions, the user can still adjust the flight speed, altitude, and heading via the remote controller.
* The aircraft can only execute one automated flight mission at a time. After uploading a new mission, the existing mission will be overwritten.
* In waypoint missions, waypoints and actions are not necessarily related. Developers can configure them independently based on actual requirements.
:::

### Workflow

The waypoint mission function controls the aircraft to execute waypoint missions according to the following process:

1. **Upload the overall mission information**  
   A waypoint mission includes the mission ID, number of waypoints, number of repetitions, the action after the mission ends, maximum flight speed, and cruise speed.
2. **Upload waypoint information**
   * Basic parameters: Waypoint coordinates (longitude, latitude, and altitude relative to the takeoff point), waypoint type, heading type, and flight speed.
   * Optional parameters: Buffer distance, heading angle, steering mode, point of interest, single-point maximum flight speed, single-point cruise speed.
   :::tip Note:
   Optional parameters can only be set after all basic parameters of the waypoint information have been configured.
   :::
3. **Set action information (optional)**  
   Set the action ID, trigger, and actuator.
4. **Upload the aircraft's waypoint mission information**
5. **Control the aircraft to execute the waypoint mission**  
   After uploading the waypoints and corresponding action information, developers can control the waypoint mission through the specified interfaces, such as starting, stopping, or pausing the mission, and setting or getting the cruise speed.

### Waypoint 2.0 Mission

:::tip Note:
Waypoint 2.0 currently only supports Matrice 300 RTK and Matrice 350 RTK.
:::

      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/waypoint-mission/waypoint_v2_sequence_en.svg" width="45%" alt="Waypoint 2.0 Interface Call Sequence"/></span></p>
</div>

#### Initialization and Callback Registration

Before using Waypoint 2.0, you need to initialize the module, subscribe to positioning data, and register mission event and state callbacks to monitor the flight status in real time during mission execution.

```c
// Step 1: Initialize the Waypoint V2 module
returnCode = DjiWaypointV2_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Init waypoint V2 failed, error code: 0x%08X", returnCode);
    return returnCode;
}

// Step 2: Subscribe to GPS fused positioning data (used for mission planning)
returnCode = DjiFcSubscription_SubscribeTopic(DJI_FC_SUBSCRIPTION_TOPIC_POSITION_FUSED,
                                              DJI_DATA_SUBSCRIPTION_TOPIC_50_HZ, NULL);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Subscribe GPS fused data failed, error code: 0x%08X", returnCode);
    goto out;
}

// Step 3: Register mission event callback (pushes events such as waypoint reached, action switch, etc.)
returnCode = DjiWaypointV2_RegisterMissionEventCallback(DjiTest_WaypointV2EventCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Register waypoint V2 event callback failed, error code: 0x%08X", returnCode);
    goto out;
}

// Register mission state callback (pushes mission execution state at 10 Hz)
returnCode = DjiWaypointV2_RegisterMissionStateCallback(DjiTest_WaypointV2StateCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Register waypoint V2 state callback failed, error code: 0x%08X", returnCode);
    goto out;
}
osalHandler->TaskSleepMs(1000);
```

Callback function examples:

```c
static T_DjiReturnCode DjiTest_WaypointV2EventCallback(T_DjiWaypointV2MissionEventPush eventData)
{
    USER_LOG_INFO("Waypoint V2 event: 0x%02X", eventData.event);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}

static T_DjiReturnCode DjiTest_WaypointV2StateCallback(T_DjiWaypointV2MissionStatePush stateData)
{
    USER_LOG_INFO("Waypoint V2 state: %d", stateData.state);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

#### Upload Waypoint Mission

Construct and upload the mission configuration, including the waypoint list, action list, cruise speed, disconnection behavior, end action, etc.

```c
T_DjiWayPointV2MissionSettings missionSettings = {0};
T_DJIWaypointV2ActionList actionList = {NULL, 0};

// Generate action list (example: 5 actions)
uint16_t actionNum = 5;
actionList.actions = DjiTest_WaypointV2GenerateWaypointV2Actions(actionNum);
actionList.actionNum = actionNum;

// Configure mission parameters
missionSettings.missionID = 10023;          // Mission ID
missionSettings.repeatTimes = 1;            // Number of repetitions
missionSettings.finishedAction = DJI_WAYPOINT_V2_FINISHED_GO_HOME; // Return to home after mission ends
missionSettings.maxFlightSpeed = 10;        // Maximum flight speed (m/s)
missionSettings.autoFlightSpeed = 2;        // Auto cruise speed (m/s)
missionSettings.actionWhenRcLost = DJI_WAYPOINT_V2_MISSION_KEEP_EXECUTE_WAYPOINT_V2; // Continue on disconnect
missionSettings.gotoFirstWaypointMode = DJI_WAYPOINT_V2_MISSION_GO_TO_FIRST_WAYPOINT_MODE_POINT_TO_POINT;
missionSettings.mission = DjiTest_WaypointV2GeneratePolygonWaypointV2(6, 6); // Waypoint list
missionSettings.missTotalLen = 8;           // Total number of waypoints
missionSettings.actionList = actionList;

returnCode = DjiWaypointV2_UploadMission(&missionSettings);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Upload waypoint V2 mission failed, error code: 0x%08X", returnCode);
    goto out;
}
osalHandler->TaskSleepMs(1000);
```

#### Control Mission Execution

After upload is complete, execute start, pause, resume, and stop operations in sequence:

```c
// Start executing the mission
returnCode = DjiWaypointV2_Start();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Start waypoint V2 mission failed, error code: 0x%08X", returnCode);
    goto out;
}
osalHandler->TaskSleepMs(20000);

// Pause the mission
returnCode = DjiWaypointV2_Pause();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Pause waypoint V2 failed, error code: 0x%08X", returnCode);
    goto out;
}
osalHandler->TaskSleepMs(5000);

// Resume the mission
returnCode = DjiWaypointV2_Resume();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Resume waypoint V2 failed, error code: 0x%08X", returnCode);
    goto out;
}
osalHandler->TaskSleepMs(50000);

// Stop the mission
returnCode = DjiWaypointV2_Stop();
```

#### Set and Get Cruise Speed

During mission execution, the global cruise speed can be dynamically adjusted:

```c
// Set global cruise speed (m/s)
T_DjiWaypointV2GlobalCruiseSpeed cruiseSpeed = 1.5f;
returnCode = DjiWaypointV2_SetGlobalCruiseSpeed(cruiseSpeed);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set global cruise speed failed, error code: 0x%08X", returnCode);
    goto out;
}

// Get the current global cruise speed
T_DjiWaypointV2GlobalCruiseSpeed currentSpeed = 0;
returnCode = DjiWaypointV2_GetGlobalCruiseSpeed(&currentSpeed);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get global cruise speed failed, error code: 0x%08X", returnCode);
    goto out;
}
USER_LOG_INFO("Current global cruise speed is %.2f m/s", currentSpeed);
```

Deinitialization:

```c
DjiWaypointV2_Deinit();
```

### Waypoint 3.0 Mission

:::tip Note:
Waypoint 3.0 supports Matrice 30 Series, Mavic 3 Enterprise Series, Matrice 3D/3TD, and subsequent models. For the KMZ file format, please refer to: [Route File Format](https://developer.dji.com/doc/cloud-api-tutorial/en/api-reference/dji-wpml/overview.html).
:::

Compared with the complex struct configuration of Waypoint 2.0, Waypoint 3.0 directly imports standard KMZ files for better versatility. Routes can be planned in advance using DJI Pilot and exported as KMZ files.

<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/waypoint-mission/waypoint_v3_sequence_en.svg" width="45%" alt="Waypoint 3.0 Interface Call Sequence"/></span></p>
</div>

#### Initialization and Callback Registration

Before using Waypoint 3.0, you need to initialize the module and register mission state and action state callbacks.

```c
// Step 1: Initialize the Waypoint V3 module
returnCode = DjiWaypointV3_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Waypoint V3 init failed.");
    return returnCode;
}

// Step 2: Register mission state callback (pushes current state machine, waypoint index, route ID)
returnCode = DjiWaypointV3_RegMissionStateCallback(DjiTest_WaypointV3MissionStateCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Register waypoint V3 state callback failed.");
    goto out;
}

// Register action state callback (pushes action execution state, action ID, action group ID)
returnCode = DjiWaypointV3_RegActionStateCallback(DjiTest_WaypointV3ActionStateCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Register waypoint V3 action state callback failed.");
    goto out;
}
```

Callback function examples:

```c
static T_DjiReturnCode DjiTest_WaypointV3MissionStateCallback(T_DjiWaypointV3MissionState missionState)
{
    USER_LOG_INFO("WP3 mission state: %d, waypoint index: %d, wayLine id: %d",
                  missionState.state, missionState.currentWaypointIndex, missionState.wayLineId);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}

static T_DjiReturnCode DjiTest_WaypointV3ActionStateCallback(T_DjiWaypointV3ActionState actionState)
{
    USER_LOG_INFO("WP3 action state: %d, waypoint index: %d, wayLine id: %d, action group: %d, action id: %d",
                  actionState.state, actionState.currentWaypointIndex, actionState.wayLineId,
                  actionState.actionGroupId, actionState.actionId);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

#### Upload KMZ Route File

```c
// Read KMZ file from file system and upload (Linux environment)
FILE *kmzFile = fopen("/path/to/waypoint.kmz", "r");
if (kmzFile == NULL) {
    USER_LOG_ERROR("Open kmz file failed.");
    goto out;
}

uint32_t kmzFileSize = 0;
UtilFile_GetFileSize(kmzFile, &kmzFileSize);

uint8_t *kmzFileBuf = osalHandler->Malloc(kmzFileSize);
fread(kmzFileBuf, 1, kmzFileSize, kmzFile);
fclose(kmzFile);

returnCode = DjiWaypointV3_UploadKmzFile(kmzFileBuf, kmzFileSize);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Upload kmz file failed.");
    goto out;
}
osalHandler->Free(kmzFileBuf);
```

#### Control Mission Execution

After uploading the KMZ file, call `DjiWaypointV3_Action` to control mission execution:

```c
// Start executing the route mission
returnCode = DjiWaypointV3_Action(DJI_WAYPOINT_V3_ACTION_START);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Execute start action failed.");
    goto out;
}

// Pause the mission
returnCode = DjiWaypointV3_Action(DJI_WAYPOINT_V3_ACTION_PAUSE);

// Resume the mission
returnCode = DjiWaypointV3_Action(DJI_WAYPOINT_V3_ACTION_RESUME);

// Stop the mission
returnCode = DjiWaypointV3_Action(DJI_WAYPOINT_V3_ACTION_STOP);
```

#### Deinitialization

```c
DjiWaypointV3_DeInit();
```

#### Query Mission Exit Reason

After the waypoint mission ends, you can call `DjiWaypointV3_GetExitReason` to query the exit result of the most recent mission.

The returned information includes:
- **Exit category**: normal finish / abnormal exit / user exit / running / no mission
- **Detailed exit reason**: e.g., low battery, RTH, RC takeover, obstacle stop, etc.

:::tip Note:
- This interface should be called after `DjiWaypointV3_Init()`. It is typically used after the mission state transitions out of `DJI_WAYPOINT_V3_MISSION_STATE_MISSION`.
- Supports Matrice 350 RTK and subsequent models. Minimum version requirement: PSDK 3.17.0.
:::

```c
T_DjiWaypointV3ExitResult exitResult;
returnCode = DjiWaypointV3_GetExitReason(&exitResult);
if (returnCode == DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_INFO("Mission exit category: %d, reason: %d",
                  exitResult.exitCategory, exitResult.exitReason);
}
```

### POI (Point of Interest) Orbiting Mission

:::tip Note:
The POI feature supports the Mavic 3 Enterprise series and subsequent models.
:::

The POI feature allows the aircraft to automatically orbit around a specified point. The orbiting radius is automatically calculated based on the aircraft's current position and the GPS coordinates of the target point.

<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/waypoint-mission/poi_sequence_en.svg" width="45%" alt="POI Interface Call Sequence"/></span></p>
</div>

#### Initialization and Callback Registration

Before using POI, you need to initialize the module and register the mission state callback to receive real-time information about the orbiting speed, radius, and mission state.

```c
// Step 1: Initialize the POI module
returnCode = DjiInterestPoint_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Interest point init failed, error code: 0x%08llX", returnCode);
    return returnCode;
}

// Step 2: Register mission state callback (pushes orbiting speed, radius, mission state)
returnCode = DjiInterestPoint_RegMissionStateCallback(DjiUser_InterestPointMissionStateCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Register mission state callback failed, error code: 0x%08llX", returnCode);
    goto out;
}
```

Callback function example:

```c
static T_DjiReturnCode DjiUser_InterestPointMissionStateCallback(T_DjiInterestPointMissionState missionState)
{
    USER_LOG_INFO("POI state: %d, speed: %.2f m/s, radius: %.2f m",
                  missionState.state, missionState.curSpeed, missionState.radius);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

#### Set Orbiting Speed

The orbiting speed can be set before starting the orbiting mission or during mission execution:

```c
returnCode = DjiInterestPoint_SetSpeed(5.0f);  // Unit: m/s
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set interest point speed failed, error code: 0x%08llX", returnCode);
    goto out;
}
```

#### Start Orbiting Mission

Set the GPS coordinates of the target orbiting point and call `DjiInterestPoint_Start` to begin orbiting:

```c
T_DjiInterestPointSettings settings = {0};
settings.latitude = 22.542812;   // Target point latitude (unit: rad)
settings.longitude = 113.958902; // Target point longitude (unit: rad)

returnCode = DjiInterestPoint_Start(settings);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Start interest point failed, error code: 0x%08llX", returnCode);
    goto out;
}
```

#### Stop Orbiting Mission

```c
returnCode = DjiInterestPoint_Stop();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Stop interest point failed, error code: 0x%08llX", returnCode);
    goto out;
}
```

Deinitialization:

```c
DjiInterestPoint_DeInit();
```
