## Overview

To help developers quickly build camera control features for DJI drones based on PSDK, DJI PSDK provides a camera management module. Through the camera management interfaces, developers can simultaneously set and get parameters such as ISO, aperture, shutter speed, and exposure for multiple cameras on the drone, and control cameras to perform functions such as photo capture, video recording, and tap zoom.
:::tip Note:
For Matrice 400, Matrice 4, Matrice 4D and future models, this feature requires the DJI Manifold 3 compute platform.
:::
Developers can:
- Get camera basic information (type, firmware version, connection status)
- Control capture functions (single shot, burst, interval, recording, reset camera settings)
- Set exposure parameters (exposure mode, ISO, aperture, shutter speed, exposure compensation, AE lock)
- Control zoom functions (optical zoom, tap zoom, infrared zoom, synchronized zoom)
- Control focus functions (focus mode, focus target, focus ring)
- Set capture format and storage (photo/video format, multi-lens storage, night scene mode, custom file extension names)
- Manage media files (download file list, download and delete files)
- Manage storage (get storage info, format SD card)
- Set metering functions (metering mode, spot metering)
- Use infrared camera functions (infrared thermometry, FFC calibration, gain mode, laser ranging)
- Use point cloud functions (point cloud recording, subscribe to point cloud data)

## Basic Concepts

### Camera Mount Position

The camera management module specifies the target camera through the mount position (`E_DjiMountPosition`). Multiple cameras can be installed on the drone simultaneously. The first parameter of all interfaces is `position`, which specifies the mount position of the camera to operate.

### Work Mode

The camera supports the following work modes, and different modes allow different operations:

| Work Mode | Description |
|-----------|-------------|
| Photo Mode (SHOOT_PHOTO) | Used for capturing photos |
| Video Mode (RECORD_VIDEO) | Used for recording videos |
| Playback Mode (PLAYBACK) | Used for previewing and deleting existing photos/videos |
| Download Mode (MEDIA_DOWNLOAD) | Used for downloading media files to external devices |

### Exposure Mode

The camera supports the following exposure modes. Some parameters can only be set in specific exposure modes:

| Exposure Mode | Manually Adjustable Parameters |
|---------------|-------------------------------|
| Program Auto (PROGRAM_AUTO) | Exposure Compensation (EV) |
| Shutter Priority (SHUTTER_PRIORITY) | Shutter Speed, Exposure Compensation |
| Aperture Priority (APERTURE_PRIORITY) | Aperture, Exposure Compensation |
| Manual Exposure (EXPOSURE_MANUAL) | ISO, Aperture, Shutter Speed |

### Photo Shooting Mode

| Photo Mode | Description |
|------------|-------------|
| Single (SINGLE) | Capture a single photo |
| HDR (HDR) | Capture an HDR composite photo |
| Burst (BURST) | Capture multiple photos in a single burst |
| AEB (AEB) | Auto Exposure Bracketing, quickly captures multiple photos with different exposures |
| Interval (INTERVAL) | Continuously captures photos at a set time interval |

### Focus Mode

| Focus Mode | Description |
|------------|-------------|
| Manual Focus (MANUAL) | Adjust focus distance by setting the focus ring value |
| Auto Focus (AUTO) | Automatically calculates focus distance based on the focus target point |
| Continuous Auto Focus (AFC) | Continuously tracks and auto-focuses |

### Zoom Types

| Zoom Type | Description |
|-----------|-------------|
| Optical Zoom | Adjusts by setting focal length or zoom factor; supports continuous zoom |
| Tap Zoom | Specifies a target point on screen and multiplier; camera automatically zooms to the target |
| Infrared Zoom | Sets the zoom factor for the infrared lens |
| Synchronized Zoom | Infrared and visible light lenses zoom synchronously in split-screen display |

## Implementation

:::tip Note:
It is recommended to develop and verify camera management features on the Linux platform. Some features (such as media file download and point cloud data subscription) do not support RTOS platforms.
:::

:::warning Warning:
The following code samples are reference examples intended to help developers understand the calling flow and implementation approach for each feature. Developers should adapt and adjust according to their own payload device's hardware characteristics and application scenarios.
:::

### Initialization

Before using camera management features, you must first call `DjiCameraManager_Init()` to initialize the camera management module.

```c
USER_LOG_INFO("--> Step 1: Init camera manager module");
DjiTest_WidgetLogAppend("--> Step 1: Init camera manager module");
returnCode = DjiCameraManager_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Init camera manager failed, error code: 0x%08X\r\n", returnCode);
    goto exitCameraModule;
}
```

### Get Camera Basic Information

After initialization, developers can call the corresponding interfaces to get the camera type, firmware version, and connection status at the specified mount position on the drone.

#### Get Camera Type and Version

```c
USER_LOG_INFO("--> Step 2: Get camera type and version");

if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get mounted position %d camera's type failed, error code: 0x%08X\r\n",
                   mountPosition, returnCode);
    goto exitCameraModule;
}
USER_LOG_INFO("Mounted position %d camera's type is %s",
              mountPosition,
              s_cameraTypeStrList[DjiTest_CameraManagerGetCameraTypeIndex(cameraType)].cameraTypeStr);

if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get mounted position %d camera's firmware version failed, error code: 0x%08X\r\n",
                   mountPosition, returnCode);

}
USER_LOG_INFO("Mounted position %d camera's firmware is V%d.%d.%d.%d\r\n", mountPosition,
              firmwareVersion.firmware_version[0], firmwareVersion.firmware_version[1],
              firmwareVersion.firmware_version[2], firmwareVersion.firmware_version[3]);
```

### Set Exposure Parameters

Camera management provides a series of Set/Get interfaces to set or get camera exposure parameters at the specified mount position. Before setting ISO, aperture, shutter speed, or other parameters, you must first set the corresponding exposure mode.

#### Set Exposure Mode

```c
returnCode = DjiCameraManager_SetExposureMode(mountPosition,
                                               DJI_CAMERA_MANAGER_EXPOSURE_MODE_EXPOSURE_MANUAL);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set camera exposure mode failed, error code: 0x%08X\r\n", returnCode);
}
```

#### Set ISO

You must first set the exposure mode to manual mode (`EXPOSURE_MANUAL`) before setting the ISO value.

```c
T_DjiReturnCode returnCode;
E_DjiCameraManagerISO isoDataTemp;

returnCode = DjiCameraManager_GetISO(position, &isoDataTemp);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS &&
    returnCode != DJI_ERROR_CAMERA_MANAGER_MODULE_CODE_UNSUPPORTED_COMMAND) {
    USER_LOG_ERROR("Get mounted position %d camera's iso failed, error code: 0x%08X.",
                   position, returnCode);
    return returnCode;
}

if (isoDataTemp == isoData) {
    USER_LOG_INFO("The mounted position %d camera's iso is already what you expected.",
                  position);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}

returnCode = DjiCameraManager_SetISO(position, isoData);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS &&
    returnCode != DJI_ERROR_CAMERA_MANAGER_MODULE_CODE_UNSUPPORTED_COMMAND) {
    USER_LOG_ERROR("Set mounted position %d camera's iso %d failed, "
                   "error code: 0x%08X.", position, isoData, returnCode);
}

return returnCode;
```

#### Set Shutter Speed

You must first set the exposure mode to manual mode or shutter priority mode before setting the shutter speed. Some newer models (H20/H20T/M30 series, etc.) only support setting shutter speed in manual mode.

```c
returnCode = DjiCameraManager_SetShutterSpeed(mountPosition,
                                               DJI_CAMERA_MANAGER_SHUTTER_SPEED_1_100);

}
```

#### Set Aperture

```c
returnCode = DjiCameraManager_SetAperture(mountPosition, DJI_CAMERA_MANAGER_APERTURE_F_4);
```

#### Subscribe to Point Cloud Data

:::warning Warning:
- The L2 camera supports mounting on Matrice 300 RTK, Matrice 350 RTK, and Matrice 400 platforms.
- The L3 camera supports mounting on the Matrice 400 platform.
- When subscribing to real-time 3D point cloud data, you must close DJI Pilot 2; otherwise, PSDK will not be able to subscribe to the camera's 3D point cloud data.
- Subscribing to real-time point cloud data is implemented through the MOP channel and is not part of the `DjiCameraManager` module interfaces.
:::

Developers can subscribe to real-time 3D point cloud data from L2/L3 cameras by calling the following sample.

```c
returnCode = DjiTest_CameraManagerSubscribePointCloud(mountPosition);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Fail to download point cloud. position %d, error code 0x%08llX",
               mountPosition, returnCode);
    goto exitCameraModule;
}
```
