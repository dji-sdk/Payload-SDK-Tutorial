## Overview
HMS (Health Management System) is a management system that monitors the operational health status of each module of the aircraft. DJI Pilot already provides an interactive interface to check whether the working status of each module is abnormal. PSDK provides basic interfaces to obtain error information of each module, enabling the PSDK program to be aware of the working status of all aircraft modules.

:::tip Note:
* For Matrice 400, Matrice 4, Matrice 4D, and future aircraft models, this feature requires Manifold 3.
* To inject custom alarm information into DJI Pilot, please refer to <a href="../basic-function/hms-customization.html" target="_blank" rel="noopener noreferrer">Custom HMS Function</a>.
:::

## Basic Concepts

### HMS Error Info

A single HMS error message contains the following fields:

| Field | Description |
|-------|-------------|
| errorCode | HMS error code, used to uniquely identify a type of error |
| componentIndex | Error component index |
| errorLevel | Error level (NONE / HINT / WARN / CRITICAL / FATAL) |

After subscribing to HMS information, these error messages will be packaged and sent to PSDK. PSDK parses the error information data into strings and prints them from the terminal.

### HMS Multilingual Database

HMS error code information can be queried through multilingual JSON files:
* General database: [hms.json](https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/cloudapi/hms.json)
* Flycart bilingual database: [drone-hms-langs.json](https://terra-1-g.djicdn.com/fee90c2e03e04e8da67ea6f56365fc76/SDK%20%E6%96%87%E6%A1%A3/PSDK/PSDK%203.9/drone-hms-langs.json)

### HMS Error Code Parsing Methods

PSDK provides two methods to parse error codes into readable alarm strings:

* **Error Code Info Table Method (RTOS Environment)**: Matches error codes through the built-in `hmsErrCodeInfoTbl` table, and selects the corresponding alarm information string based on the flight status (in-air / on-ground).
* **JSON File Method (Linux Environment)**: Matches error codes through the `hms.json` file, supporting multiple languages including Chinese, English, Japanese, French, etc.

Both methods require replacing placeholders in the alarm strings:

| Placeholder | Replace With |
|-------------|--------------|
| %alarmid | Error code value |
| %index | componentIndex + 1 |
| %component_index | componentIndex + 1 (hexadecimal format) |

## Implementation

:::warning Note:
The following code samples are reference examples intended to help developers understand the calling workflow and implementation approach for each function. Developers should adapt and adjust according to the actual hardware characteristics and application scenarios of their payload devices.
:::

### Initialization

Before using the related interfaces of the HMS function, you need to complete the following initialization work:

1. Subscribe to flight status data (used to distinguish whether the aircraft is on the ground or in the air, to select the corresponding alarm information)
2. Load the HMS error code database (load the `hms.json` file in Linux environment)
3. Call `DjiHmsManager_Init()` to complete HMS Manager module initialization

```c
T_DjiReturnCode returnCode;

/* Initialize data subscription module and subscribe to flight status */
returnCode = DjiFcSubscription_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Hms sample init data subscription module failed, error code:0x%08llX", returnCode);
    return returnCode;
}

returnCode = DjiFcSubscription_SubscribeTopic(DJI_FC_SUBSCRIPTION_TOPIC_STATUS_FLIGHT,
                                              DJI_DATA_SUBSCRIPTION_TOPIC_10_HZ,
                                              NULL);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("HMS sample subscribe topic flight status error, error code:0x%08llX", returnCode);
    return returnCode;
}

/* Initialize HMS Manager module */
returnCode = DjiHmsManager_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Hms manager init error, error code:0x%08llX", returnCode);
    return returnCode;
}
```

### HMS Information Subscription

Developers can register the HMS information callback by calling the `DjiHmsManager_RegHmsInfoCallback` interface to obtain real-time HMS error information push. The SDK pushes HMS information at a 1Hz frequency. When an exception occurs, developers can obtain the specific HMS error code, component index, and error level in the callback function.

```c
returnCode = DjiHmsManager_RegHmsInfoCallback(DjiTest_HmsInfoCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Register callback function of push HMS information failed, error code:0x%08llX", returnCode);
    goto out;
}
```

In the callback function, the received error codes need to be parsed into readable alarm strings. The parsing workflow includes: iterating through the HMS information table, matching error codes, selecting the corresponding alarm information based on the flight status (in-air/on-ground), replacing placeholders, and taking appropriate log output or handling measures based on the error level.

```c
static T_DjiReturnCode DjiTest_HmsInfoCallback(T_DjiHmsInfoTable hmsInfoTable)
{
    char alarmIdStr[20] = {0};
    char sensorIdStr[20] = {0};
    char componentIdStr[20] = {0};
    char printBuff[256] = {0};
    const char *originalAlarmInfo = NULL;
    uint8_t hmsCodeMatchFlag = 0;

    for (int i = 0; i < hmsInfoTable.hmsInfoNum; i++) {
        hmsCodeMatchFlag = 0;
        for (int j = 0; j < sizeof(hmsErrCodeInfoTbl) / sizeof(T_DjiHmsErrCodeInfo); j++) {
            if (hmsInfoTable.hmsInfo[i].errorCode == hmsErrCodeInfoTbl[j].alarmId) {
                hmsCodeMatchFlag = 1;
                snprintf(alarmIdStr, sizeof(alarmIdStr), "%u", hmsInfoTable.hmsInfo[i].errorCode);
                //note:sensor_idx:[0,5]. In order to be consistent with the display of pilot, add one.
                snprintf(sensorIdStr, sizeof(sensorIdStr), "%d", hmsInfoTable.hmsInfo[i].componentIndex + 1);
                snprintf(componentIdStr, sizeof(componentIdStr), "0x%02X",
                         hmsInfoTable.hmsInfo[i].componentIndex + 1);
                if (DjiTest_GetValueOfFlightStatus() == DJI_FC_SUBSCRIPTION_FLIGHT_STATUS_IN_AIR) {
                    originalAlarmInfo = hmsErrCodeInfoTbl[j].flyAlarmInfo;
                } else {
                    originalAlarmInfo = hmsErrCodeInfoTbl[j].groundAlarmInfo;
                }
                if (strlen(originalAlarmInfo)) {
                    snprintf(printBuff, sizeof(printBuff), "%s", originalAlarmInfo);
                    DjiTest_ReplaceStr(printBuff, sizeof(printBuff), "%alarmid", alarmIdStr);
                    DjiTest_ReplaceStr(printBuff, sizeof(printBuff), "%index", sensorIdStr);
                    DjiTest_ReplaceStr(printBuff, sizeof(printBuff), "%component_index", componentIdStr);
                    if (hmsInfoTable.hmsInfo[i].errorLevel > MIN_HMS_ERROR_LEVEL &&
                        hmsInfoTable.hmsInfo[i].errorLevel < MID_HMS_ERROR_LEVEL) {
                        USER_LOG_WARN("[ErrorCode:0x%2x] %s", hmsInfoTable.hmsInfo[i].errorCode, printBuff);
                    } else if (hmsInfoTable.hmsInfo[i].errorLevel >= MID_HMS_ERROR_LEVEL &&
                               hmsInfoTable.hmsInfo[i].errorLevel < MAX_HMS_ERROR_LEVEL) {
                        USER_LOG_ERROR("[ErrorCode:0x%2x] %s", hmsInfoTable.hmsInfo[i].errorCode, printBuff);
                    }
                }
            }
        }
        if (!hmsCodeMatchFlag) {
            USER_LOG_WARN("[ErrorCode:0x%2x] No matching entry in hmsErrCodeInfoTbl.",
                          hmsInfoTable.hmsInfo[i].errorCode);
        }
    }

    if (hmsInfoTable.hmsInfoNum == 0) {
        USER_LOG_INFO("All systems of drone are running well now.");
    }

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```
