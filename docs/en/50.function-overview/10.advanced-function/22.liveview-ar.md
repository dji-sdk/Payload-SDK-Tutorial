## Overview

The Open AR Capability Interface provides AR graphics rendering capabilities for streams, allowing developers to draw points, lines, 3D polygons, cylinders, and pivot axes on the DJI Pilot liveview interface, enabling augmented reality information overlay on the stream display.

:::warning Note:
This feature requires the use of Manifold 3.
:::

## Basic Concepts

### AR Graphics Types

AR graphics rendering capabilities include the following types:

| Graphics Type | Description |
|--------------|-------------|
| Point | Supports batch drawing, up to 16 points at a time. Can include text annotations and icon attributes |
| Line | Connect multiple coordinate points into line segments |
| 3D Polygon | Draw 3D polygons in space, with independent control of top, side, and bottom faces |
| Cylinder | Draw cylinders in 3D space, defined by center, radius, and normal vector |
| Pivot Axis | Draw 3D cone pivot axes in space |

Each graphics type supports full CRUD operations (Set/Update/Delete/Clear).

### AR Coordinate System

AR graphics use the longitude/latitude/altitude coordinate system (`T_DjiOpenArCoordinate`), defining the position of graphics in space through longitude, latitude, and altitude.

### Style and Resource Configuration

AR graphics styles are associated through the `style_id` defined in the `widget_config.json` file. Each graphics element is uniquely identified by the `uuid` in the `T_DjiOpenArIds` structure, with `style_id` referencing the styles described in `widget_config.json`.

:::warning Note:
The content after "//" in the following code is a code comment. Please do not add this content in the actual JSON configuration file.
:::

`widget_config.json` is a file used to configure static properties of controls, including style configurations for AR graphics rendering. Developers can change property values as needed. When modifying the configuration, please strictly adhere to [JSON](https://www.json.org/) syntax rules, or the configuration file will not be usable.

### Refresh Mechanism

When Pilot exits the Liveview interface and re-enters, the previously drawn AR graphics will be lost. Developers should register the `DjiLiveview_ArRegRefleshAllCallback` callback function to redraw all AR graphics upon receiving the refresh notification.

## Implementation

:::warning Note:
The following code samples are provided as reference examples to help developers understand the calling workflow and implementation approach of each feature. Developers should adapt and adjust based on the actual hardware characteristics and application scenarios of their own payload devices.
:::

### Register Refresh Notification Callback

Before drawing AR graphics, it is recommended to register the refresh notification callback function to ensure all AR graphics can be redrawn when Pilot re-enters the Liveview interface.

```c
T_DjiReturnCode DjiLiveview_ArRegRefleshAllCallback(DjiLiveview_ArRefleshAllCallback callback);
```

### Point Drawing

Supports batch rendering, updating, deleting, and clearing points.

:::tip Note:
A maximum of 16 points can be rendered at once.
:::

Use the set interface to batch render points. The style of the points is identified by the `style_id` parameter, which is described in `widget_config.json`.

```c
T_DjiReturnCode DjiLiveview_ArSetPoint(const T_DjiOpenArPointArray* entry);
```

Batch update already rendered points:

```c
T_DjiReturnCode DjiLiveview_ArUpdatePoint(const T_DjiOpenArPointArray* entry);
```

Batch delete already drawn points:

```c
T_DjiReturnCode DjiLiveview_ArDeletePoint(const T_DjiOpenArDeletePointEntry* entry);
```

Clear already drawn points by resource_id:

```c
T_DjiReturnCode DjiLiveview_ArClearPoint(uint32_t resource_id);
```

### Line Drawing

Supports set, update, delete, and clear operations for lines.

Connect multiple points to draw a line:

```c
T_DjiReturnCode DjiLiveview_ArSetLine(const T_DjiOpenArLine* entry);
```

Redraw already drawn lines:

```c
T_DjiReturnCode DjiLiveview_ArUpdateLine(const T_DjiOpenArLine* entry);
```

Batch delete already drawn lines:

```c
T_DjiReturnCode DjiLiveview_ArDeleteLine(const T_DjiOpenArDeleteLineEntry* entry, uint32_t entry_len);
```

Clear all already drawn lines:

```c
T_DjiReturnCode DjiLiveview_ArClearLine();
```

### Polygon Drawing

Supports drawing, updating, deleting, and clearing 3D polygons.

Draw 3D polygons in space:

```c
T_DjiReturnCode DjiLiveview_ArSetPolygon(const T_DjiOpenArPolygon* entry);
```

Redraw already drawn polygons:


Batch delete already drawn polygons:

Clear all already drawn polygons:
