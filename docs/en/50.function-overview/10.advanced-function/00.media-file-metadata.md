## Whitepaper V2.0 Beta

The development of DJI Media File Metadata Whitepaper V2.0 (DJI Video File Metadata Whitepaper V2.0) has entered the beta stage and has been adopted on several mass-produced products. The V2.0 version provides more metadata about video files and a new method of data organization, making it more convenient for users to implement industry applications such as image analysis or modeling. For details and data formats of DJI Video File Metadata Whitepaper V2.0, please contact camera-dev@dji.com.

## Whitepaper V1.0

[DJI Media File Metadata Whitepaper V1.0](https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/general/DJI_Media_File_Metadata_WhitePaper.zip) was officially released on May 7, 2021. This document describes the format for storing media file metadata and the meaning of each field.<br/>
By using this whitepaper, developers can understand the metadata and corresponding field information in media files, and implement industry applications such as image analysis or modeling based on media file metadata.
