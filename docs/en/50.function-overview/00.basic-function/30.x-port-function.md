## Overview

DJI X-Port standard gimbal is a hardware platform for developing payload devices. Developers can use X-Port to quickly develop payload devices with gimbal capabilities. Combined with the <a href="./custom-widget.html" target="_blank" rel="noopener noreferrer">Custom Widget</a> function, users can also control the X-Port and the payload device mounted on it through DJI Pilot and apps developed based on MSDK.

:::tip Note:
* Before using the X-Port control function, please follow the <a href="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/DJI%20ENTERPRISE%20X-Port%20user%20manual.pdf" target="_blank" rel="noopener noreferrer">User Guide</a>, <a href="../../payload-quick-start/configure-the-hardware-environment/payload-develop-criterion.html" target="_blank" rel="noopener noreferrer">Payload Standard</a> and <a href="../../payload-quick-start/configure-the-hardware-environment/device-connect.html" target="_blank" rel="noopener noreferrer">Interface Description</a> to reasonably design the payload device and use the X-Port correctly;
* When the X-Port is powered off abnormally, such as directly disconnecting from the gimbal interface, the parameter information set during the X-Port working process may not be stored normally.
:::

## Basic Concepts

### X-Port Status Information

Payload devices developed based on PSDK can obtain information such as the X-Port mode, current attitude, and calibration results. Please refer to the [PSDK API documentation](https://developer.dji.com/doc/payload-sdk-api-reference/en/practice/xport.html) for details on how to obtain X-Port status.

* Basic information: X-Port mode
* X-Port status: rotation status, control status, reset status, limit angle
* Key parameter: speed conversion factor

### X-Port Control

:::tip Note:
 X-Port standard gimbal integrates the basic functions of a gimbal. For details, please refer to <a href="../../function-overview/basic-function/gimbal-function.html" target="_blank" rel="noopener noreferrer">Gimbal Function</a>.
:::

#### Control Mode

X-Port rotation control supports the following three modes:

* Relative angle control: X-Port rotates by the **specified angle** within the specified time according to the angle **specified** by the user.
  * The rotation direction of the yaw axis is **independent of** the rotation angle sign.
  * **Intermediate value (X)** when the yaw axis rotates to the target angle = current angle of the yaw axis + rotation angle of the yaw axis
  * Final yaw axis **target angle** = `MOD((X + 180), 360) - 180`
* Absolute angle control: X-Port rotates from the **current position** to the specified position within the specified time according to the user's instruction.
* Speed control: The actual motion speed of X-Port is limited by the maximum speed.

:::tip Note:
* In the angle control mode, the rotation range of the X-Port yaw axis is [-180,180], and the **actual motion time** of the X-Port is limited by the **maximum acceleration and maximum speed** of the X-Port movement.
* The roll axis of the X-Port is used to eliminate drone vibration, and payload devices developed with PSDK cannot control the roll axis of the X-Port.
* X-Port **actual reachable position** is limited by the X-Port limit angle.
:::

#### Control Permission

For detailed description of X-Port control permissions, see Table 1.

* Permission rules:
  * Control actions with lower priority can only control the X-Port **after** higher priority control actions have ended;
  * Higher priority control actions can **preempt** the control of lower priority control actions;
  * Control scenarios with the same priority preempt control in **chronological order** of when control started; scenarios that start later cannot seize control.
* Permission release:
  * The payload device developed with PSDK releases the control right after completing the control of the X-Port;
  * If the payload device developed with PSDK does not release the control right after completing the control of the X-Port, the X-Port will automatically release the control right within 2s after the rotation ends.

#### Speed Conversion Factor

When the zoom factor of the camera payload is large, if the X-Port rotates quickly, the image recorded by the camera payload will become blurred, affecting the recording quality and viewing experience. Therefore, PSDK provides the "speed conversion factor" feature. By setting the conversion factor between the control command and the rotation speed, the payload device can still obtain a stable image even at a large zoom factor.

* Factor: Users can set the speed conversion factor of the X-Port according to actual needs. It is **recommended** to set the speed conversion factor to *the reciprocal of the zoom factor*.
* Max_speed (maximum speed of X-Port) = `Default Max Speed × Max Speed Percentage`
* Actual motion speed of X-Port = `Max_speed * Factor`, `Factor ≤ 1`

:::tip Note:
 X-Port only supports users using DJI Pilot and PSDK to set the speed conversion factor of X-Port.
:::

### X-Port Reset

* Yaw axis reset: Reset the X-Port yaw axis angle to the sum of the drone yaw axis angle and the X-Port yaw axis fine-tuning angle.
* Pitch axis and yaw axis reset: Reset the X-Port pitch axis angle to the fine-tuning angle, and reset the X-Port yaw axis angle to the sum of the drone yaw axis angle and the X-Port yaw axis fine-tuning angle.
* Reset X-Port yaw and pitch axes: Reset the X-Port yaw axis angle to the sum of the drone yaw axis and X-Port fine-tuning angle. Reset the X-Port pitch axis to the sum of -90° and the X-Port fine-tuning angle (X-Port mounted downward), or 90° and the X-Port fine-tuning angle (X-Port mounted upward).
* Reset the X-Port yaw axis to the sum of -90° and the X-Port fine-tuning angle (X-Port mounted downward), or 90° and the X-Port fine-tuning angle (X-Port mounted upward).

After setting the X-Port limit angle, the X-Port will rotate within the limited range. If the X-Port rotation angle exceeds the limit range, the X-Port will automatically adjust its attitude, which may cause slight jitter. To reduce jitter, the X-Port has a limit buffer zone.

:::warning Note:
 Except for the "Roll axis Euler angle" range which cannot be modified, all other types of limit angle ranges can be adjusted according to actual needs.
:::

#### Limit Buffer Zone

To reduce the jitter when the X-Port adjusts its attitude after exceeding the limit angle, limit buffer zones have been set for the X-Port pitch, roll, and yaw axes. When the X-Port enters the limit buffer zone, it will stop within the buffer zone.

:::tip Note:
* When the X-Port is in the limit buffer zone, it cannot move further toward the limit direction.
* The limit buffer width of the X-Port pitch and roll axes is 5°, and the limit buffer width of the yaw axis is 15°.
:::

**Example**
* If the upper limit of the yaw axis joint angle is 90° and the limit buffer width is 15°, the limit buffer zone is 75° ~ 90°;
* When the X-Port yaw axis angle is 30° and the angle control command controls the X-Port yaw axis angle to reach 78°, the X-Port will stop somewhere within the limit buffer zone, such as 80°;
* At this point, the X-Port yaw axis will not be able to move beyond 80°.

#### X-Port (Downward / Upward Mounted) Euler Angle Motion Range

* X-Port mounted downward:
  * When pitch axis angle range extension is not enabled, the pitch axis Euler angle motion range is `[pitchEulerAngleLowerLimit, pitchEulerAngleUpperLimit]`
  * When pitch axis angle range extension is enabled, the pitch axis Euler angle motion range is `[pitchEulerAngleExtensionLowerLimit, pitchEulerAngleExtensionUpperLimit]`
* X-Port mounted upward:
  * When pitch axis angle range extension is not enabled, the pitch axis Euler angle motion range is `[-pitchEulerAngleUpperLimit, -pitchEulerAngleLowerLimit]`
  * When pitch axis angle range extension is enabled, the pitch axis Euler angle motion range is `[-pitchEulerAngleExtensionUpperLimit, -pitchEulerAngleExtensionLowerLimit]`

## Implementation

:::tip Note:
 When using PSDK to develop the X-Port function for a payload device, please complete hardware installation and structural design according to the X-Port User Guide, and ensure the payload device meets the balance requirements.
:::

:::warning Note:
The following code samples are provided as reference examples to help developers understand the calling workflow and implementation approach of each feature. Developers should adapt and adjust based on the actual hardware characteristics and application scenarios of their own payload devices.
:::

### Status Reporting

Payload devices developed based on PSDK can receive X-Port system state information and attitude information by registering callback functions:

* **System state**: Includes X-Port mode, rotation status, control status, reset status, limit angle information, fine-tuning angle, etc.
* **Attitude information**: Includes the current pitch, roll, and yaw Euler angles of the X-Port.

**Get X-Port System State**

Construct a callback function to receive the X-Port system state information:

```c
static T_DjiReturnCode ReceiveXPortSystemState(T_DjiGimbalSystemState systemState)
{
    T_DjiReturnCode returnCode;
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    returnCode = osalHandler->MutexLock(s_userXPortMutex);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("user XPort mutex lock error: 0x%08llX.", returnCode);
        return returnCode;
    }

    s_isUserXPortSystemStateVaild = true;
    memcpy(&s_userXPortSystemState, &systemState, sizeof(T_DjiGimbalSystemState));

    returnCode = osalHandler->MutexUnlock(s_userXPortMutex);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("user XPort mutex unlock error: 0x%08llX.", returnCode);
        return returnCode;
    }

    USER_LOG_DEBUG("receive XPort system state: mounted upward flag %d, gimbal mode %d.",
                   systemState.mountedUpward, systemState.gimbalMode);

    USER_LOG_DEBUG("XPort fine tune: %d %d %d.", systemState.fineTuneAngle.pitch,
                   systemState.fineTuneAngle.roll, systemState.fineTuneAngle.yaw);

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

Register the system state receiving callback function:

```c
djiStat = DjiXPort_RegReceiveSystemStateCallback(ReceiveXPortSystemState);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("register receive XPort system state callback function error: 0x%08llX.", djiStat);
    return djiStat;
}
```

    USER_LOG_ERROR("get yaw joint angle limit angle from XPort error: 0x%08llX.", djiStat);
    continue;
}

USER_LOG_DEBUG("yaw joint angle limit angle of XPort: upper limit %d, lower limit %d.",
               limitAngle.upperLimit, limitAngle.lowerLimit);

### Mode Switch

X-Port supports three working modes. After setting the mode, you can check the current mode through the system state callback. 

* **Free mode** (`DJI_GIMBAL_MODE_FREE`): The X-Port does not follow the drone's attitude changes.
* **FPV mode** (`DJI_GIMBAL_MODE_FPV`): The X-Port follows the drone's yaw and roll axes rotation, maintaining the field of view unchanged.
* **YAW follow mode** (`DJI_GIMBAL_MODE_YAW_FOLLOW`): The X-Port only follows the drone's yaw axis rotation.

```c
djiStat = DjiXPort_SetGimbalModeSync(DJI_GIMBAL_MODE_FREE);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("set XPort gimbal mode error: 0x%08llX.", djiStat);
    return djiStat;
}
```

### Parameter Setting

To achieve stable control of the X-Port, you can set the speed conversion factor. When the zoom factor of the camera payload is large, reducing the speed conversion factor can avoid image blur. It is recommended to set the speed conversion factor to the reciprocal of the zoom factor. For details, see [Basic Concepts - Speed Conversion Factor](#speed-conversion-factor).

```c
if (USER_UTIL_IS_WORK_TURN(step, 10, XPORT_TASK_FREQ)) {
    if (DjiTest_CameraIsInited()) {
        djiStat = DjiTest_CameraGetOpticalZoomFactor(&opticalZoomFactor);
        if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
            USER_LOG_ERROR("get camera optical zoom factor error: %d.", djiStat);
            continue;
        }

        djiStat = DjiTest_CameraGetDigitalZoomFactor(&digitalZoomFactor);
        if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
            USER_LOG_ERROR("get camera digital zoom factor error: %d.", djiStat);
            continue;
        }

        djiStat = DjiXPort_SetSpeedConversionFactor(1 / (opticalZoomFactor * digitalZoomFactor));
        if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
            USER_LOG_ERROR("set speed conversion factor error: %d.", djiStat);
            continue;
        }
    }
}
```

### Rotation Control

X-Port controls rotation through `DjiXPort_RotateSync()` in synchronous blocking mode, supporting three modes:

* **Relative angle control**: Rotate by a specified angle increment from the current position within the specified time.
* **Absolute angle control**: Rotate to a specified target angle within the specified time.
* **Speed control**: Continuously rotate at a specified speed.

After control is complete, you can call `DjiXPort_ReleaseControlPermissionSync()` to actively release control permission. If not actively released, the X-Port will automatically release the control permission within 2s after rotation ends. For details on control permissions, see [Basic Concepts - Control Permission](#control-permission).

**Rotation Control**

```c
T_DjiGimbalRotationProperty rotationProperty = {0};
T_DjiAttitude3d rotationValue = {0};

rotationProperty.relativeAngleRotation.actionTime = 2000;
rotationValue.pitch = 0;
rotationValue.roll = 0;
rotationValue.yaw = 300;

djiStat = DjiXPort_RotateSync(DJI_GIMBAL_ROTATION_MODE_RELATIVE_ANGLE,
                              rotationProperty, rotationValue);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("rotate XPort error: 0x%08llX.", djiStat);
    return djiStat;
}
```

**Release Control Permission**

```c
djiStat = DjiXPort_ReleaseControlPermissionSync();
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("release XPort control permission error: 0x%08llX.", djiStat);
    return djiStat;
}
```

### Reset

X-Port supports multiple reset modes to restore the gimbal attitude to a specified initial state. For details on the target angles of each reset mode, see [Basic Concepts - X-Port Reset](#x-port-reset).

## FAQ

### How to Debug the X-Port?

After installing the payload device on the X-Port, you need to complete manual leveling first, then perform software debugging through [DJI Assistant 2](http://www.dji.com/matrice-200-series-v2/info#downloads). For details on installation steps and the DJI Assistant 2 interface, please refer to the DJI X-Port <a href="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/DJI ENTERPRISE X-Port 用户手册.pdf">User Guide</a>.

:::tip Note:
* When installing the payload device on the X-Port, please ensure that the payload device on the X-Port can **stay in each position** of the pitch, yaw, and roll axes, and **maintain balance at each position**.
* While debugging the gimbal with DJI Assistant 2, do not control the gimbal, such as controlling the gimbal angle, speed, or gimbal centering.
:::

#### Manual Leveling

**1. Adjust the pitch axis**

Rotate the payload device around the P-axis centerline to ensure the payload device can stay at each position of the pitch axis.

**2. Roll axis leveling**

1. Use an L-shaped hex screwdriver to loosen the 4 screws on the Roll axis arm (no need to remove the screws);
2. Adjust the R-axis arm position left and right, so that the R-axis arm maintains balance at any position when rotating;
3. Re-tighten the 4 screws (torque: 2.0±0.1 kgf.cm).

3. Re-tighten the 4 screws (torque: 2.0±0.1 kgf.cm).

#### Software Debugging

After completing manual leveling, please debug in the following order: **Balance Detection -> Coaxiality Detection -> Control Parameter Auto-tuning -> Auto Calibration**.

**1. Balance Detection** (X-Port in joint angle mode)

1. On the "Gimbal Settings" page, click "Gimbal Balance Detection", and prepare the drone and X-Port gimbal according to the instructions;
2. Detect and adjust the X-Port according to the guidance of DJI Assistant 2;
3. During detection, if the X-Port is not balanced, the developer needs to readjust the gimbal based on the detection progress and results:
   1. Please move the payload forward (backward), upward (downward), and then perform the balance detection again;
   2. Please adjust the position of the gimbal roll axis arm to the left (right), and then perform the balance detection again;
   3. Please adjust the position of the gimbal yaw axis arm forward (backward), and then perform the balance detection again.

**2. Coaxiality Detection** (X-Port in joint angle mode)

Before performing coaxiality detection, please perform balance detection first, and ensure the result is good.

1. On the "Gimbal Settings" page, click "Gimbal Coaxiality Detection", and prepare the drone and X-Port gimbal according to the instructions;
2. Detect and adjust the X-Port according to the guidance of DJI Assistant 2;
3. During testing, if the X-Port coaxiality test result is poor, please adjust the screws of the payload auxiliary axis arm forward (backward), upward (downward), and then perform the coaxiality test again.

**3. Control Parameter Auto-tuning**

Before performing control parameter auto-tuning, please perform balance detection and coaxiality detection first, and ensure the results are good. Place the drone horizontally, and ensure that the roll and pitch axis angles are within ±5°.

1. On the "Gimbal Settings" page, click "Gimbal Parameter Auto-tuning", DJI Assistant 2 will automatically adjust the X-Port control parameters according to the payload device status;
2. Turn off the drone motors and keep the payload device in a static state;
3. DJI Assistant 2 or DJI Pilot sends gimbal control commands to the X-Port to execute the control parameter auto-tuning function.

**4. Auto Calibration**

If the initial position of the payload device on the X-Port is not horizontally centered, use the auto-calibration function to calibrate the X-Port.
