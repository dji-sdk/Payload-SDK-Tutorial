Camera basic functions are the core features of camera-type payload devices, covering camera mode switching, photo capture, video recording, and SD card management.

## Basic Concepts

### Camera Mode

Before using the camera class function, you need to set the mode of the camera-type payload device. Different modes specify the working logic of the camera-type payload device when performing a certain task.

* Take a photo: In this mode, the user can trigger the camera-type payload device to take a photo.
* Recording: In this mode, users can trigger camera-type payload devices to record video.
* Video playback: In this mode, users can play or download media files on the payload device on the Mobile App.

:::warning Note:
 The camera can only perform corresponding operations in one mode, such as in video mode **only video recording but not taking photos**.
:::

### Photo Mode

The camera-type payload device developed with PSDK supports the following photo modes:

* Single shot: After issuing the photo command, the camera takes a single photo.
* Burst: After issuing the photo command, the camera will continuously shoot the specified number of photos; currently supports 2/3/5/7/10/14 burst shots.
* Interval photo: When a photo command is issued, the camera will take a specified number of photos at a specified time interval.
    * Currently supports 2/3/5/7/10 second intervals;
    * Currently the maximum number of photos can be specified as 254. When the number of photos is 255, the camera will take photos continuously.

### Media File Management
The camera-type payload device developed with PSDK can perform operations such as file deletion or download according to the user's instructions.

### Media File Preview
The camera-type payload device developed with PSDK allows users to preview the media files in the payload device using DJI Pilot or the Mobile App developed based on MSDK.
* Static preview: preview a single file or a list of files
  * Thumbnail, preview file list
    - Image: The payload device generates a thumbnail in the original proportion of the file, please set the width of the preview image to 100 pixels
    - Video: Capture a frame of the video
  * Screenshot, preview individual files
    - Image: at the original ratio, it is recommended to scale the image into a preview image with a width of 600 pixels
    - Video: Capture a frame of the video
  * Original files, if you want to get the original media files in the camera-type payload device, please use the download function to obtain the specified media files.
* Dynamic preview (video preview): play, pause, stop, seek (fast forward, rewind and progress drag)
  
:::tip Note:
Supported file formats for dynamic preview: MP4, JPG, DNG and MOV. For encoding formats, please refer to <a href="../../../payload-quick-start/configure-the-hardware-environment/payload-develop-criterion.html#video-stream-transmission-standard" target="_blank" rel="noopener noreferrer">Video Standard</a>.
:::

## Implementation

:::warning Note:
* Before developing the basic functions of camera-type payload devices using PSDK, you need to call `DjiPayloadCamera_Init()` to initialize the camera module. For details, see <a href="./camera-overview.html#initialization" target="_blank" rel="noopener noreferrer">Camera Function Overview - Initialization</a>.
* The following code samples are reference examples intended to help developers understand the calling process and implementation approach for each function. Developers can adapt and adjust them according to the actual hardware characteristics and application scenarios of their payload devices.
:::

### Register Basic Function Callbacks

Developers are requested to construct functions for setting camera mode, taking photos and recording videos for camera-type payload devices according to the structure `T_DjiCameraCommonHandler` in PSDK based on the selected **development platform** and the actual use requirements of industrial applications. After registering the camera functions to the interface specified in PSDK, users can control the camera-type payload device developed with PSDK to perform the corresponding actions by using DJI Pilot or the Mobile App developed based on MSDK.

```c
    // Get the current state of the payload device system
    s_commonHandler.GetSystemState = GetSystemState;
    // Implement the function of setting the camera-type payload device mode
    s_commonHandler.SetMode = SetMode;
    s_commonHandler.GetMode = DjiTest_CameraGetMode;
    // Implement the function to start or stop recording
    s_commonHandler.StartRecordVideo = StartRecordVideo;
    s_commonHandler.StopRecordVideo = StopRecordVideo;
    // Implement the function to start or stop taking photos
    s_commonHandler.StartShootPhoto = StartShootPhoto;
    s_commonHandler.StopShootPhoto = StopShootPhoto;
    // Implement the photo shooting functions of the camera-type payload device
    s_commonHandler.SetShootPhotoMode = SetShootPhotoMode;
    s_commonHandler.GetShootPhotoMode = GetShootPhotoMode;
    s_commonHandler.SetPhotoBurstCount = SetPhotoBurstCount;
    s_commonHandler.GetPhotoBurstCount = GetPhotoBurstCount;
    s_commonHandler.SetPhotoTimeIntervalSettings = SetPhotoTimeIntervalSettings;
    s_commonHandler.GetPhotoTimeIntervalSettings = GetPhotoTimeIntervalSettings;
    // Implement SD card management function
    s_commonHandler.GetSDCardState = GetSDCardState;
    s_commonHandler.FormatSDCard = FormatSDCard;

    returnCode = DjiPayloadCamera_RegCommonHandler(&s_commonHandler);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("camera register common handler error:0x%08llX", returnCode);
    }
```

#### Control the Camera to Take a Single Shot
The payload device control program developed based on PSDK calls the `StartShootPhoto` and `StopShootPhoto` interfaces to control the camera-type payload device to take a single photo. Users can use DJI Pilot and the Mobile App developed based on MSDK to control the camera-type payload device to take a single photo.

```c
static T_DjiReturnCode StartShootPhoto(void)
{
    T_DjiReturnCode returnCode;
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    returnCode = osalHandler->MutexLock(s_commonMutex);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("lock mutex error: 0x%08llX.", returnCode);
        return returnCode;
    }

    USER_LOG_INFO("start shoot photo");
    s_cameraState.isStoring = true;

    if (s_cameraShootPhotoMode == DJI_CAMERA_SHOOT_PHOTO_MODE_SINGLE) {
        s_cameraState.shootingState = DJI_CAMERA_SHOOTING_SINGLE_PHOTO;
    } else if (s_cameraShootPhotoMode == DJI_CAMERA_SHOOT_PHOTO_MODE_BURST) {
        s_cameraState.shootingState = DJI_CAMERA_SHOOTING_BURST_PHOTO;
    } else if (s_cameraShootPhotoMode == DJI_CAMERA_SHOOT_PHOTO_MODE_INTERVAL) {
        s_cameraState.shootingState = DJI_CAMERA_SHOOTING_INTERVAL_PHOTO;
        s_cameraState.isShootingIntervalStart = true;
        s_cameraState.currentPhotoShootingIntervalTimeInSeconds = s_cameraPhotoTimeIntervalSettings.timeIntervalSeconds;
    }

    returnCode = osalHandler->MutexUnlock(s_commonMutex);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("unlock mutex error: 0x%08llX.", returnCode);
        return returnCode;
    }

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}

static T_DjiReturnCode StopShootPhoto(void)
{
    T_DjiReturnCode returnCode;
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    returnCode = osalHandler->MutexLock(s_commonMutex);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("lock mutex error: 0x%08llX.", returnCode);
        return returnCode;
    }

    USER_LOG_INFO("stop shoot photo");
    s_cameraState.shootingState = DJI_CAMERA_SHOOTING_PHOTO_IDLE;
    s_cameraState.isStoring = false;
    s_cameraState.isShootingIntervalStart = false;

    returnCode = osalHandler->MutexUnlock(s_commonMutex);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("unlock mutex error: 0x%08llX.", returnCode);
        return returnCode;
    }

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

#### Photo Status Management
After clicking the "Photo" button in DJI Pilot or the Mobile App developed with MSDK, the camera-type payload device developed with PSDK will perform photo capture, photo storage, and memory status update operations in the thread within a custom time (e.g. 0.5s).

**Confirm Photo Status**

After the camera-type payload device developed with PSDK performs the photo action, it needs to obtain the photo status of the payload device.

```c
if (s_cameraState.shootingState != DJI_CAMERA_SHOOTING_PHOTO_IDLE &&
    photoCnt++ > TAKING_PHOTO_SPENT_TIME_MS_EMU / (1000 / PAYLOAD_CAMERA_EMU_TASK_FREQ)) {
    s_cameraState.isStoring = false;
    s_cameraState.shootingState = DJI_CAMERA_SHOOTING_PHOTO_IDLE;
    photoCnt = 0;
}
```

**Store Photos**

After the camera-type payload device finishes taking photos, the camera-type payload device developed with PSDK stores the photos taken by the camera in the memory card **on the camera-type payload device**.

* Store photos taken by the camera-type payload device in single-shot mode

```c
if (s_cameraShootPhotoMode == DJI_CAMERA_SHOOT_PHOTO_MODE_SINGLE) {
    s_cameraSDCardState.remainSpaceInMB =
        s_cameraSDCardState.remainSpaceInMB - SDCARD_PER_PHOTO_SPACE_IN_MB;
    s_cameraState.isStoring = false;
    s_cameraState.shootingState = DJI_CAMERA_SHOOTING_PHOTO_IDLE;
}
```

* Store photos taken by the camera-type payload device in burst mode

```c
else if (s_cameraShootPhotoMode == DJI_CAMERA_SHOOT_PHOTO_MODE_BURST) {
    s_cameraSDCardState.remainSpaceInMB =
        s_cameraSDCardState.remainSpaceInMB - SDCARD_PER_PHOTO_SPACE_IN_MB * s_cameraBurstCount;
    s_cameraState.isStoring = false;
    s_cameraState.shootingState = DJI_CAMERA_SHOOTING_PHOTO_IDLE;
}
```

* Store photos taken by the camera-type payload device in interval photo mode

```c
else if (s_cameraShootPhotoMode == DJI_CAMERA_SHOOT_PHOTO_MODE_INTERVAL) {
    if (isStartIntervalPhotoAction == true) {
        s_cameraState.isStoring = false;
        s_cameraState.shootingState = DJI_CAMERA_SHOOTING_PHOTO_IDLE;
        s_cameraSDCardState.remainSpaceInMB =
            s_cameraSDCardState.remainSpaceInMB - SDCARD_PER_PHOTO_SPACE_IN_MB;
    }
}
```

**Check Storage Space**

To ensure that the SD card in the camera-type payload device has sufficient storage space to store photos or videos after the camera-type payload device performs a photo action, it is recommended to add the function of checking the SD card storage space in the camera-type payload device developed with PSDK.

* Check the remaining storage space of the SD card after the camera-type payload device performs single shot and burst shooting.

```c
if (s_cameraSDCardState.remainSpaceInMB > SDCARD_TOTAL_SPACE_IN_MB) {
    s_cameraSDCardState.remainSpaceInMB = 0;
    s_cameraSDCardState.isFull = true;
}
```

* Check the remaining storage space of the SD card after the camera-type payload device performs interval photography

```c
if (s_cameraShootPhotoMode == DJI_CAMERA_SHOOT_PHOTO_MODE_INTERVAL) {
    if (isStartIntervalPhotoAction == true) {
```

#### Control Camera Recording

Users can use DJI Pilot and the Mobile App developed based on MSDK to control the camera-type payload device recording.

```c
static T_DjiReturnCode StartRecordVideo(void)
{
    T_DjiReturnCode djiStat;
    T_DjiReturnCode returnCode = DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    djiStat = osalHandler->MutexLock(s_commonMutex);
    if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("lock mutex error: 0x%08llX.", djiStat);
        return djiStat;
    }

    if (s_cameraState.isRecording != false) {
        USER_LOG_ERROR("camera is already in recording state");
        returnCode = DJI_ERROR_SYSTEM_MODULE_CODE_NONSUPPORT_IN_CURRENT_STATE;
        goto out;
    }

    s_cameraState.isRecording = true;
    USER_LOG_INFO("start record video");

out:
    djiStat = osalHandler->MutexUnlock(s_commonMutex);
    if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("unlock mutex error: 0x%08llX.", djiStat);
        return djiStat;
    }

    return returnCode;
}

    }

    return returnCode;
}
```

### SD Card Management

:::tip Note:
* Camera-type payload devices developed using X-Port need to implement the function of storing media files and register this function in the interface specified by PSDK. The memory card on the X-Port only supports storing X-Port log information, and cannot store the media files generated by the payload device.
* This tutorial takes the **simulated** SD card management function as an example to introduce how to use the PSDK SD card management function. If you need to develop a payload device with SD card management capabilities, please call the interface of the payload device system to implement the SD card management function.
:::

#### SD Card Module Initialization
To use the SD card management function, the developer needs to first develop and register the function to operate the SD card, and obtain the status information of the SD card by initializing the SD card management module.

```c
    /* Init the SDcard parameters */
    s_cameraSDCardState.isInserted = true;
    s_cameraSDCardState.isVerified = true;
    s_cameraSDCardState.totalSpaceInMB = SDCARD_TOTAL_SPACE_IN_MB;
    s_cameraSDCardState.remainSpaceInMB = SDCARD_TOTAL_SPACE_IN_MB;
    s_cameraSDCardState.availableCaptureCount = SDCARD_TOTAL_SPACE_IN_MB / SDCARD_PER_PHOTO_SPACE_IN_MB;
    s_cameraSDCardState.availableRecordingTimeInSeconds = SDCARD_TOTAL_SPACE_IN_MB / SDCARD_PER_SECONDS_RECORD_SPACE_IN_MB;
```

#### SD Card Formatting
The payload device control program developed based on PSDK can control the payload device to execute SD card formatting by calling the `FormatSDCard` interface. Users can use DJI Pilot and the APP developed based on MSDK to obtain the status information of the SD card in the payload device and control the payload device to execute the SD card formatting function.

```c
static T_DjiReturnCode FormatSDCard(void)
{
    T_DjiReturnCode returnCode;
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    returnCode = osalHandler->MutexLock(s_commonMutex);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("lock mutex error: 0x%08llX.", returnCode);
        return returnCode;
    }

    USER_LOG_INFO("format sdcard");

    memset(&s_cameraSDCardState, 0, sizeof(T_DjiCameraSDCardState));
    s_cameraSDCardState.isInserted = true;
    s_cameraSDCardState.isVerified = true;
    s_cameraSDCardState.totalSpaceInMB = SDCARD_TOTAL_SPACE_IN_MB;
    s_cameraSDCardState.remainSpaceInMB = SDCARD_TOTAL_SPACE_IN_MB;
    s_cameraSDCardState.availableCaptureCount = SDCARD_TOTAL_SPACE_IN_MB / SDCARD_PER_PHOTO_SPACE_IN_MB;
    s_cameraSDCardState.availableRecordingTimeInSeconds =
    SDCARD_TOTAL_SPACE_IN_MB / SDCARD_PER_SECONDS_RECORD_SPACE_IN_MB;

    returnCode = osalHandler->MutexUnlock(s_commonMutex);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("unlock mutex error: 0x%08llX.", returnCode);
        return returnCode;
    }

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```
