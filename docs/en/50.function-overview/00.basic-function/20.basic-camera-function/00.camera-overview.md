## Overview

PSDK provides camera payload control interfaces, enabling developers to integrate capabilities such as photo capture, video recording, zoom, and focus, and control camera payloads through DJI Pilot or MSDK-based Apps.

## API Overview

Developers need to call `DjiPayloadCamera_Init()` to initialize the camera module, then register different callback handler sets as needed. The corresponding Handler structures and registration interfaces for each feature are as follows:

| Function | Handler Structure | Registration Interface |
|---------|-------------------|----------------------|
| Camera Basic Functions | T_DjiCameraCommonHandler | DjiPayloadCamera_RegCommonHandler() |
| Focus Function | T_DjiCameraFocusHandler | DjiPayloadCamera_RegFocusHandler() |
| Metering Function | T_DjiCameraExposureMeteringHandler | DjiPayloadCamera_RegExposureMeteringHandler() |
| Digital Zoom | T_DjiCameraDigitalZoomHandler | DjiPayloadCamera_RegDigitalZoomHandler() |
| Optical Zoom | T_DjiCameraOpticalZoomHandler | DjiPayloadCamera_RegOpticalZoomHandler() |
| Tap Zoom | T_DjiCameraTapZoomHandler | DjiPayloadCamera_RegTapZoomHandler() |

:::tip Note:
Interfaces with `()` in the table are actively called interfaces, while those without `()` are callback functions.
:::

## Basic Concepts

### Camera Mode and Photo Capture
Camera payload devices must first switch to the corresponding mode (photo, video, or video playback) before operation; only one mode can be active at a time. In photo mode, multiple shooting methods are supported, including single shot, burst, and interval photo. See <a href="./camera-basic.html#basic-concepts" target="_blank" rel="noopener noreferrer">Camera Basic Functions - Basic Concepts</a> for details.

### Focus Function
The focus function controls the camera lens to adjust the focal point, ensuring the subject is captured clearly. Developers can implement two modes: Auto Focus (AF) and Manual Focus (MF), and can set the focus target position, focus ring parameters, and focus assistant settings. See <a href="./camera-focus.html#basic-concepts" target="_blank" rel="noopener noreferrer">Focus - Basic Concepts</a> for details.

### Metering Function
The metering function analyzes the brightness of the scene to provide correct exposure parameters for the camera. Depending on the shooting scenario, you can choose average metering, center-weighted metering, or spot metering mode. See <a href="./camera-metering.html#basic-concepts" target="_blank" rel="noopener noreferrer">Metering Function - Basic Concepts</a> for details.

### Zoom Function
The zoom function adjusts the focal length of the camera lens to change the field of view and the apparent distance to the subject. Four zoom methods are supported: optical zoom, digital zoom, continuous zoom, and tap zoom. Developers can implement them as needed based on the hardware capabilities of the payload device. See <a href="./camera-zoom.html#basic-concepts" target="_blank" rel="noopener noreferrer">Zoom - Basic Concepts</a> for details.

## Initialization

When using PSDK to develop camera functions for a payload device, you must first initialize the camera module and then register the callback handler sets for each feature as needed. Below is the framework code for the initialization process:

:::tip Note:
* `DjiPayloadCamera_RegCommonHandler` is the required basic function callback registration. The remaining Handlers can be registered as needed based on actual requirements.
* For detailed field assignments and feature implementations of each Handler, please refer to the corresponding feature documentation.
:::

```c
// 1. Initialize the camera module
returnCode = DjiPayloadCamera_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("init payload camera error:0x%08llX", returnCode);
    return returnCode;
}

// 2. Register basic function callbacks (mode/photo/video/SD card) — required
returnCode = DjiPayloadCamera_RegCommonHandler(&s_commonHandler);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("camera register common handler error:0x%08llX", returnCode);
}

// 3. Register exposure metering callbacks — optional
returnCode = DjiPayloadCamera_RegExposureMeteringHandler(&s_exposureMeteringHandler);

// 4. Register focus callbacks — optional
returnCode = DjiPayloadCamera_RegFocusHandler(&s_focusHandler);

// 5. Register digital zoom callbacks — optional
returnCode = DjiPayloadCamera_RegDigitalZoomHandler(&s_digitalZoomHandler);

// 6. Register optical zoom callbacks — optional
returnCode = DjiPayloadCamera_RegOpticalZoomHandler(&s_opticalZoomHandler);

// 7. Register tap zoom callbacks — optional
returnCode = DjiPayloadCamera_RegTapZoomHandler(&s_tapZoomHandler);
```
