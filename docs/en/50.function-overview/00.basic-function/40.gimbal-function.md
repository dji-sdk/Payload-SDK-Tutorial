## Overview

Using the gimbal function of PSDK, developers can implement gimbal control capabilities for payload devices. Developers need to design the gimbal hardware and implement the control program. After registering gimbal control functions to PSDK's specified interfaces, users can control the gimbal and obtain gimbal status information such as attitude through DJI Pilot, Mobile Apps developed based on MSDK, or the remote controller.

:::tip Note:
* Only payload devices developed with SkyPort support the gimbal function using PSDK.
* X-Port supports developers to adjust configuration parameters using DJI Assistant 2 (version 2.0.11 and above).
:::

## Basic Concepts

### Gimbal Status Information

Gimbal-type payload devices developed using PSDK need to report gimbal status, current attitude, and calibration status according to specified requirements, so that the user's Mobile App or onboard computer can achieve precise control based on the gimbal status. Please refer to the **PSDK API documentation** for methods and details on obtaining gimbal status.

### Gimbal Mode

The gimbal mode determines how the gimbal rotates when following the drone's movement:

* Free mode: When the drone's attitude changes, the gimbal will not rotate.
* FPV mode: When the drone's attitude changes, the gimbal will rotate the yaw axis and roll axis to ensure that the current field of view of the payload device does not change.
* YAW Follow mode: In this mode, the gimbal's yaw axis will follow the drone's yaw axis rotation.

:::tip Note:
 In all three modes above, other modules in the drone system (gimbal control commands during waypoint flight), the remote controller, and the Mobile App can control the gimbal rotation.
:::

### Gimbal Control

#### Control Mode

There are three control modes for gimbal rotation:

* Relative angle control: The gimbal developed with PSDK rotates the **specified angle** within the specified time according to the angle **specified** by the user.
* Absolute angle control: The gimbal developed with PSDK rotates from the **current position** to the specified position within the specified time according to the user's instruction.
* Speed control: The user can control the rotation speed of the gimbal developed with PSDK.

:::tip Note:
* In the angle control mode, the rotation time of the gimbal is limited by the maximum rotation speed and maximum acceleration of the gimbal, and the actual rotation angle is limited by the gimbal's limit angle.
* In speed control mode, the gimbal rotates for 0.5s according to the speed specified by the user. When the gimbal rotates to the limit angle, it will stop rotating.
:::

#### Control Permission

For detailed description of gimbal control permissions, see Table 1. Gimbal Control Permissions.

* Control rules:
  * Control actions with low priority can only control the gimbal after high priority control actions have ended;
  * High priority control actions can preempt control of low priority control actions;
  * Control scenarios with the same priority preempt control in chronological order of when control started; scenarios that start later cannot seize control.
* Permission release:
  * After the control module completes gimbal control, it will release the control right;
  * If the control module does not release the control right after completing gimbal control, the gimbal developed with PSDK will automatically release the control right within the specified time after gimbal rotation ends.

#### Smoothness

The smoothness of the gimbal refers to the responsiveness of the gimbal's actions. The gimbal developed with PSDK supports users to set the smooth control coefficient through DJI Pilot and the Mobile App developed based on MSDK to achieve smooth start and stop of the gimbal.

* Smooth control coefficient: The smooth control coefficient determines the maximum acceleration of the gimbal rotation.
* Maximum acceleration of gimbal rotation = 10000 × (0.8 ^ (1 + X)) deg/s^2 (X is the smooth control coefficient)

#### Maximum Speed Percentage

* Maximum speed percentage: The maximum speed percentage of the gimbal determines the maximum speed of the gimbal's rotation.

* Actual maximum rotation speed of the gimbal = default maximum speed × maximum speed percentage

:::tip Note:
Developers can set the default maximum gimbal rotation speed according to actual usage needs.
:::

#### Angle Fine-tuning

The gimbal developed with PSDK supports users to finely adjust the gimbal joint angle through DJI Pilot and the Mobile App developed based on MSDK. The adjustment results can also be stored in the payload device as calibration parameters to reduce various gimbal errors.

#### Gimbal Limit Function

To avoid accidental damage to the gimbal due to structural interference or interference with the drone's flight mission when the gimbal is working, be sure to set mechanical limits and software limits for the gimbal.

* Mechanical limit: The mechanical limit is determined by the physical form and design structure of the gimbal-type payload device. For details, please refer to <a href="../../payload-quick-start/configure-the-hardware-environment/payload-develop-criterion.html" target="_blank" rel="noopener noreferrer">Standard Declaration</a>.

* Software limit: Developers can set software limits according to actual usage requirements:

  * Set the Euler angle limit of the gimbal pitch axis, roll axis, and yaw axis;
  * Set the pitch axis Euler angle extension angle limit;
  * Set the gimbal joint angle limit.
  :::tip Tip:
  * After using the pitch axis angle range extension function, the Euler angle limit of the gimbal pitch axis can be set to the default limit or the extended limit.
  * When the gimbal joint angle reaches the limit, DJI Pilot and the Mobile App developed based on MSDK will receive a prompt message that the gimbal has rotated to the limit angle.
  :::


#### Gimbal Reset

Gimbal-type payload devices developed with PSDK support users to reset the gimbal through DJI Pilot and the Mobile App developed based on MSDK, resetting the gimbal attitude to the initial state.

* Yaw axis reset: Reset the gimbal yaw axis angle to the sum of the drone yaw axis angle and the gimbal yaw axis fine-tuning angle.
* Pitch axis and yaw axis reset: Reset the gimbal pitch axis angle to the fine-tuning angle, reset the gimbal yaw axis angle to the sum of the drone yaw axis angle and the gimbal yaw axis fine-tuning angle.
* Reset the gimbal yaw and pitch axes: Reset the gimbal yaw axis angle to the sum of the drone yaw axis and the gimbal fine-tuning angle. Reset the gimbal pitch axis to the sum of -90° and the gimbal fine-tuning angle (gimbal mounted downward), or 90° and the gimbal fine-tuning angle (gimbal mounted upward).
* Reset the gimbal yaw axis to the sum of -90° and the gimbal fine-tuning angle (gimbal mounted downward), or 90° and the gimbal fine-tuning angle (gimbal mounted upward).

### Initialization

Before using the "gimbal control" function, you need to first initialize the gimbal control function module, then register the gimbal control callback functions to the specified interfaces.

```c
djiStat = DjiGimbal_Init();
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("init gimbal module error: 0x%08llX", djiStat);
}
```

```c
djiStat = DjiGimbal_RegCommonHandler(&s_commonHandler);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("gimbal register common handler error: 0x%08llX", djiStat);
}
```

The callback function set is registered as follows:

```c
    s_commonHandler.GetSystemState = GetSystemState;
```

### Status Reporting

To facilitate the user in controlling the gimbal to perform corresponding actions, implement the `GetSystemState` callback interface to report the gimbal state.

```c
static T_DjiReturnCode GetSystemState(T_DjiGimbalSystemState *systemState)
{
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    if (osalHandler->MutexLock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex lock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    *systemState = s_systemState;

    if (osalHandler->MutexUnlock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex unlock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```


### Mode Switch

Developers can adjust the gimbal attitude, target angle, and limit reached flag when the gimbal is in different modes according to **actual usage requirements**.

* In FPV mode:
  * Adjust gimbal attitude: Superimpose the change in drone attitude onto the gimbal's roll axis and yaw axis;
  * Adjust gimbal rotation target angle: When the gimbal rotates, superimpose the drone attitude change onto the gimbal's roll axis and yaw axis.
* In YAW mode:
  * Adjust gimbal attitude: Superimpose the change in drone attitude onto the gimbal's yaw axis;
  * Adjust gimbal rotation target angle: When the gimbal rotates, superimpose the drone attitude change onto the gimbal's yaw axis.
* Adjust the rotation range of the gimbal attitude and target angle, and the payload device can calculate the gimbal's limit reached flag.

```c
switch (s_systemState.gimbalMode) {
    case PSDK_GIMBAL_MODE_FREE:
        break;
    case PSDK_GIMBAL_MODE_FPV:
        s_attitudeInformation.attitude.roll += (s_aircraftAttitude.roll - s_lastAircraftAttitude.roll);
        s_attitudeInformation.attitude.yaw += (s_aircraftAttitude.yaw - s_lastAircraftAttitude.yaw);

        s_attitudeHighPrecision.roll += (float) (s_aircraftAttitude.roll - s_lastAircraftAttitude.roll);
        s_attitudeHighPrecision.yaw += (float) (s_aircraftAttitude.yaw - s_lastAircraftAttitude.yaw);

        if (s_rotatingFlag == true && s_controlType == TEST_GIMBAL_CONTROL_TYPE_ANGLE) {
            s_targetAttitude.roll += (s_aircraftAttitude.roll - s_lastAircraftAttitude.roll);
            s_targetAttitude.yaw += (s_aircraftAttitude.yaw - s_lastAircraftAttitude.yaw);
        }
        break;
    case PSDK_GIMBAL_MODE_YAW_FOLLOW:
        s_attitudeInformation.attitude.yaw += (s_aircraftAttitude.yaw - s_lastAircraftAttitude.yaw);

        s_attitudeHighPrecision.yaw += (float) (s_aircraftAttitude.yaw - s_lastAircraftAttitude.yaw);

        if (s_rotatingFlag == true && s_controlType == TEST_GIMBAL_CONTROL_TYPE_ANGLE) {
            s_targetAttitude.yaw += (s_aircraftAttitude.yaw - s_lastAircraftAttitude.yaw);
        }
        break;
    default:
        PsdkLogger_UserLogError("gimbal mode invalid: %d.", s_systemState.gimbalMode);
}
s_lastAircraftAttitude = s_aircraftAttitude;

attitudeFTemp.pitch = s_attitudeInformation.attitude.pitch;
attitudeFTemp.roll = s_attitudeInformation.attitude.roll;
attitudeFTemp.yaw = s_attitudeInformation.attitude.yaw;
PsdkTest_GimbalAngleLegalization(&attitudeFTemp, s_aircraftAttitude, &s_attitudeInformation.reachLimitFlag);
s_attitudeInformation.attitude.pitch = attitudeFTemp.pitch;
s_attitudeInformation.attitude.roll = attitudeFTemp.roll;
s_attitudeInformation.attitude.yaw = attitudeFTemp.yaw;

PsdkTest_GimbalAngleLegalization(&s_attitudeHighPrecision, s_aircraftAttitude, NULL);

attitudeFTemp.pitch = s_targetAttitude.pitch;
attitudeFTemp.roll = s_targetAttitude.roll;
attitudeFTemp.yaw = s_targetAttitude.yaw;
PsdkTest_GimbalAngleLegalization(&attitudeFTemp, s_aircraftAttitude, NULL);
s_targetAttitude.pitch = attitudeFTemp.pitch;
s_targetAttitude.roll = attitudeFTemp.roll;
s_targetAttitude.yaw = attitudeFTemp.yaw;
```

### Parameter Setting

The gimbal function supports multiple parameter settings through callback functions, including smooth control factor, maximum speed percentage, pitch axis angle range extension, angle fine-tuning, and restore factory settings. These callback functions are registered through `T_DjiGimbalCommonHandler` during initialization, and the SDK automatically calls them when the corresponding control commands are received. For details on each parameter, see [Basic Concepts - Gimbal Control](#gimbal-control).

**Set Smooth Control Factor**

The smooth control factor determines the maximum acceleration of gimbal rotation, with a range of 0~30. Only Pitch and Yaw axes are supported.

```c
static T_DjiReturnCode SetControllerSmoothFactor(uint8_t smoothingFactor, E_DjiGimbalAxis axis)
{
    USER_LOG_INFO("set gimbal controller smooth factor: factor %d, axis %d.", smoothingFactor, axis);
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    if (osalHandler->MutexLock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex lock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    if (axis == DJI_GIMBAL_AXIS_PITCH)
        s_systemState.smoothFactor.pitch = smoothingFactor;
    else if (axis == DJI_GIMBAL_AXIS_YAW)
        s_systemState.smoothFactor.yaw = smoothingFactor;
    else
        USER_LOG_ERROR("axis is not supported.");

    if (osalHandler->MutexUnlock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex unlock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    DjiTest_WidgetLogAppend("set smooth factor: factor %d, axis %d.", smoothingFactor, axis);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

**Set Maximum Speed Percentage**

The maximum speed percentage determines the maximum speed of gimbal rotation, with a range of 1~100. Only Pitch and Yaw axes are supported.

```c
static T_DjiReturnCode SetControllerMaxSpeedPercentage(uint8_t maxSpeedPercentage, E_DjiGimbalAxis axis)
{
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    USER_LOG_INFO("set gimbal controller max speed: max speed %d, axis %d.", maxSpeedPercentage, axis);

    if (osalHandler->MutexLock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex lock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    if (axis == DJI_GIMBAL_AXIS_PITCH)
        s_systemState.maxSpeedPercentage.pitch = maxSpeedPercentage;
    else if (axis == DJI_GIMBAL_AXIS_YAW)
        s_systemState.maxSpeedPercentage.yaw = maxSpeedPercentage;
    else
        USER_LOG_ERROR("axis is not supported.");

    if (osalHandler->MutexUnlock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex unlock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    DjiTest_WidgetLogAppend("set gimbal max speed: %d, axis %d.", maxSpeedPercentage, axis);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

**Enable Pitch Range Extension**

When enabled, the pitch axis Euler angle limit is extended from the default range to a larger range.

```c
static T_DjiReturnCode SetPitchRangeExtensionEnabled(bool enabledFlag)
{
    USER_LOG_INFO("set gimbal pitch range extension enable flag: %d.", enabledFlag);
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    if (osalHandler->MutexLock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex lock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    s_systemState.pitchRangeExtensionEnabledFlag = enabledFlag;

    if (osalHandler->MutexUnlock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex unlock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    DjiTest_WidgetLogAppend("set gimbal pitch range extension enable: %d.", enabledFlag);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

**Restore Factory Settings**

Resets all gimbal parameters to default values: mode is restored to Free mode, fine-tuning angles and smooth factors are cleared to zero, and maximum speed percentage is restored to 1.

```c
static T_DjiReturnCode RestoreFactorySettings(void)
{
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    USER_LOG_INFO("restore gimbal factory settings.");

    if (osalHandler->MutexLock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex lock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    s_systemState.pitchRangeExtensionEnabledFlag = false;
    s_systemState.gimbalMode = DJI_GIMBAL_MODE_FREE;
    memset(&s_systemState.fineTuneAngle, 0, sizeof(s_systemState.fineTuneAngle));
    memset(&s_systemState.smoothFactor, 0, sizeof(s_systemState.smoothFactor));
    s_systemState.maxSpeedPercentage.pitch = 1;
    s_systemState.maxSpeedPercentage.yaw = 1;

    if (osalHandler->MutexUnlock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex unlock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    DjiTest_WidgetLogAppend("restore gimbal factory settings.");

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

**Construct Callback Function to Calculate Gimbal Rotation Speed**

Construct a callback function to calculate the gimbal rotation speed, adjust the gimbal attitude, and record the gimbal's target angle and rotation speed.

```c
T_DjiReturnCode DjiTest_GimbalRotate(E_DjiGimbalRotationMode rotationMode,
                                     T_DjiGimbalRotationProperty rotationProperty,
                                     T_DjiAttitude3d rotationValue)
{
    T_DjiReturnCode djiStat;
    T_DjiReturnCode returnCode = DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
    T_DjiAttitude3d targetAttitudeDTemp = {0};
    T_DjiAttitude3f targetAttitudeFTemp = {0};
    T_DjiAttitude3d speedTemp = {0};
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    USER_LOG_DEBUG("gimbal rotation value invalid flag: pitch %d, roll %d, yaw %d.",
                   rotationProperty.rotationValueInvalidFlag.pitch,
                   rotationProperty.rotationValueInvalidFlag.roll,
                   rotationProperty.rotationValueInvalidFlag.yaw);

    if (osalHandler->MutexLock(s_attitudeMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex lock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    if (osalHandler->MutexLock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex lock error");
        returnCode = DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
        goto out2;
    }

    switch (rotationMode) {
        case DJI_GIMBAL_ROTATION_MODE_RELATIVE_ANGLE:
            USER_LOG_INFO("gimbal relative rotate angle: pitch %d, roll %d, yaw %d.", rotationValue.pitch,
                          rotationValue.roll, rotationValue.yaw);
            USER_LOG_DEBUG("gimbal relative rotate action time: %d.",
                           rotationProperty.relativeAngleRotation.actionTime);

            if (s_rotatingFlag == true) {
                USER_LOG_WARN("gimbal is rotating.");
                goto out1;
            }

            targetAttitudeDTemp.pitch =
                rotationProperty.rotationValueInvalidFlag.pitch == true ? s_attitudeInformation.attitude.pitch : (
                    s_attitudeInformation.attitude.pitch + rotationValue.pitch);
            targetAttitudeDTemp.roll =
                rotationProperty.rotationValueInvalidFlag.roll == true ? s_attitudeInformation.attitude.roll : (
                    s_attitudeInformation.attitude.roll + rotationValue.roll);
            targetAttitudeDTemp.yaw =
                rotationProperty.rotationValueInvalidFlag.yaw == true ? s_attitudeInformation.attitude.yaw : (
                    s_attitudeInformation.attitude.yaw + rotationValue.yaw);

            targetAttitudeFTemp.pitch = targetAttitudeDTemp.pitch;
            targetAttitudeFTemp.roll = targetAttitudeDTemp.roll;
            targetAttitudeFTemp.yaw = targetAttitudeDTemp.yaw;
            DjiTest_GimbalAngleLegalization(&targetAttitudeFTemp, s_aircraftAttitude, NULL);
            targetAttitudeDTemp.pitch = targetAttitudeFTemp.pitch;
            targetAttitudeDTemp.roll = targetAttitudeFTemp.roll;
            targetAttitudeDTemp.yaw = targetAttitudeFTemp.yaw;

            s_targetAttitude = targetAttitudeDTemp;
            s_rotatingFlag = true;
            s_controlType = TEST_GIMBAL_CONTROL_TYPE_ANGLE;

            djiStat = DjiTest_GimbalCalculateSpeed(s_attitudeInformation.attitude, s_targetAttitude,
                                                   rotationProperty.relativeAngleRotation.actionTime, &s_speed);
            if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
                USER_LOG_ERROR("calculate gimbal rotation speed error: 0x%08llX.", djiStat);
                returnCode = djiStat;
                goto out1;
            }

            break;
        case DJI_GIMBAL_ROTATION_MODE_ABSOLUTE_ANGLE:
            USER_LOG_INFO("gimbal absolute rotate angle: pitch %d, roll %d, yaw %d.", rotationValue.pitch,
                          rotationValue.roll, rotationValue.yaw);
            USER_LOG_DEBUG("gimbal absolute rotate action time: %d.",
                           rotationProperty.absoluteAngleRotation.actionTime);
            if (rotationProperty.absoluteAngleRotation.jointAngleValid) {
                USER_LOG_DEBUG("gimbal joint angles: pitch %d, roll %d, yaw %d.",
                               rotationProperty.absoluteAngleRotation.jointAngle.pitch,
                               rotationProperty.absoluteAngleRotation.jointAngle.roll,
                               rotationProperty.absoluteAngleRotation.jointAngle.yaw);
            }

            if (s_rotatingFlag == true) {
                USER_LOG_WARN("gimbal is rotating.");
                goto out1;
            }

            targetAttitudeDTemp.pitch =
                rotationProperty.rotationValueInvalidFlag.pitch == true ? s_attitudeInformation.attitude.pitch
                                                                        : rotationValue.pitch;
            targetAttitudeDTemp.roll =
                rotationProperty.rotationValueInvalidFlag.roll == true ? s_attitudeInformation.attitude.roll
                                                                       : rotationValue.roll;
            targetAttitudeDTemp.yaw =
                rotationProperty.rotationValueInvalidFlag.yaw == true ? s_attitudeInformation.attitude.yaw
                                                                      : rotationValue.yaw;

            targetAttitudeFTemp.pitch = targetAttitudeDTemp.pitch;
            targetAttitudeFTemp.roll = targetAttitudeDTemp.roll;
            targetAttitudeFTemp.yaw = targetAttitudeDTemp.yaw;
            DjiTest_GimbalAngleLegalization(&targetAttitudeFTemp, s_aircraftAttitude, NULL);
            targetAttitudeDTemp.pitch = targetAttitudeFTemp.pitch;
            targetAttitudeDTemp.roll = targetAttitudeFTemp.roll;
            targetAttitudeDTemp.yaw = targetAttitudeFTemp.yaw;

            s_targetAttitude = targetAttitudeDTemp;
            s_rotatingFlag = true;
            s_controlType = TEST_GIMBAL_CONTROL_TYPE_ANGLE;

            djiStat = DjiTest_GimbalCalculateSpeed(s_attitudeInformation.attitude, s_targetAttitude,
                                                   rotationProperty.absoluteAngleRotation.actionTime, &s_speed);
            if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
                USER_LOG_ERROR("calculate gimbal rotation speed error: 0x%08llX.", djiStat);
                returnCode = djiStat;
                goto out1;
            }

            break;
        case DJI_GIMBAL_ROTATION_MODE_SPEED:
            USER_LOG_INFO("gimbal rotate speed: pitch %d, roll %d, yaw %d.", rotationValue.pitch,
                          rotationValue.roll, rotationValue.yaw);

            if (s_rotatingFlag == true && s_controlType == TEST_GIMBAL_CONTROL_TYPE_ANGLE) {
                USER_LOG_WARN("gimbal is rotating.");
                goto out1;
            }

            memcpy(&speedTemp, &rotationValue, sizeof(T_DjiAttitude3d));
            DjiTest_GimbalSpeedLegalization(&speedTemp);
            s_speed = speedTemp;

            if (rotationValue.pitch != 0 || rotationValue.roll != 0 || rotationValue.yaw != 0) {
                s_rotatingFlag = true;
                s_controlType = TEST_GIMBAL_CONTROL_TYPE_SPEED;
            } else {
                s_rotatingFlag = false;
            }

            break;
        default:
            USER_LOG_ERROR("gimbal rotation mode invalid: %d.", rotationMode);
            returnCode = DJI_ERROR_SYSTEM_MODULE_CODE_NONSUPPORT;
            goto out1;
    }

out1:
    if (osalHandler->MutexUnlock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex unlock error");
        returnCode = DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
        goto out2;
    }

out2:
    if (osalHandler->MutexUnlock(s_attitudeMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex unlock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    return returnCode;
}
```

**Control Gimbal Rotation**

The payload device converts the relative angle control value, absolute angle control value, or speed control value into the speed for controlling gimbal rotation based on the gimbal's attitude and rotation speed, and controls the gimbal rotation according to that speed, as shown in Figure 3.

```c
nextAttitude.pitch =
            (float) s_attitudeHighPrecision.pitch + (float) s_speed.pitch / (float) PAYLOAD_GIMBAL_TASK_FREQ;
        nextAttitude.roll =
            (float) s_attitudeHighPrecision.roll + (float) s_speed.roll / (float) PAYLOAD_GIMBAL_TASK_FREQ;
        nextAttitude.yaw = (float) s_attitudeHighPrecision.yaw + (float) s_speed.yaw / (float) PAYLOAD_GIMBAL_TASK_FREQ;

        if (s_controlType == TEST_GIMBAL_CONTROL_TYPE_ANGLE) {
            nextAttitude.pitch =
                (nextAttitude.pitch - s_targetAttitude.pitch) * s_speed.pitch >= 0 ? s_targetAttitude.pitch
                                                                                    : nextAttitude.pitch;
            nextAttitude.roll = (nextAttitude.roll - s_targetAttitude.roll) * s_speed.roll >= 0 ? s_targetAttitude.roll
                                                                                                 : nextAttitude.roll;
            nextAttitude.yaw =
                (nextAttitude.yaw - s_targetAttitude.yaw) * s_speed.yaw >= 0 ? s_targetAttitude.yaw : nextAttitude.yaw;
        }

        DjiTest_GimbalAngleLegalization(&nextAttitude, s_aircraftAttitude, &s_attitudeInformation.reachLimitFlag);
        s_attitudeInformation.attitude.pitch = nextAttitude.pitch;
        s_attitudeInformation.attitude.roll = nextAttitude.roll;
        s_attitudeInformation.attitude.yaw = nextAttitude.yaw;

        s_attitudeHighPrecision.pitch = nextAttitude.pitch;
        s_attitudeHighPrecision.roll = nextAttitude.roll;
        s_attitudeHighPrecision.yaw = nextAttitude.yaw;

        if (s_controlType == TEST_GIMBAL_CONTROL_TYPE_ANGLE) {
            if (memcmp(&s_attitudeInformation.attitude, &s_targetAttitude, sizeof(T_DjiAttitude3d)) == 0) {
                s_rotatingFlag = false;
            }
        } else if (s_controlType == TEST_GIMBAL_CONTROL_TYPE_SPEED) {
            if ((s_attitudeInformation.reachLimitFlag.pitch == true || s_speed.pitch == 0) &&
                (s_attitudeInformation.reachLimitFlag.roll == true || s_speed.roll == 0) &&
                (s_attitudeInformation.reachLimitFlag.yaw == true || s_speed.yaw == 0)) {
                s_rotatingFlag = false;
            }
        }
```

### Calibration

To facilitate users in controlling the gimbal more accurately, it is **recommended** that developers implement the gimbal calibration function when developing payload devices with gimbal capability.

<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/gimbal-function/gimbal_calibration_en.svg" width="40%" alt="Gimbal Calibration Flow"/></span></p>
</div>

When the user triggers calibration in the App, the SDK calls the `StartCalibrate` callback. The background task continuously calculates progress within 2000ms and reports it via `GetCalibrationState`. After completion, the calibration is marked as finished.

**Trigger Calibration**

To use the gimbal calibration function, please first implement the gimbal calibration function, and register the gimbal calibration function to the specified interface, so that users can calibrate the gimbal-capable payload device using DJI Pilot or the Mobile App developed based on MSDK.

```c
static T_PsdkReturnCode StartCalibrate(void)
{
    T_PsdkReturnCode psdkStat;

    PsdkLogger_UserLogDebug("start calibrate gimbal.");

    psdkStat = PsdkOsal_GetTimeMs(&s_calibrationStartTime);
    if (psdkStat != PSDK_RETURN_CODE_OK) {
        PsdkLogger_UserLogError("get start time error: %lld.", psdkStat);
    }

    if (PsdkOsal_MutexLock(s_calibrationMutex) != PSDK_RETURN_CODE_OK) {
        PsdkLogger_UserLogError("mutex lock error");
        return PSDK_RETURN_CODE_ERR_UNKNOWN;
    }

    s_calibrationState.calibratingFlag = true;
    s_calibrationState.progress = 0;
    s_calibrationState.stage = PSDK_GIMBAL_CALIBRATION_STAGE_PROCRESSING;

    if (PsdkOsal_MutexUnlock(s_calibrationMutex) != PSDK_RETURN_CODE_OK) {
        PsdkLogger_UserLogError("mutex unlock error");
        return PSDK_RETURN_CODE_ERR_UNKNOWN;
    }

    return PSDK_RETURN_CODE_OK;
}
```
**Calibration State Update**

After the payload device performs the gimbal calibration, it records the calibration state. The Mobile App developed based on MSDK can obtain the calibration state of the gimbal.

```c
 // calibration
        if (s_calibrationState.calibratingFlag != true)
            goto unlockCalibrationMutex;

        progressTemp = (currentTime - s_calibrationStartTime) * 100 / PAYLOAD_GIMBAL_CALIBRATION_TIME_MS;
        if (progressTemp >= 100) {
            s_calibrationState.calibratingFlag = false;
            s_calibrationState.currentCalibrationProgress = 100;
            s_calibrationState.currentCalibrationStage = PSDK_GIMBAL_CALIBRATION_STAGE_COMPLETE;
        }

unlockCalibrationMutex:
        if (PsdkOsal_MutexUnlock(s_calibrationMutex) != PSDK_RETURN_CODE_OK) {
            PsdkLogger_UserLogError("mutex unlock error");
            continue;
        }
```

### Reset

The SDK calls the `Reset` callback based on the reset mode. Different modes reset different axes and target angles. After the reset is complete, angle legalization is performed and the current rotation is stopped.

<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/gimbal-function/gimbal_reset_en.svg" width="60%" alt="Gimbal Reset Flow"/></span></p>
</div>

Example code:
```c
static T_DjiReturnCode Reset(E_DjiGimbalResetMode mode)
{
    T_DjiReturnCode djiReturnCode = DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
    T_DjiAttitude3f attitudeFTemp = {0};
    T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();

    USER_LOG_INFO("reset gimbal: %d.", mode);

    if (osalHandler->MutexLock(s_attitudeMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex lock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    if (osalHandler->MutexLock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex lock error");
        djiReturnCode = DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
        goto unlock2;
    }

    switch (mode) {
        case DJI_GIMBAL_RESET_MODE_YAW:
            s_attitudeInformation.attitude.yaw = s_aircraftAttitude.yaw + s_systemState.fineTuneAngle.yaw;
            s_attitudeHighPrecision.yaw = s_aircraftAttitude.yaw + s_systemState.fineTuneAngle.yaw;
            break;
        case DJI_GIMBAL_RESET_MODE_PITCH_AND_YAW:
            s_attitudeInformation.attitude.pitch = s_systemState.fineTuneAngle.pitch;
            s_attitudeInformation.attitude.yaw = s_aircraftAttitude.yaw + s_systemState.fineTuneAngle.yaw;
            s_attitudeHighPrecision.pitch = s_systemState.fineTuneAngle.pitch;
            s_attitudeHighPrecision.yaw = s_aircraftAttitude.yaw + s_systemState.fineTuneAngle.yaw;
            break;
        case DJI_GIMBAL_RESET_MODE_PITCH_DOWNWARD_UPWARD_AND_YAW:
            s_attitudeInformation.attitude.pitch =
                s_systemState.fineTuneAngle.pitch + (s_systemState.mountedUpward ? 900 : -900);
            s_attitudeInformation.attitude.yaw = s_aircraftAttitude.yaw + s_systemState.fineTuneAngle.yaw;
            s_attitudeHighPrecision.pitch =
                s_systemState.fineTuneAngle.pitch + (s_systemState.mountedUpward ? 900 : -900);
            s_attitudeHighPrecision.yaw = s_aircraftAttitude.yaw + s_systemState.fineTuneAngle.yaw;
            break;
        case DJI_GIMBAL_RESET_MODE_PITCH_DOWNWARD_UPWARD:
            s_attitudeInformation.attitude.pitch =
                s_systemState.fineTuneAngle.pitch + (s_systemState.mountedUpward ? 900 : -900);
            s_attitudeHighPrecision.pitch =
                s_systemState.fineTuneAngle.pitch + (s_systemState.mountedUpward ? 900 : -900);
            break;
        default:
            USER_LOG_ERROR("reset mode is invalid: %d.", mode);
            djiReturnCode = DJI_ERROR_SYSTEM_MODULE_CODE_INVALID_PARAMETER;
            goto unlock1;
    }

    // Angle legalization and stop rotation
    attitudeFTemp.pitch = s_attitudeInformation.attitude.pitch;
    attitudeFTemp.roll = s_attitudeInformation.attitude.roll;
    attitudeFTemp.yaw = s_attitudeInformation.attitude.yaw;
    DjiTest_GimbalAngleLegalization(&attitudeFTemp, s_aircraftAttitude, &s_attitudeInformation.reachLimitFlag);
    s_attitudeInformation.attitude.pitch = attitudeFTemp.pitch;
    s_attitudeInformation.attitude.roll = attitudeFTemp.roll;
    s_attitudeInformation.attitude.yaw = attitudeFTemp.yaw;
    DjiTest_GimbalAngleLegalization(&s_attitudeHighPrecision, s_aircraftAttitude, NULL);

    s_rotatingFlag = false;

unlock1:
    if (osalHandler->MutexUnlock(s_commonMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex unlock error");
        djiReturnCode = DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
        goto unlock2;
    }

unlock2:
    if (osalHandler->MutexUnlock(s_attitudeMutex) != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("mutex unlock error");
        return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    return djiReturnCode;
}
```
