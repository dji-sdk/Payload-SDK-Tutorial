## Overview
In order to meet the positioning requirements of payload devices developed using PSDK for centimeter-level accuracy, DJI supports developers to use reference stations (such as D-RTK 2) and mobile stations, with RTK (Real Time Kinematic, real-time dynamic carrier phase difference technology) to obtain drone flight attitude and high-precision positioning information.

:::tip Note:
Before running the "Precise Positioning" sample code, please use the APP developed by DJI Pilot or MSDK to check the good communication status between the drone and RTK satellites to ensure that the payload device can obtain accurate positioning results, as shown in Figure 1. RTK Signal Status.
:::

## Basic Concepts

### Terminology Explanation
* Target point: The position where the positioning information is actually obtained, such as the center point of the gimbal port.
  :::tip Note:
  - On Matrice 300 RTK, the target point is the center point of the upper surface of the payload device adapter ring, and the payload device needs to be mounted on the drone No. 1 gimbal.
  - On Matrice 400, the target point is the center point of the upper surface of the payload adapter ring, and access via SkyPort V2/SkyPort V3 is supported on ports E1 and E2.
  ::: 
* Point of interest: The position of a device on the payload device arbitrarily specified by the user, such as the center point of the camera image sensor. The target point can also be a point of interest.
* Mission: A collection of multiple continuous flight actions is called a mission, such as a surveying and mapping mission for a certain area. Users can create multiple tasks according to actual usage needs.
* Positioning event: An event that triggers a positioning request. For example, a positioning request is triggered when the camera is exposed, and "camera exposure" is a positioning event; a collection of multiple events is an event collection. A payload device developed using PSDK can request position information at the time of multiple positioning events simultaneously, such as camera co-exposure.

### Get Precise Positioning

:::tip Note:
 When obtaining precise positioning, you need to use the time synchronization function to synchronize the local time of the payload device to the drone time. For details on using the time synchronization function, please refer to <a href="../basic-function/time-syn.html" target="_blank" rel="noopener noreferrer">Time Synchronization</a>.   
:::

The process of obtaining precise positioning is as follows:

1. When a positioning event occurs, the payload device needs to record the local time (this time is the time on the payload device);
2. The payload device converts the time on the payload device to the time on the drone through the time conversion function;
3. The payload device requests the location using the drone time (the time of the drone system) at the time of the positioning event.

:::tip Note:
 The drone time (the time of the drone system) when the positioning event occurs should be earlier than the rising edge time of the latest PPS signal, and the time interval must be within 1~2s, as shown in Figure 2. Get Precise Positioning.   
:::

## Implementation

:::warning Caution:
 The following code is for reference only, intended to help developers understand the calling process and implementation approach of each function. Developers can adapt and adjust according to the actual hardware characteristics and application scenarios of their payload devices.
:::

### Initialization
Before using the "Precise Positioning" function, you need to initialize the precise positioning function module to ensure that the precise positioning function can operate normally.  

```c
djiStat = DjiPositioning_Init();
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("positioning module init error.");
    return djiStat;
}
```

### Set Task Index
**Recommended** to use the task index function, which is convenient for users to quickly find the position request information in the Mark file (when the task index is not set, the default value of the task index is 0).

```c
DjiPositioning_SetTaskIndex(0);
```

### Receive RTCM Data
Register the callback function for receiving RTK RTCM raw data, supporting both aircraft-side RTK and base station RTK data types.

```c
djiStat = DjiPositioning_RegReceiveRtcmDataCallback(DJI_POSITIONING_RTCM_DATA_TYPE_RTK_BASE_STATION,
                                                    DjiTest_ReceiveRtkBaseStationRtcmDataCallback);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Register receive rtk base station callback error.");
    return djiStat;
}

djiStat = DjiPositioning_RegReceiveRtcmDataCallback(DJI_POSITIONING_RTCM_DATA_TYPE_RTK_ON_AIRCRAFT,
                                                    DjiTest_ReceiveRtkOnAircraftRtcmDataCallback);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Register receive rtk on aircraft callback error.");
    return djiStat;
}
```

### Get Position Information
After the user triggers the precise positioning function, the payload device will obtain precise positioning information according to the time when the positioning event occurs.

#### Get local time      
After the user triggers the precise positioning function, the payload device obtains the local time on the payload device when the PPS signal is triggered.

```c
djiStat = DjiTest_TimeSyncGetNewestPpsTriggerLocalTimeUs(&ppsNewestTriggerTimeUs);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("get newest pps trigger time error: 0x%08llX.", djiStat);
    continue;
}
```

#### Time conversion     
Converts the local time on the payload device at the time of the specified positioning event to the time of the drone system.

```c
for (i = 0; i < DJI_TEST_POSITIONING_EVENT_COUNT; ++i) {
    eventInfo[i].eventSetIndex = s_eventIndex;
    eventInfo[i].targetPointIndex = i;

    djiStat = DjiTimeSync_TransferToAircraftTime(
        ppsNewestTriggerTimeUs - 1000000 - i * DJI_TEST_TIME_INTERVAL_AMONG_EVENTS_US, &aircraftTime);
    if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("transfer to aircraft time error: 0x%08llX.", djiStat);
        continue;
    }

    eventInfo[i].eventTime = aircraftTime;
}
```

#### Obtain precise positioning information      
After the time synchronization is completed, the user can obtain and print the precise location of the payload device at a certain moment. The detailed location information of the payload device is shown in Figure 3. Positioning Details.

```c
djiStat = DjiPositioning_GetPositionInformationSync(DJI_TEST_POSITIONING_EVENT_COUNT, eventInfo, positionInfo);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("get position information error.");
    continue;
}

USER_LOG_DEBUG("request position of target points success.");
USER_LOG_DEBUG("detail position information:");
for (i = 0; i < DJI_TEST_POSITIONING_EVENT_COUNT; ++i) {
    USER_LOG_DEBUG("position solution property: %d.", positionInfo[i].positionSolutionProperty);
    USER_LOG_DEBUG("pitchAttitudeAngle: %d\trollAttitudeAngle: %d\tyawAttitudeAngle: %d",
                   positionInfo[i].uavAttitude.pitch, positionInfo[i].uavAttitude.roll,
                   positionInfo[i].uavAttitude.yaw);
    USER_LOG_DEBUG("northPositionOffset: %d\tearthPositionOffset: %d\tdownPositionOffset: %d",
                   positionInfo[i].offsetBetweenMainAntennaAndTargetPoint.x,
                   positionInfo[i].offsetBetweenMainAntennaAndTargetPoint.y,
                   positionInfo[i].offsetBetweenMainAntennaAndTargetPoint.z);
    USER_LOG_DEBUG("longitude: %.8f\tlatitude: %.8f\theight: %.8f",
                   positionInfo[i].targetPointPosition.longitude,
                   positionInfo[i].targetPointPosition.latitude,
                   positionInfo[i].targetPointPosition.height);
    USER_LOG_DEBUG(
        "longStandardDeviation: %.8f\tlatStandardDeviation: %.8f\thgtStandardDeviation: %.8f",
        positionInfo[i].targetPointPositionStandardDeviation.longitude,
        positionInfo[i].targetPointPositionStandardDeviation.latitude,
        positionInfo[i].targetPointPositionStandardDeviation.height);
}

s_eventIndex++;
```
