## Overview
Time synchronization is a function for synchronizing the time of the payload device and the time of the drone. PSDK synchronizes the time of the payload device and the **RTK-capable drone** through the PPS signal (periodic pulse). The payload device with the "time synchronization" function can facilitate users to smoothly use the log to troubleshoot various faults during the flight of the drone, analyze the data sampled by the sensor, and obtain accurate positioning information.

:::tip Note:
- Drone Time: The time of the drone system.
- Local Time: The time on the payload device.
- Before using the time synchronization function, please use the Mobile App to confirm that the drone and RTK satellite maintain a good communication status; the Mobile App can be an App released by DJI, such as DJI Pilot, or a Mobile App developed based on MSDK, as shown in Figure 1. Viewing satellite communication status.
:::

## Basic Concepts

### Time Synchronization Principle

After the payload device developed using PSDK installed on the drone is powered on, the time synchronization function module will be initialized to eliminate the clock difference between the payload device and the drone, and synchronize the time of the payload device and the drone.

1. Install the payload device on the gimbal of the drone. After the drone is powered on, the payload device developed using PSDK will receive the PPS hardware pulse signal sent by the drone;
2. When the payload device detects the rising edge of the PPS signal, the payload device needs to record the local time on the payload device;
3. The underlying handler of the PSDK will get the time on the UAS that is synchronized with the PPS signal.
    :::warning Caution:
    * Please ensure that the delay between the rising edge of the PPS signal reaching the payload and the payload recording the local time is less than 1ms.
    * Please use the form of hardware interrupt to implement the response to PPS signal.
    :::
4. The underlying processing program of PSDK will calculate the clock difference between the local time of the payload device and the time of the drone system, so as to realize the synchronization of the time between the payload device and the drone system.  
5. The payload device converts the local time of the payload device to the time on the drone system through the `DjiTimeSync_TransferToAircraftTime` interface.
6. Leap seconds change over time. Developers can choose whether to implement compensation to fix the time gap or not. Check the table below for different models.

## Implementation

:::warning Caution:
The following code is for reference only, intended to help developers understand the calling process and implementation approach of each function. Developers can adapt and adjust according to the actual hardware characteristics and application scenarios of their payload devices.
:::


### Initialization

To use the time synchronization function, the time synchronization module needs to be initialized first.

```c
djiStat = DjiTimeSync_Init();
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("time synchronization module init error.");
    return djiStat;
}
```

### PPS Signal Configuration

The payload device needs to respond to the PPS time synchronization signal pushed by the drone by means of hardware interrupt, and register the callback function for getting PPS trigger time to the SDK.

#### Configure PPS Pin Parameters

Set the various parameters of the PPS pin, enable the function of the PPS hardware pin to receive the PPS time synchronization signal.

```c
T_DjiReturnCode DjiTest_PpsSignalResponseInit(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    /* Enable GPIOD clock */
    __HAL_RCC_GPIOD_CLK_ENABLE();

    /* Configure pin as input floating */
    GPIO_InitStructure.Mode = GPIO_MODE_IT_RISING;
    GPIO_InitStructure.Pull = GPIO_NOPULL;
    GPIO_InitStructure.Pin = PPS_PIN;
    HAL_GPIO_Init(PPS_PORT, &GPIO_InitStructure);

    /* Enable and set EXTI Line Interrupt to the lowest priority */
    HAL_NVIC_SetPriority(PPS_IRQn, PPS_IRQ_PRIO_PRE, PPS_IRQ_PRIO_SUB);
    HAL_NVIC_EnableIRQ(PPS_IRQn);

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

#### Implement PPS Interrupt Handler

The developer needs to implement the hardware interrupt processing function and register the hardware interrupt processing function to the specified interface. When the payload device receives the rising edge of the PPS signal, the hardware interrupt processing function will record the local time on the payload device for subsequent time synchronization calculation.

```c
void DjiTest_PpsIrqHandler(void)
{
    T_DjiReturnCode psdkStat;
    uint32_t timeMs = 0;

    /* EXTI line interrupt detected */
    if (__HAL_GPIO_EXTI_GET_IT(PPS_PIN) != RESET) {
        __HAL_GPIO_EXTI_CLEAR_IT(PPS_PIN);
        psdkStat = Osal_GetTimeMs(&timeMs);
        if (psdkStat == DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS)
            s_ppsNewestTriggerLocalTimeMs = timeMs;
    }
}
```

#### Implement and Register the PPS Trigger Time Callback

The developer needs to implement the function of obtaining the local time on the payload device when the PPS signal is triggered. When the payload device receives the rising edge of the PPS signal, the payload device control program developed based on PSDK can record the local time on the payload device when the PPS signal is triggered.

```c
T_DjiReturnCode DjiTest_GetNewestPpsTriggerLocalTimeUs(uint64_t *localTimeUs)
{
    if (localTimeUs == NULL) {
        USER_LOG_ERROR("input pointer is null.");
        return DJI_ERROR_SYSTEM_MODULE_CODE_INVALID_PARAMETER;
    }

    if (s_ppsNewestTriggerLocalTimeMs == 0) {
        USER_LOG_WARN("pps have not been triggered.");
        return DJI_ERROR_SYSTEM_MODULE_CODE_BUSY;
    }

    *localTimeUs = (uint64_t) (s_ppsNewestTriggerLocalTimeMs * 1000);

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

After implementing the above callback function, it needs to be registered in the payload device control program. After registration, when the payload device receives the rising edge of the PPS signal, the PSDK underlying handler can obtain the local time of the payload device when the PPS signal is triggered through this callback.

```c
// users must register getNewestPpsTriggerTime callback function
djiStat = DjiTimeSync_RegGetNewestPpsTriggerTimeCallback(s_timeSyncHandler.GetNewestPpsTriggerLocalTimeUs);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("register GetNewestPpsTriggerLocalTimeUsCallback error.");
    return djiStat;
}
```

### Time Conversion

The payload device control program developed using PSDK gets the local time on the payload device through `osalHandler->GetTimeMs` and converts the local time of the payload device to the time on the drone system through `DjiTimeSync_TransferToAircraftTime`.

```c
djiStat = osalHandler->GetTimeMs(&currentTimeMs);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("get current time error: 0x%08llX.", djiStat);
    continue;
}

djiStat = DjiTimeSync_TransferToAircraftTime(currentTimeMs * 1000, &aircraftTime);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("transfer to aircraft time error: 0x%08llX.", djiStat);
    continue;
}

USER_LOG_INFO("current aircraft time is %04d-%02d-%02d %02d:%02d:%02d %d.",
              aircraftTime.year, aircraftTime.month, aircraftTime.day,
              aircraftTime.hour, aircraftTime.minute, aircraftTime.second, aircraftTime.microsecond);
```
