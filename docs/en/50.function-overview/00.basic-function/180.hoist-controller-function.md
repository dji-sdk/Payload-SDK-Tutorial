## Overview

Built on a third-party PSDK payload paired with the DJI Aerial Hoist 2.0 system, this solution enables control of the hoist system and provides real-time status feedback. The hoist system consists of a winch and an active hook. Developers can use PSDK APIs to independently control the winch's cable pay-out/reel-in, the active hook's open/close actions, and retrieve the hoist operational status.

:::tip Note:
* Currently only supported on FlyCart 100.
* Applicable Configuration: 1 E-Port Lite port (PSDK) and 1 FlyCart 100 aircraft.
* Supported Capabilities: Through the E-Port Lite port (PSDK), you can control the hoist system and the simple hoist, and retrieve status data including weight measurements for both the hoist system and simple hoist.
* Constraints: Payload-based hoist control and complex status retrieval are not supported.
:::

## Basic Concepts

### Hoist Types

The hoist system supports two types:
- **Standard Hoist**: Supports winch control, hook control, and full status retrieval.
- **Simple Hoist**: Only supports force and angle status retrieval.

When requesting the flight controller to push hoist information, the API returns the currently connected hoist type. Developers should call the corresponding control and status retrieval APIs based on the hoist type.

### Winch Control

The winch supports control commands including pay-out, reel-in, stop, maintenance, and escape. See the `E_DjiHoistControllerCmdStatus` enum definition in the header file for details.

### Active Hook Control

The active hook supports open and close control commands. See the `E_DjiHookControllerCmdStatus` enum definition in the header file for details.

## Implementation

:::warning Warning:
The following code is provided as reference examples to help developers understand the calling process and implementation approach for each feature. Developers can adapt and adjust according to their own payload device hardware characteristics and application scenarios.
:::

### Initialization

Before using the hoist control feature, initialize the hoist control module first. It is recommended to use the model retrieval function to confirm whether the current aircraft supports hoist control.

```c
// Initialize the hoist control module
returnCode = DjiHoistControllerManagement_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Hoist controller management init error: 0x%08llX", returnCode);
    return returnCode;
}

// Confirm aircraft model information
returnCode = DjiAircraftInfo_GetBaseInfo(&aircraftBaseInfo);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get aircraft base info error");
    return returnCode;
}
```

### Request Control

Start task execution (recommended not to exceed 10 Hz), and request the flight controller to start pushing hoist information. The API returns the currently connected hoist type (standard hoist or simple hoist). Developers should call the corresponding control and status retrieval APIs based on the hoist type.

:::tip Note:
The hoist system can only be controlled after takeoff via the APP simulator. Ground-state control is not supported.
:::

```c
djiStat = psdk_HoistController_NotifyFlight_to_startPushInfo();
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("get hoist can start controller error: 0x%08llX.", djiStat);
    continue;
}
```

### Winch Control

Use `psdk_hoistControllerCmdAction()` to send winch control commands, supporting pay-out, reel-in, stop, maintenance, and escape operations. Only the standard hoist type supports winch control.

```c
// Send winch control commands (pay-out / reel-in / stop / maintenance / escape)
djiStat = psdk_hoistControllerCmdAction(DJI_HOIST_CARGO_RELEASE_CMD);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("hoist controller cmd action error: 0x%08llX.", djiStat);
}
```

### Hook Control

Use `psdk_hookControllerCmdAction()` to send active hook control commands, supporting open and close operations. Only the standard hoist type supports hook control.

```c
// Send active hook control commands (open hook / close hook)
djiStat = psdk_hookControllerCmdAction(DJI_HOOK_CARGO_OPEN_HOOK);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("hook controller cmd action error: 0x%08llX.", djiStat);
}
```

### Simple Hoist Escape

Use `psdk_simpleHoistEscapeCmdAction()` to send the simple hoist escape command. Only the simple hoist type supports this operation.

```c
djiStat = psdk_simpleHoistEscapeCmdAction(DJI_SIMPLE_HOIST_ESCAPE_CMD);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("simple hoist escape cmd action error: 0x%08llX.", djiStat);
}
```

### Status Retrieval

Call the corresponding status retrieval APIs based on the hoist type. Standard hoist supports retrieving winch status and hook status, while simple hoist supports retrieving force sensor and angle status. Additionally, use `DjiHoistController_flightAvoidStatus()` to get flight obstacle avoidance status (up to 10 Hz).

**Standard Hoist Status Retrieval**

```c
// Get winch status
djiStat = DjiHoistController_hoistStatus(&hoist_status);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    return djiStat;
}

USER_LOG_INFO("hoist status:cab_s:%d ,can_s:%d, g_w:%d, mg_w:%d, c_s_s:%d, cc_l:%d",
    hoist_status.cable_state, hoist_status.can_status, hoist_status.goods_weight, hoist_status.max_goods_weight,
    hoist_status.cargo_swing_speed, hoist_status.cur_cable_length);
USER_LOG_INFO("hoist status: c_f:%d, c_an:%d, is_r_t:%d, is_rmr:%d, cdcs:%d",
    hoist_status.cable_force, hoist_status.cable_angle, hoist_status.is_reach_top, hoist_status.is_reach_max_round,
    hoist_status.cable_direction_check_state);

// Get hook status
djiStat = DjiHoistController_hookStatus(&hook_status);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    return djiStat;
}

USER_LOG_INFO("hook status: steer_state:%d, weight:%d, warning:%d",
    hook_status.steer_state, hook_status.cargo_weight, hook_status.cargo_warnig);
USER_LOG_INFO("hook status: error:%d, ctr_state:%d", hook_status.cargo_error, hook_status.ctrl_state);
```

**Simple Hoist Status Retrieval**

```c
psdk_receive_simple_hoist_status_t simple_hoist_status;

djiStat = DjiHoistController_simpleHoistStatus(&simple_hoist_status);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    return djiStat;
}

USER_LOG_INFO("simple hoist status: f_kg:%d, angle_z:%d",
    simple_hoist_status.force_kg, simple_hoist_status.angle_deg);
```

**Flight Obstacle Avoidance Status Retrieval**

```c
psdk_receive_avoid_status_t avoid_status;

djiStat = DjiHoistController_flightAvoidStatus(&avoid_status);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    return djiStat;
}

USER_LOG_INFO("avoid status: is_cargo_avoid:%d, is_avoid_stop_finish:%d, is_start_avoid:%d",
    avoid_status.is_cargo_avoid, avoid_status.is_avoid_stop_finish, avoid_status.is_start_avoid);
```
