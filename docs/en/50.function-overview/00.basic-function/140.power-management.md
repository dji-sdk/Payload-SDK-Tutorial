## Overview

After the payload device developed based on PSDK is installed on the gimbal of the drone, the payload device can obtain higher power through power application. Therefore, the payload device using high power must support the use of low power at the same time; In case of data loss or accidental damage due to shutdown preparation, PSDK also provides the function of sending shutdown notifications.

:::tip Notes:
Before a payload device requests high power, ensure that the hardware meets the following conditions:
- **Matrice 5TD**: No manual high-voltage request is needed. When the aircraft's payload port detects that a third-party payload is connected, it outputs high voltage directly through the VCC pin of the E-Port V3 port (6S voltage, 20-26V).
- **Matrice 350 RTK / Matrice 300 RTK**: When requesting high power, the **HIGH_POWER_APPLY** pin (Pin 22) must be pulled high.
- **Matrice 400**: When requesting high power, the **HIGH_PWR_REQ** pin (Pin 36) must be pulled low.
- **FlyCart 200**: When requesting 24V, the payload device must be connected to the PSDK2 port (right port). The PSDK1 port (left port) supports 24V only when the standard speaker is connected; otherwise, it supports only 13.6V and 17V.
:::

## Implementation

:::warning Warning:
The following code snippets are reference examples intended to help developers understand the calling process and implementation approach for each function. Developers should adapt and adjust them according to the actual hardware characteristics and application scenarios of their payload devices.
:::

### Initialization

Before using the power management functions, you need to initialize the power management module and the pins used for applying high power on the payload device.

```c
static T_PsdkReturnCode PsdkTest_HighPowerApplyPinInit(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_AHB1PeriphClockCmd(HIGH_POWER_APPLY_RCC, ENABLE);

    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_OUT;
    GPIO_InitStructure.GPIO_PuPd = GPIO_PuPd_DOWN;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_100MHz;

    GPIO_InitStructure.GPIO_Pin = HIGH_POWER_APPLY_PIN;
    GPIO_Init(HIGH_POWER_APPLY_Port, &GPIO_InitStructure);

    return PSDK_RETURN_CODE_OK;
}
```

:::tip Note:
 Please implement the function of initializing the application for high-power pins according to the library supported by the selected development platform.
:::

### High Power Application

Developers need to first develop and register a callback function to change the pin level state, and then call the high power application interface.

#### Develop a Function to Change the Pin Level State

After the developer develops the function of changing the pin level state of the payload device, it is necessary to register the function of changing the pin level state of the payload device into the specified interface.

```c
T_DjiReturnCode DjiTest_WriteHighPowerApplyPin(E_DjiPowerManagementPinState pinState)
{
    GPIO_PinState state;

    switch (pinState) {
        case DJI_POWER_MANAGEMENT_PIN_STATE_RESET:
            state = GPIO_PIN_RESET;
            break;
        case DJI_POWER_MANAGEMENT_PIN_STATE_SET:
            state = GPIO_PIN_SET;
            break;
        default:
            USER_LOG_ERROR("pin state unknown: %d.", pinState);
            return DJI_ERROR_SYSTEM_MODULE_CODE_UNKNOWN;
    }

    HAL_GPIO_WritePin(HIGH_POWER_APPLY_PORT, HIGH_POWER_APPLY_PIN, state);

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

#### Register a Function to Change the Pin Level State

After registering the function to change the pin level state of the payload device, the user can control the payload device to change the pin level state.

```c
returnCode = DjiPowerManagement_RegWriteHighPowerApplyPinCallback(s_applyHighPowerHandler.pinWrite);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("register WriteHighPowerApplyPinCallback error.");
    return returnCode;
}
```

#### Apply for High Power

After the payload device calls the `DjiPowerManagement_ApplyHighPowerSync()` interface, the payload device can apply for high power from the drone. After the high power application is completed, you can use a voltmeter or other instruments to measure the voltage of the SkyPort v2 and X-Port designated interfaces.

```c
returnCode = DjiPowerManagement_ApplyHighPowerSync();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("apply high power error");
    return returnCode;
}
```

If the payload device is connected to the E-Port V2 port via a SkyPort V3 adapter ring or an E-Port V2 coaxial cable, you can call `DjiPowerManagement_ApplyHighPowerSyncV2()` to specify the high-power voltage level:

| Voltage Level | Enum Value |
|---------------|------------|
| 13.6V | E_DJI_HIGH_POWER_VOLTAGE_13V6 |
| 17V | E_DJI_HIGH_POWER_VOLTAGE_17V |
| 24V | E_DJI_HIGH_POWER_VOLTAGE_24V |

```c
returnCode = DjiPowerManagement_ApplyHighPowerSyncV2(E_DJI_HIGH_POWER_VOLTAGE_17V);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("apply high power V2 error");
    return returnCode;
}
```

#### High-Voltage Output (Manifold 3)

DJI Manifold 3 connected to the M4 series drone E-Port/E-Port V2 interface supports enabling high-voltage output on the rear Type-C port through the PSDK API. When high-voltage output is enabled, do not connect standard USB peripherals such as USB flash drives, as this may cause damage.

:::warning Warning:
Before calling `DjiPowerManagement_OutputHighPower(true)`, you must first pull down **GPIO12** on the rear Type-C interface of Manifold 3. This pin corresponds to pins **A8/B8 (SBU1/SBU2)** of the Type-C connector. The system allows high-voltage output only when GPIO12 is at a low level.
:::

Use `T_DjiReturnCode DjiPowerManagement_OutputHighPower(bool stat);`

- `true`: output high voltage
- `false`: output low voltage

The rear Type-C port of Manifold 3 has a hardware current limit of 2.75 A for external output. The supported output voltages vary by aircraft model:

| Aircraft Model | Output Voltage | Output Current Limit |
|----------------|----------------|----------------------|
| Matrice 400 | 14V | 2.75 A |
| Matrice 4E/4T | 12.8V–17V | 2.75 A |
| Matrice 4D/4TD | 16.8V–25.5V | 2.75 A |

### Shutdown Notification

The process of sending a shutdown notification from the drone is as follows:
* When the drone receives the shutdown notification sent by the user, the drone will send a shutdown notification to the payload developed using PSDK;
* When the payload device receives the shutdown notification sent by the drone, the payload device will complete the operations that need to be performed before shutdown, and change the shutdown preparation state;
* When the drone obtains the status of all payload devices being ready to shut down, it will shut down immediately.

:::warning Warning:
 After receiving the shutdown notification for a period of time, the drone will be forced to shut down. For the specific forced shutdown time, please refer to the corresponding product model <a href="https://www.dji.com/products/enterprise?site=enterprise&from=nav">Instructions</a>.
:::

#### Construct Shutdown State Callback Function

After the developer develops the function for the payload device to perform shutdown preparation, the developer needs to register the function in the specified interface.

```c
static T_DjiReturnCode DjiTest_PowerOffNotificationCallback(bool *powerOffPreparationFlag)
{
    USER_LOG_INFO("aircraft will power off soon.");

    *powerOffPreparationFlag = true;

    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

#### Register the Callback Function

After registering the shutdown preparation callback function, the payload device will perform shutdown preparation actions upon receiving the shutdown notification and update the shutdown preparation state, as shown in Figure 1. Shutdown Information.

```c
// register power off notification callback function
returnCode = DjiPowerManagement_RegPowerOffNotificationCallback(DjiTest_PowerOffNotificationCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("register power off notification callback function error");
    return returnCode;
}
```
