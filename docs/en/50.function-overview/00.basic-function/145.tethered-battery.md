## Overview

A tethered battery is a power battery used in tethered drone systems, mainly serving as a backup and buffer power source. When the drone is continuously powered by a ground power supply through the tether cable, the tethered battery can provide temporary power during power fluctuations or interruptions, ensuring flight safety and supporting safe landing.

The Matrice 400 drone supports tethered mode. In tethered mode, developers can push the tether cable length information to the aircraft through PSDK. Based on the remaining cable length, the aircraft issues safety alerts and imposes speed restrictions, thus ensuring the safety of tethered operations.

:::warning Warning:
The tethered battery function is only applicable to the Matrice 400 drone and requires a payload device developed based on the E-Port V2 coaxial cable. For the hardware interface, wiring, and working mode of the tethered battery, see <a href="../../payload-quick-start/configure-the-hardware-environment/payload-develop-criterion.html#tethered-battery" target="_blank" rel="noopener noreferrer">Tethered Battery</a>.
:::

## Implementation

:::warning Warning:
The following code snippets are reference examples intended to help developers understand the calling process and implementation approach for each function. Developers should adapt and adjust them according to the actual hardware characteristics and application scenarios of their payload devices.
:::

### Initialization

Before using the tethered battery function, you need to initialize the tethered battery module first.

```c
returnCode = DjiTetheredBattery_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Dji tethered battery init failed, errno = 0x%08llX", returnCode);
    return returnCode;
}
```

### Push Tether Cable Length

When the drone is operating in tethered mode, developers can create a tether cable length push thread to periodically push the cable length. The recommended push frequency should not exceed the data update frequency, with a maximum of 10Hz and a cable length range of 0–300m. When the remaining cable length reaches 15m and 5m, DJI Pilot will issue safety flight alerts and impose speed restrictions on the aircraft.

The tether cable length information is described by the `T_DjiTetherLineStatus` structure:

| Member | Description |
|--------|-------------|
| totalLength | Total length of the tether cable, range: 0–300, unit: meters |
| usedLength | Used length of the tether cable, range: 0–300, unit: meters. This value must be less than or equal to the total length |

After constructing the cable length information, call the `DjiTetheredBattery_PushTetherLineStatus()` interface to push it periodically:

```c
T_DjiTetherLineStatus tetherLineStatus = {0};

tetherLineStatus.usedLength = 0;
tetherLineStatus.totalLength = 150;

while (1) {
    returnCode = DjiTetheredBattery_PushTetherLineStatus(tetherLineStatus);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("Push tether line status error, stat = 0x%08llX", returnCode);
    }

    osalHandler->TaskSleepMs(100);
}
```

### Deinitialization

When the tethered battery function is no longer needed, call the `DjiTetheredBattery_DeInit()` interface to release the module resources.

```c
returnCode = DjiTetheredBattery_DeInit();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Dji tethered battery deinit failed, errno = 0x%08llX", returnCode);
    return returnCode;
}
```
