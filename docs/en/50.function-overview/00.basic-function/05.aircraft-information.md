## Overview
Payload devices developed based on PSDK have the aircraft information acquisition capability, which can actively obtain information such as the aircraft model, the mounting position of the payload device, and the Mobile App used by the user, allowing different configuration files to be loaded for user convenience.

:::tip Note:
 Install the payload device developed with PSDK on the drone, and the correct data information of the drone can be obtained only after 5s of booting and initialization.
:::

## Basic Concepts

### Information Acquisition
Information acquisition means that the payload device can **actively acquire and record** data information on the aircraft, such as the aircraft model, hardware platform type, and the mounting position of the payload device.

After the payload device developed with PSDK is initialized, the following information can be obtained:
* Basic information: drone model, hardware platform type, and payload mounting location
* Mobile App information: the system language of the App and the screen type of the App

## Implementation

:::warning Note:
 The following code samples are provided as reference examples to help developers understand the calling workflow and implementation approach of each feature. Developers should adapt and adjust based on the actual hardware characteristics and application scenarios of their own payload devices.
:::

### Get Aircraft Basic Information

Use the `DjiAircraftInfo_GetBaseInfo()` interface to obtain basic information such as the aircraft model and payload mounting position.

```c
T_DjiAircraftInfoBaseInfo aircraftInfoBaseInfo;
djiStat = DjiAircraftInfo_GetBaseInfo(&aircraftInfoBaseInfo);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("get aircraft base info error");
    return DJI_ERROR_SYSTEM_MODULE_CODE_SYSTEM_ERROR;
}

USER_LOG_INFO("aircraft type: %d, mount position: %d.", 
              aircraftInfoBaseInfo.aircraftType, aircraftInfoBaseInfo.mountPosition);
```

### Get Mobile App Information

Use the `DjiAircraftInfo_GetMobileAppInfo()` interface to obtain the system language and screen type of the currently connected mobile App.

```c
T_DjiMobileAppInfo mobileAppInfo;
djiStat = DjiAircraftInfo_GetMobileAppInfo(&mobileAppInfo);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("get mobile app info error");
} else {
    USER_LOG_INFO("app language: %d, screen type: %d.", 
                  mobileAppInfo.appLanguage, mobileAppInfo.appScreenType);
}
```

:::tip Note:
 If the remote controller or App is not connected to the aircraft, the obtained App language and screen type will return unknown.
:::
