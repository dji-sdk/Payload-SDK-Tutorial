## Overview

Transport mode development based on a PSDK payload used with Matrice 400 allows developers to configure the transport mode of Matrice 400, enabling safer and more reliable long-distance transport operation control.

:::tip Note:
* Currently only Matrice 400 is supported.
* Applicable Configuration: 1 PSDK device and 1 Matrice 400 aircraft. Ports E1 through E4 support connection to E-Port V2 and SkyPort V3. If an expansion hub is connected to the E4 port, up to 7 ports can be supported for E-Port V2 development boards.
* Supported Capabilities: Transport mode can be configured through PSDK.
* Constraints: The PSDK device must be certified. The dimensions of the transport box mounted on Matrice 400 must comply with DJI official requirements to ensure safe and reliable system operation. For specific dimension requirements, see the [attachment](https://terra-1-g.djicdn.com/6189933d30024fc1b331bffe4fe41837/matrice-400/DJI_Matrice_400_Transport_Case_Drawing_Delivery_Mode_Application_Guide_EN.zip).
:::

## Implementation

:::warning Warning:
The following code is provided as reference examples to help developers understand the calling process and implementation approach for each feature. Developers can adapt and adjust according to their own payload device hardware characteristics and application scenarios.
:::

### Set Payload Type

Developers can use `DjiCore_SetSdkDeviceType()` to set the payload type of the PSDK device so that the aircraft enters transport mode. This setting is required when the payload type is transport gear, and it must be called before `DjiCore_Init`.

```c
// Must be called before DjiCore_Init()
returnCode = DjiCore_SetSdkDeviceType(DJI_SDK_DEVICE_TYPE_TRANSPORT_BOX);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set SDK device type error: 0x%08llX", returnCode);
    return returnCode;
}

// Then initialize the PSDK core module
returnCode = DjiCore_Init(&userInfo);
```
