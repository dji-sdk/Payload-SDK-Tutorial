## Overview

Health Management System (HMS) is a system that manages the operational health status of aircraft modules. DJI Pilot 2 provides an interactive interface to check whether the working status of each module is abnormal. PSDK provides basic interfaces to report custom error codes for PSDK devices, allowing developers to obtain the working status of PSDK devices on Pilot 2.

:::tip Note:
Currently HMS customization only supports Chinese and English.
:::

## Basic Concepts

### HMS Error Code

A single HMS error code includes an error ID, an error index, and an error level. After PSDK reports a custom HMS error code, the corresponding error code and message will be displayed on Pilot 2. HMS error code levels range from low to high, corresponding to the severity of the error:

| Level | Enum Value | Severity |
|-------|------------|----------|
| 0 | DJI_HMS_ERROR_LEVEL_NONE | None |
| 1 | DJI_HMS_ERROR_LEVEL_HINT | Hint |
| 2 | DJI_HMS_ERROR_LEVEL_WARN | Warning |
| 3 | DJI_HMS_ERROR_LEVEL_CRITICAL | Critical |
| 4 | DJI_HMS_ERROR_LEVEL_FATAL | Fatal |

### Message Specifications for HMS Customization

The message configuration for HMS customization must follow the specifications below. After PSDK reports a custom HMS error code, Pilot 2 parses the HMS message configuration to obtain the message corresponding to the error code. If the error code configuration does not match the specifications, the expected custom message will not be displayed.

| Field | Description |
|-------|-------------|
| hms_position_desc | Payload position description |
| hms_error_code_list | Payload error code list |
| hms_error_code | Custom error code. Available range: 0x1E020000 ~ 0x1E02FFFF |
| hms_interface.message_title | Message title displayed on the HMS interface of Pilot 2 |
| hms_interface.message_content | Message content displayed on the HMS interface of Pilot 2 |
| fpv_interface.message_on_the_ground | Custom error message displayed on the FPV view of Pilot 2 when the aircraft is on the ground |
| fpv_interface.is_keep_history_on_the_ground | Whether to keep error code history when the aircraft is on the ground |
| fpv_interface.message_in_the_sky | Custom error message displayed on the FPV view of Pilot 2 when the aircraft is in the sky |
| fpv_interface.is_keep_history_in_the_sky | Whether to keep error code history when the aircraft is in the sky |

Message configuration JSON example:

```json
{
    "hms_database": {
        "hms_position_desc": "Payload%position_index",
        "hms_error_code_list": [
            {
                "hms_error_code": "0x1E020000",
                "hms_interface": {
                    "message_title": "HMS test text: I am error code Title 0",
                    "message_content": "HMS test text: I am error code Content 0"
                },
                "fpv_interface": {
                    "message_on_the_ground": "HMS test text: I got error on the ground 0",
                    "is_keep_history_on_the_ground": false,
                    "message_in_the_sky": "HMS test text: I got error in the sky 0",
                    "is_keep_history_in_the_sky": false
                }
            }
        ]
    }
}
```

### Alert Enhancement

The alert enhancement interface can control remote controller vibration and buzzer sound. Different parameters control the start and stop of alerts, as well as the number of consecutive alert actions and their intervals.

| Alarm Type | Enum Value | Description |
|------------|------------|-------------|
| Vibration | DJI_HMS_ALARM_ENHANCED_TYPE_SHAKE_MOTOR | Vibrate the remote controller motor |
| Buzzer | DJI_HMS_ALARM_ENHANCED_PLAY_SOUND | Play buzzer sound |
| Vibration + Buzzer | DJI_HMS_ALARM_ENHANCED_PLAY_SOUND_AND_SHAKE_MOTOR | Vibrate and play buzzer simultaneously |

| Alarm Action | Enum Value | Description |
|--------------|------------|-------------|
| Stop | DJI_HMS_ALARM_ENHANCED_ACTION_STOP | Stop the specified type of alert |
| Start | DJI_HMS_ALARM_ENHANCED_ACTION_START | Start the specified type of alert |
| Exit All | DJI_HMS_ALARM_ENHANCED_ACTION_EXIT_ALL | Exit all enhanced alerts |

## Implementation

:::warning Note:
The following code samples are reference examples intended to help developers understand the calling process and implementation approach for each feature. Developers should adapt and adjust according to the actual hardware characteristics and application scenarios of their payload devices.
:::

### Initialization

Before using the related interfaces of the HMS customization, you need to call the `DjiHmsCustomization_Init` interface to initialize the HMS customization module.

```c
returnCode = DjiHmsCustomization_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Hms init error, error code:0x%08llX", returnCode);
    return returnCode;
}
```

### Register Message Configuration

When developing payload devices on Linux and RTOS systems, developers need to register the message configuration for HMS customization, such as the default message configuration and configuration files for different system languages, to ensure that Pilot 2 can obtain and correctly display the custom HMS messages.

#### Register Message Configuration (Linux)

```c
//Step 2 : Set hms text Config (Linux environment)
returnCode = DjiUserUtil_GetCurrentFileDirPath(__FILE__, HMS_DIR_PATH_LEN_MAX, curFileDirPath);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get file current path error, stat = 0x%08llX", returnCode);
    return returnCode;
}

if (s_isHmsConfigFileDirPathConfigured == true) {
    snprintf(tempPath, HMS_DIR_PATH_LEN_MAX, "%shms_text/en", s_hmsConfigFileDirPath);
} else {
    snprintf(tempPath, HMS_DIR_PATH_LEN_MAX, "%shms_text/en", curFileDirPath);
}

//Set default hms text config path
returnCode = DjiHmsCustomization_RegDefaultHmsTextConfigByDirPath(tempPath);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Add default hms text config error, stat = 0x%08llX", returnCode);
    return returnCode;
}

//Set hms text config for English language
returnCode = DjiHmsCustomization_RegHmsTextConfigByDirPath(DJI_MOBILE_APP_LANGUAGE_ENGLISH,
                                                           tempPath);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Add hms text config error, stat = 0x%08llX", returnCode);
    return returnCode;
}

//Set hms text config for Chinese language
if (s_isHmsConfigFileDirPathConfigured == true) {
    snprintf(tempPath, HMS_DIR_PATH_LEN_MAX, "%shms_text/cn", s_hmsConfigFileDirPath);
} else {
    snprintf(tempPath, HMS_DIR_PATH_LEN_MAX, "%shms_text/cn", curFileDirPath);
}

returnCode = DjiHmsCustomization_RegHmsTextConfigByDirPath(DJI_MOBILE_APP_LANGUAGE_CHINESE,
                                                           tempPath);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Add hms text config error, stat = 0x%08llX", returnCode);
    return returnCode;
}
```

#### Register Message Configuration (RTOS)

```c
//Step 2 : Set hms text Config (RTOS environment)
T_DjiHmsBinaryArrayConfig enHmsTextBinaryArrayConfig = {
    .binaryArrayCount = sizeof(s_EnHmsTextConfigFileBinaryArrayList) / sizeof(T_DjiHmsFileBinaryArray),
    .fileBinaryArrayList = s_EnHmsTextConfigFileBinaryArrayList
};

//Set default hms text config
returnCode = DjiHmsCustomization_RegDefaultHmsTextConfigByBinaryArray(&enHmsTextBinaryArrayConfig);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Add default hms text config error, stat = 0x%08llX", returnCode);
    return returnCode;
}
```

### Error Code Management

#### Report HMS Error Codes

Custom HMS error codes can be reported by calling the `DjiHmsCustomization_InjectHmsErrorCode` interface. When an error occurs in the PSDK device, developers can obtain the real-time error code and the corresponding custom message on Pilot 2.

```c
DjiHmsCustomization_InjectHmsErrorCode(0x1E020000, DJI_HMS_ERROR_LEVEL_FATAL);
DjiHmsCustomization_InjectHmsErrorCode(0x1E020001, DJI_HMS_ERROR_LEVEL_CRITICAL);
DjiHmsCustomization_InjectHmsErrorCode(0x1E020002, DJI_HMS_ERROR_LEVEL_WARN);
DjiHmsCustomization_InjectHmsErrorCode(0x1E020003, DJI_HMS_ERROR_LEVEL_HINT);
```

#### Clear HMS Error Codes

:::warning Note:
Once reported, HMS error codes will continue to be displayed on Pilot 2. To clear the display, you need to call the `DjiHmsCustomization_EliminateHmsErrorCode` interface.
:::

Developers can clear the custom error codes of the PSDK device displayed on Pilot 2 by calling the `DjiHmsCustomization_EliminateHmsErrorCode` interface.

```c
DjiHmsCustomization_EliminateHmsErrorCode(0x1E020000);
DjiHmsCustomization_EliminateHmsErrorCode(0x1E020001);
DjiHmsCustomization_EliminateHmsErrorCode(0x1E020002);
DjiHmsCustomization_EliminateHmsErrorCode(0x1E020003);
```

### Alert Enhancement

The alert enhancement interface can control remote controller vibration and buzzer sound. Different parameters control the start and stop of alerts, as well as the number of consecutive alert actions and their intervals.
:::warning Note:
This feature is only supported when used with Manifold 3.
:::
```c
T_DjiHmsAlarmEnhancedSetting setting = {
    .type = DJI_HMS_ALARM_ENHANCED_PLAY_SOUND_AND_SHAKE_MOTOR,
    .times = 3,       // Consecutive alerts: 3 times
    .interval = 500    // Interval: 500ms
};

// Start alert
DjiHmsCustomization_AlarmEnhancedCtrl(DJI_HMS_ALARM_ENHANCED_ACTION_START, setting);

// Stop specified alert type
DjiHmsCustomization_AlarmEnhancedCtrl(DJI_HMS_ALARM_ENHANCED_ACTION_STOP, setting);

// Exit all enhanced alerts
DjiHmsCustomization_AlarmEnhancedCtrl(DJI_HMS_ALARM_ENHANCED_ACTION_EXIT_ALL, setting);
```
