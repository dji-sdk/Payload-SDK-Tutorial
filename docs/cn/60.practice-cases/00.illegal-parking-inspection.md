## 概述

本文介绍如何基于妙算3（Manifold 3）和 PSDK，构建一套自动化违停车辆巡检系统。系统通过无人机沿预设航线自动巡飞，利用机载 AI 实时识别违停车辆，自动抵近取证并最终生成巡检报告。

本案例综合运用了 PSDK 的多项核心能力：

- **Liveview**：获取相机实时码流并解码为图像
- **AI 推理标签推送**：将识别结果叠加至 Pilot App
- **飞行控制**：航线任务、FlyTo、兴趣点环绕
- **相机管理**：指点变焦、拍照取证

本案例的完整工程源码请参见 <a href="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/%E6%9C%80%E4%BD%B3%E5%AE%9E%E8%B7%B5Demo/Matrice%20400-parking-monitor-src-v01.00.00.15.tar.gz" target="_blank" rel="noopener noreferrer">示例工程</a>。

### 流程详解

#### 阶段一：系统初始化

1. 初始化 PSDK 各功能模块（Liveview、飞行控制、相机管理等）
2. 加载 YOLOv5 TensorRT 推理引擎
3. 注册 AI 识别标签列表

#### 阶段二：下发并启动航线

1. 通过 Pilot 下发航线任务
2. 等待航线任务启动

#### 阶段三：巡航检测

1. 订阅 H30T Wide 视频流，持续执行 AI 推理
2. 检查航线任务是否结束，若已结束则清理资源并退出
3. 判断是否识别到车辆目标，若未识别到则继续巡检并持续推理
4. 当识别到车辆目标时，进入取证阶段

#### 阶段四：抵近取证

1. **暂停航线** — 对各目标执行激光打点，获取车辆物理坐标
2. **指点变焦** — H30T Zoom 相机对目标进行变焦锁定
3. **FlyTo 抵近** — 飞行至目标附近约 10m 位置
4. **兴趣点环绕** — 围绕目标执行环绕飞行，多角度拍照取证
5. **车牌识别** — 订阅 Zoom 图像，识别车牌号码
6. 若存在待处理目标，则继续执行单目标处置流程

#### 阶段五：恢复航线

1. 取证完成后恢复航线并继续区域复检
2. 所有航点执行完毕后清理资源并退出

### 权重文件转换

训练完成后，需将 `.pt` 权重转换为 TensorRT 可用的中间文件。提供两种方案：

#### 方案 A：转换为 .wts 文件

1. 将 `best.pt` 上传至妙算3
2. 创建 `gen_wts.py` 脚本，内容如下：

```python
#!/usr/bin/env python3
import sys
import struct
import argparse

import numpy as np
import numpy.core
import numpy.core.multiarray
sys.modules.setdefault('numpy._core', np.core)
sys.modules.setdefault('numpy._core.multiarray', numpy.core.multiarray)

import torch

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument('--input', '-i', default='best.pt', help='Input .pt file')
    parser.add_argument('--output', '-o', default='best.wts', help='Output .wts file')
    parser.add_argument('--no-convert-anchors', action='store_true',
                        help='Skip anchor conversion (not recommended)')
    args = parser.parse_args()

    pt_file = args.input
    wts_file = args.output

    ckpt = torch.load(pt_file, map_location='cpu', weights_only=False)
    model = ckpt['model'].float().eval()

    m = model.model[-1]
    strides = m.stride.cpu().numpy()
    anchors = m.anchors.clone().cpu().numpy()

    print(f"Strides: {strides}")
    print(f"Original anchors (max={anchors.max():.4f}, shape={anchors.shape})")

    state_dict = model.state_dict()
    anchor_key = next((k for k in state_dict.keys()
                       if 'anchors' in k and 'anchor_grid' not in k), None)

    if anchor_key is None:
        print("Warning: No anchor key found in model")
    elif args.no_convert_anchors:
        print("Skipping anchor conversion (--no-convert-anchors)")
    else:
        pixel_anchors = anchors.copy()
        for i in range(len(strides)):
            pixel_anchors[i] *= strides[i]

        state_dict[anchor_key] = torch.tensor(pixel_anchors).float()
        model.load_state_dict(state_dict, strict=False)
        print(f"Anchors converted to pixel units: max={pixel_anchors.max():.2f}")

    with open(wts_file, 'w') as f:
        f.write(f"{len(state_dict)}\n")
        for k, v in state_dict.items():
            vr = v.reshape(-1).cpu().numpy()
            f.write(f"{k} {len(vr)}")
            for vv in vr:
                f.write(f" {struct.pack('>f', float(vv)).hex()}")
            f.write("\n")

    print(f"Done: {wts_file}")

if __name__ == '__main__':
    main()
```

3. 执行转换：

```bash
python3 gen_wts.py
```

执行完成后，当前目录下生成 `best.wts` 文件。

#### 方案 B：转换为 .onnx 文件（推荐在 Ubuntu 系统上进行）

1. 克隆 YOLOv5 官方仓库：

```bash
git clone https://github.com/ultralytics/yolov5.git
cd yolov5
```

2. 安装依赖：

```bash
pip3 install -r requirements.txt
pip3 install onnx onnxslim
```

3. 将 `best.pt` 放入 `yolov5` 目录，执行转换：

```bash
python3 export.py \
  --weights best.pt \
  --include onnx \
  --imgsz 640 \
  --opset 12 \
  --simplify
```

转换完成后生成 `best.onnx` 文件。

### 生成 TensorRT 推理引擎

使用 `yolo_test` 工具将权重文件转换为 TensorRT 推理引擎。

**从 .wts 文件：**

```bash
./yolo_test -e best.wts best.engine s 10
```

**从 .onnx 文件：**

```bash
./yolo_test -eo best.onnx best.engine 10
```

## PSDK 集成
妙算3 支持通过 PSDK 获取无人机相机的 1080p/4K 码流，以及通过 NVIDIA 硬件解码后的 RGB/NV12 格式图像数据。建议直接使用解码后的图像进行 AI 推理。


### 1. 初始化 Liveview 模块

```cpp
T_DjiReturnCode DjiLiveview_Init(void);
```

### 2. 注册 AI 识别标签列表

```cpp
T_DjiReturnCode DjiLiveview_RegUserAiTargetLableList(
    uint8_t lableCount,
    const char *labels[]
);
```

### 3. 订阅图像流并执行推理

```cpp
T_DjiReturnCode DjiLiveview_StartImageStream(
    E_DjiLiveViewCameraPosition position,
    E_DjiLiveViewCameraSource source,
    Callback function
);
```

在回调函数中获取 NVIDIA 硬件解码后的 RGB/NV12 图像，调用 YOLOv5 推理库执行目标检测。

### 4. 推送识别结果

```cpp
T_DjiReturnCode DjiLiveview_SendAiMetaToPilot(
    T_DjiLiveViewStandardMetaData *metaData
);
```

将标注框、置信度等识别结果发送至飞控，在 Pilot App 中实时渲染。

:::warning 注意
AI 标签推送功能需要以 DPK 应用方式启动才能生效。
:::
