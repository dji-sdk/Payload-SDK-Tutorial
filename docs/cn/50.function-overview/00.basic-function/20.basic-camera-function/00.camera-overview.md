## 概述

PSDK 提供相机类负载控制接口，支持开发者接入拍照、录像、变焦、对焦等能力，并通过 DJI Pilot 或基于 MSDK 的 App 实现相机负载控制。

## 接口总览

开发者需要调用 `DjiPayloadCamera_Init()` 初始化相机模块，再根据需要注册不同的回调函数集合（Handler）。各功能对应的 Handler 结构体和注册接口如下：

| 功能 | Handler 结构体 | 注册接口 |
|------|---------------|---------|
| 相机基础功能 | T_DjiCameraCommonHandler | DjiPayloadCamera_RegCommonHandler() |
| 对焦功能 | T_DjiCameraFocusHandler | DjiPayloadCamera_RegFocusHandler() |
| 测光功能 | T_DjiCameraExposureMeteringHandler | DjiPayloadCamera_RegExposureMeteringHandler() |
| 数码变焦 | T_DjiCameraDigitalZoomHandler | DjiPayloadCamera_RegDigitalZoomHandler() |
| 光学变焦 | T_DjiCameraOpticalZoomHandler | DjiPayloadCamera_RegOpticalZoomHandler() |
| 指点变焦 | T_DjiCameraTapZoomHandler | DjiPayloadCamera_RegTapZoomHandler() |

:::tip 说明：
表格中带 `()` 的为主动调用接口，不带 `()` 的为回调函数。
:::

## 基础概念

### 相机模式与拍照
相机类负载设备在工作时需要先切换到对应的模式（拍照、录像或视频回放），同一时刻只能在一种模式下工作。在拍照模式下，支持单拍、连拍和定时拍照等多种拍摄方式。详见 <a href="./camera-basic.html#基础概念" target="_blank" rel="noopener noreferrer">相机基础功能 - 基础概念</a>。

### 对焦功能
对焦功能用于控制相机镜头调节焦点，使拍摄目标成像清晰。开发者可以实现自动对焦（AF）和手动对焦（MF）两种模式，并可设置对焦点位置、对焦环参数和对焦助手等辅助功能。详见 <a href="./camera-focus.html#基础概念" target="_blank" rel="noopener noreferrer">对焦功能 - 基础概念</a>。

### 测光功能
测光功能用于分析画面亮度，为相机提供正确的曝光参数。根据不同的拍摄场景，可选择平均测光、中央重点测光或点测光模式。详见 <a href="./camera-metering.html#基础概念" target="_blank" rel="noopener noreferrer">测光功能 - 基础概念</a>。

### 变焦功能
变焦功能用于调整相机镜头的焦距，改变画面的视野范围和拍摄目标的远近。支持光学变焦、数码变焦、连续变焦和指点变焦四种方式，开发者可根据负载设备的硬件能力按需实现。详见 <a href="./camera-zoom.html#基础概念" target="_blank" rel="noopener noreferrer">变焦功能 - 基础概念</a>。

## 初始化

使用 PSDK 开发负载设备的相机功能时，必须先初始化相机模块，再根据需要注册各个功能的回调函数集合。以下为初始化流程的框架代码：

:::tip 说明：
* `DjiPayloadCamera_RegCommonHandler` 为必须注册的基础功能回调，其余 Handler 可根据实际需求按需注册。
* 各 Handler 的详细字段赋值和功能实现请参考对应的功能文档。
:::

```c
// 1. 初始化相机模块
returnCode = DjiPayloadCamera_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("init payload camera error:0x%08llX", returnCode);
    return returnCode;
}

// 2. 注册基础功能回调（模式/拍照/录像/SD卡）—— 必须注册
returnCode = DjiPayloadCamera_RegCommonHandler(&s_commonHandler);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("camera register common handler error:0x%08llX", returnCode);
}

// 3. 注册测光功能回调 —— 按需注册
returnCode = DjiPayloadCamera_RegExposureMeteringHandler(&s_exposureMeteringHandler);

// 4. 注册对焦功能回调 —— 按需注册
returnCode = DjiPayloadCamera_RegFocusHandler(&s_focusHandler);

// 5. 注册数码变焦功能回调 —— 按需注册
returnCode = DjiPayloadCamera_RegDigitalZoomHandler(&s_digitalZoomHandler);

// 6. 注册光学变焦功能回调 —— 按需注册
returnCode = DjiPayloadCamera_RegOpticalZoomHandler(&s_opticalZoomHandler);

// 7. 注册指点变焦功能回调 —— 按需注册
returnCode = DjiPayloadCamera_RegTapZoomHandler(&s_tapZoomHandler);
```
