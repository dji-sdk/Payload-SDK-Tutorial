## 基础概念

### 客户端与服务端

* **客户端**：根据指定的通道 ID，发起通道连接的一端。
* **服务端**：根据用户的实际需求，创建通道并指定通道 ID 的一端。

MSDK 与 PSDK 负载设备通信时，MSDK 仅能作为客户端，PSDK 负载设备则作为服务端。PSDK 负载设备间通信时，PSDK 负载（负载设备）与 PSDK 负载（机载应用）均可作为客户端。

### 传输方式

* **可靠传输**<br/>
  DJI SDK 内部采用丢包重传、超时重发及错误检验等机制，确保不同 SDK 间收发的数据准确可靠。
  * 数据可靠：发送和接收数据时使用校验函数检验正确性，同时使用加密算法加密传输数据，确保安全性。
  * 传输可靠：拥有计时器和 ACK 机制，超时后自动重发数据，防止数据意外丢失。发送端为数据编号，接收端可重排乱序数据，确保传输可靠性。
* **不可靠传输**<br/>
  以不可靠的传输方式传输数据时，机载应用和设备间能够以更快的速度传输数据，但无法保证可靠地传输数据。

### 对象指定

DJI SDK 的互联互通功能，通过设备类型和设备槽位能够准确指定飞行器上所需通信的设备或模块。

* **设备类型**：用于识别对端的身份和类型，区分数据传输的对象，包括 MSDK、PSDK（机载应用）和 PSDK（负载设备）。
* **设备槽位**：DJI 的飞行器支持多种拓展方式接入负载设备和机载应用，可使用不同的槽位区分移动端 App、负载设备和机载应用当前所处的位置。
* **通道 ID**：用于区分同一个设备上的不同通道，开发者创建通道时可为通道指定 ID。

:::tip 说明：
* 仅基于 PSDK 开发的负载设备和机载应用在使用数据传输功能时，需要为创建的通道指定通道 ID。
* 开发者可以根据实际的使用需求，在创建通道时，为所创建的通道指定通道 ID，最大支持设置 65535 个通道。
:::

### 通道管理

DJI SDK 为互联互通功能提供了通信管理能力，开发者无需关注底层工作逻辑：

* **链路管理**：管理链路的接入、关闭、销毁、重连及拥塞管理等。
* **数据管理**：数据转发、数据读写、流量控制、数据校验、乱序重排及丢包重传等。

### 通道带宽

:::warning 注意：
以下数据仅供参考，建议以实际测试为准。
:::

* MSDK 上行（向服务器端发送数据）可靠/非可靠传输最大速率一般为 **24-48 Kbps**，带宽上限取决于实际的无线链路情况。
* MSDK 下行（从服务器端接收数据）可靠传输最大速率为 **16Mbps**，非可靠传输最大速率为 **20Mbps**。
* 对于 PSDK 机载应用与 PSDK 负载设备之间的数据传输，可靠传输最大速率为 **24Mbps**，非可靠传输最大速率为 **30Mbps**。

## 功能介绍

:::warning 注意：
以下代码均为参考示例，旨在帮助开发者理解各功能的调用流程和实现思路。开发者可根据自身负载设备的实际硬件特性和应用场景进行适配和调整。
:::

### PSDK 端

仅使用 Linux 平台开发的负载设备支持基于 PSDK 开发互联互通功能。

#### 初始化与创建

使用 SDK 互联互通功能前，需要先初始化 MOP 通道模块，再创建通道句柄。创建通道时需指定传输类型：可靠传输或不可靠传输。

```c
// 初始化 MOP 通道模块
T_DjiReturnCode returnCode = DjiMopChannel_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("MOP channel init error, stat:0x%08llX.", returnCode);
    return returnCode;
}

// 创建通道句柄（选择可靠或不可靠传输）
T_DjiMopChannelHandle channelHandle;
returnCode = DjiMopChannel_Create(&channelHandle, DJI_MOP_CHANNEL_TRANS_RELIABLE);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("MOP channel create error, stat:0x%08llX.", returnCode);
    return returnCode;
}
```

#### 服务端连接

基于 PSDK 开发的负载设备作为服务端时，需先将通道 ID 绑定到已创建的通道句柄，然后调用 `DjiMopChannel_Accept()` 阻塞等待客户端连接。为支持同时与多个客户端建立连接，`DjiMopChannel_Accept()` 会返回一个新的 `outChannelHandle` 句柄用于后续数据收发。

:::tip 说明：
`DjiMopChannel_Accept()` 为阻塞式接口，建议在独立的线程中调用。
:::

```c
// 绑定通道 ID
REBIND:
returnCode = DjiMopChannel_Bind(channelHandle, 49152);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("MOP bind channel error: 0x%08llX", returnCode);
    osalHandler->TaskSleepMs(3000);
    goto REBIND;
}

// 阻塞等待客户端连接
T_DjiMopChannelHandle outChannelHandle;
REACCEPT:
returnCode = DjiMopChannel_Accept(channelHandle, &outChannelHandle);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_WARN("MOP accept channel error: 0x%08llX", returnCode);
    osalHandler->TaskSleepMs(3000);
    goto REACCEPT;
}
USER_LOG_INFO("MOP channel connected.");
```

#### 客户端连接

基于 PSDK 开发的负载设备作为客户端时（如 PSDK 间互联互通场景），使用 `DjiMopChannel_Connect()` 主动连接至指定地址和通道 ID 的服务端。

:::tip 说明：
`DjiMopChannel_Connect()` 为阻塞式接口，建议在独立的线程中调用。
:::

```c
// 连接至服务端（指定通道地址和通道 ID）
T_DjiReturnCode returnCode = DjiMopChannel_Connect(channelHandle,
                                                    DJI_CHANNEL_ADDRESS_PAYLOAD_PORT_NO1,
                                                    49152);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("MOP connect error: 0x%08llX", returnCode);
    return returnCode;
}
USER_LOG_INFO("MOP channel connected to server.");
```

#### 数据收发

通道连接建立后，可通过 `DjiMopChannel_SendData()` 和 `DjiMopChannel_RecvData()` 进行数据收发。服务端使用 `DjiMopChannel_Accept()` 返回的 `outChannelHandle` 进行收发；客户端直接使用创建的 `channelHandle` 进行收发。

:::tip 说明：
`DjiMopChannel_RecvData()` 为阻塞式接口，建议在独立的线程中调用。
:::

```c
// 接收数据
uint8_t recvBuf[100 * 1024];
uint32_t realLen = 0;
returnCode = DjiMopChannel_RecvData(outChannelHandle, recvBuf, sizeof(recvBuf), &realLen);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    if (returnCode == DJI_ERROR_MOP_CHANNEL_MODULE_CODE_CONNECTION_CLOSE) {
        USER_LOG_INFO("MOP channel disconnected.");
        DjiMopChannel_Close(outChannelHandle);
        DjiMopChannel_Destroy(outChannelHandle);
        goto REACCEPT;
    }
}

// 发送数据
uint8_t sendBuf[64 * 1024];
memset(sendBuf, 0xAB, sizeof(sendBuf));
DjiMopChannel_SendData(outChannelHandle, sendBuf, sizeof(sendBuf), &realLen);
```

#### 关闭与销毁

通信结束后，先调用 `DjiMopChannel_Close()` 关闭通道连接，再调用 `DjiMopChannel_Destroy()` 销毁通道句柄释放资源。关闭通道后，该通道将无法收发数据，但可重新接受新的连接。

```c
// 关闭通道
DjiMopChannel_Close(outChannelHandle);

// 销毁通道句柄
DjiMopChannel_Destroy(outChannelHandle);
```

### MSDK 端

基于 MSDK 开发的移动端 App 使用 SDK 互联互通功能时，能够与指定的通道建立连接，实现数据的接收和发送。**基于 MSDK 开发的移动端 App 仅能作为客户端，通过通道 ID 与指定的通道建立连接。**



#### 通道连接

通道连接时，请指定通道传输方式和所需连接的通道 ID 与指定的通道建立连接，并以阻塞回调的方式接收传输的数据。

* iOS
```c
- (void)connect:(uint16_t)Id pipelineType:(DJITransmissionControlType)transferType withCompletion:(void (^_Nullable)(DJIPipeline *_Nullable pipeline, NSError *_Nullable error))completion;
```

* Android
```java
void connect(int id, @NonNull TransmissionControlType transmissionType, @Nullable CommonCallbacks.CompletionCallback<PipelineError> callback);
```

#### 数据接收

通道建立连接后，使用如下接口接收对端发送的数据。

* iOS
```c
- (NSData *)readData:(uint32_t)readLength error:(NSError **)error;
```

* Android
```java
int readData(byte[] buff, int length);
```

#### 数据发送

通道建立连接后，使用如下接口向对端发送数据。

:::tip 说明：
为实现良好的数据传输效果，建议每次传输的数据不超过 1KB。
:::

* iOS
```c
- (int32_t)writeData:(NSData *)data error:(NSError **)error;
```

* Android
```java
int writeData(byte[] data);
```

#### 关闭通道

通信结束后，请使用如下接口断开已连接的通道。

:::tip 说明：
* 执行通道关闭的操作后，基于 MSDK 开发的移动端 App 将清除本地的缓存信息。
* 通道关闭后，DJI SDK 将自动销毁已创建的通道，释放通道所占用的系统资源。
:::

* iOS
```c
- (void)disconnect:(uint16_t)Id withCompletion:(DJICompletionBlock)completion;
```

* Android
```java
void disconnect(int id, @Nullable CommonCallbacks.CompletionCallback<PipelineError> callback);
```

## 示例教程

本节提供两种互联互通场景的完整实现示例，帮助开发者快速上手。

### MSDK 与 PSDK 互联互通

MSDK 仅可作为客户端，PSDK（云台口/E-Port 口）作为服务端。两端需对齐自定义的通道 ID 和数据协议。

**PSDK 端（服务端）**

以下为 PSDK 端作为服务端的完整流程：初始化 → 创建通道 → 绑定通道 ID → 等待连接 → 数据收发 → 关闭销毁。

```c
// Step 1: 初始化 MOP 通道模块
T_DjiReturnCode returnCode = DjiMopChannel_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("MOP channel init error, stat:0x%08llX.", returnCode);
    return returnCode;
}

// Step 2: 创建通道句柄（选择可靠或不可靠传输）
T_DjiMopChannelHandle channelHandle;
returnCode = DjiMopChannel_Create(&channelHandle, DJI_MOP_CHANNEL_TRANS_RELIABLE);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("MOP channel create error, stat:0x%08llX.", returnCode);
    return returnCode;
}

// Step 3: 绑定通道 ID
REBIND:
returnCode = DjiMopChannel_Bind(channelHandle, 49152);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("MOP bind channel error: 0x%08llX", returnCode);
    osalHandler->TaskSleepMs(3000);
    goto REBIND;
}

// Step 4: 阻塞等待客户端连接（建议在独立线程中调用）
T_DjiMopChannelHandle outChannelHandle;
REACCEPT:
returnCode = DjiMopChannel_Accept(channelHandle, &outChannelHandle);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_WARN("MOP accept channel error: 0x%08llX", returnCode);
    osalHandler->TaskSleepMs(3000);
    goto REACCEPT;
}
USER_LOG_INFO("MOP channel connected.");

// Step 5: 数据收发（使用 outChannelHandle）
uint8_t recvBuf[100 * 1024];
uint32_t realLen = 0;
returnCode = DjiMopChannel_RecvData(outChannelHandle, recvBuf, sizeof(recvBuf), &realLen);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    if (returnCode == DJI_ERROR_MOP_CHANNEL_MODULE_CODE_CONNECTION_CLOSE) {
        USER_LOG_INFO("MOP channel disconnected.");
        DjiMopChannel_Close(outChannelHandle);
        DjiMopChannel_Destroy(outChannelHandle);
        goto REACCEPT;
    }
}

uint8_t sendBuf[64 * 1024];
memset(sendBuf, 0xAB, sizeof(sendBuf));
DjiMopChannel_SendData(outChannelHandle, sendBuf, sizeof(sendBuf), &realLen);

// Step 6: 关闭与销毁通道
DjiMopChannel_Close(outChannelHandle);
DjiMopChannel_Destroy(outChannelHandle);
```

**MSDK 端（客户端）**

当 PSDK 调用 `DjiMopChannel_Accept` 接口成功后，MSDK 可以使用 `connect` 接口选择指定的通道 ID 和通道类型进行连接，连接成功后可以通过 `writeData` 和 `readData` 收发数据。

* iOS

```objc
// Step 1: 连接至 PSDK 服务端指定通道
[pipeline connect:49152
     pipelineType:DJITransmissionControlTypeReliable
   withCompletion:^(DJIPipeline *pipeline, NSError *error) {
    if (error) {
        NSLog(@"Connect failed: %@", error);
        return;
    }
    NSLog(@"Connect success");
}];

// Step 2: 接收数据
NSError *error = nil;
NSData *recvData = [pipeline readData:1024 error:&error];
if (error) {
    NSLog(@"Read data error: %@", error);
}

// Step 3: 发送数据（建议每次不超过 1KB）
NSData *sendData = [@"Hello PSDK" dataUsingEncoding:NSUTF8StringEncoding];
```

### PSDK 云台口与 PSDK E-Port 口互联互通

基于此场景，PSDK（E-Port 口）与 PSDK（云台口）均可作为客户端或服务端。两端需对齐自定义的通道 ID 和数据协议。以下以 PSDK 云台口作为服务端、PSDK E-Port 口作为客户端为例。

**PSDK 云台口（服务端）**

服务端流程与上述 [MSDK 与 PSDK 互联互通](#msdk-与-psdk-互联互通) 中的 PSDK 端一致。

**PSDK E-Port 口（客户端）**

```c
// Step 1: 初始化 MOP 通道模块
DjiMopChannel_Init();

// Step 2: 创建通道句柄
T_DjiMopChannelHandle channelHandle;
DjiMopChannel_Create(&channelHandle, DJI_MOP_CHANNEL_TRANS_RELIABLE);

// Step 3: 连接至服务端（指定通道地址和通道 ID，阻塞式，建议在独立线程中调用）
T_DjiReturnCode returnCode = DjiMopChannel_Connect(channelHandle,
                                                    DJI_CHANNEL_ADDRESS_PAYLOAD_PORT_NO1,
                                                    49152);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("MOP connect error: 0x%08llX", returnCode);
    return returnCode;
}
USER_LOG_INFO("MOP channel connected to server.");

// Step 4: 数据收发
uint8_t recvBuf[100 * 1024];
uint32_t realLen = 0;
DjiMopChannel_RecvData(channelHandle, recvBuf, sizeof(recvBuf), &realLen);

uint8_t sendBuf[64 * 1024];
memset(sendBuf, 0xAB, sizeof(sendBuf));
DjiMopChannel_SendData(channelHandle, sendBuf, sizeof(sendBuf), &realLen);

// Step 5: 关闭与销毁通道
DjiMopChannel_Close(channelHandle);
DjiMopChannel_Destroy(channelHandle);
```
