## 概述

基于第三方 PSDK 负载搭载 DJI 空吊 2.0 系统开发，可以实现对空吊系统的控制，并获取空吊系统的实时状态反馈。空吊系统包含卷扬机和主动挂钩两部分，开发者可通过 PSDK 接口分别控制卷扬机的收放绳、主动挂钩的开合，以及获取空吊运行状态。

:::tip 说明：
* 目前仅 FlyCart 100 支持。
* 使用对象：1 个 E-Port Lite 口（PSDK）、一台 FlyCart 100 机型。
* 使用范围：通过 E-Port Lite 口（PSDK）可以控制空吊系统和简易空吊，并获取空吊系统以及简易吊运的称重数据状态。
* 使用约束：不支持负载空吊控制和复杂的状态获取。
:::

## 基础概念

### 空吊类型

空吊系统支持两种类型：
- **标准空吊**：支持卷扬机控制、挂钩控制和完整状态获取。
- **简易空吊**：仅支持力和角度状态获取。

请求飞控推送空吊信息时，接口会返回当前连接的空吊类型，开发者需根据空吊类型调用对应的控制和状态获取接口。

### 卷扬机控制

卷扬机支持放绳、收绳、停止、维护和脱困等控制指令，详见头文件中 `E_DjiHoistControllerCmdStatus` 枚举定义。

### 主动挂钩控制

主动挂钩支持开钩和关钩两种控制指令，详见头文件中 `E_DjiHookControllerCmdStatus` 枚举定义。

## 功能介绍

:::warning 注意：
以下代码均为参考示例，旨在帮助开发者理解各功能的调用流程和实现思路。开发者可根据自身负载设备的实际硬件特性和应用场景进行适配和调整。
:::

### 初始化

使用空吊控制功能前，需要先初始化空吊控制功能模块。建议通过机型获取函数确认当前飞行器是否为支持空吊控制的机型。

```c
// 初始化空吊控制模块
returnCode = DjiHoistControllerManagement_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Hoist controller management init error: 0x%08llX", returnCode);
    return returnCode;
}

// 确认机型信息
returnCode = DjiAircraftInfo_GetBaseInfo(&aircraftBaseInfo);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get aircraft base info error");
    return returnCode;
}
```

### 请求控制

开启 task 运行（建议不高于 10Hz），请求飞控开始推送空吊信息。接口返回当前连接的空吊类型（标准空吊或简易空吊），开发者需根据空吊类型调用对应的控制和状态获取接口。

:::tip 说明：
需要 APP 模拟器起飞后才能控制空吊系统，地面状态无法控制。
:::

```c
djiStat = psdk_HoistController_NotifyFlight_to_startPushInfo();
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("get hoist can start controller error: 0x%08llX.", djiStat);
    continue;
}
```

### 卷扬机控制

通过 `psdk_hoistControllerCmdAction()` 发送卷扬机控制指令，支持放绳、收绳、停止、维护和脱困等操作。仅标准空吊类型支持卷扬机控制。

```c
// 发送卷扬机控制指令（放绳 / 收绳 / 停止 / 维护 / 脱困）
djiStat = psdk_hoistControllerCmdAction(DJI_HOIST_CARGO_RELEASE_CMD);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("hoist controller cmd action error: 0x%08llX.", djiStat);
}
```

### 挂钩控制

通过 `psdk_hookControllerCmdAction()` 发送主动挂钩控制指令，支持开钩和关钩操作。仅标准空吊类型支持挂钩控制。

```c
// 发送主动挂钩控制指令（开钩 / 关钩）
djiStat = psdk_hookControllerCmdAction(DJI_HOOK_CARGO_OPEN_HOOK);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("hook controller cmd action error: 0x%08llX.", djiStat);
}
```

### 简易空吊脱困

通过 `psdk_simpleHoistEscapeCmdAction()` 发送简易空吊脱困指令。仅简易空吊类型支持此操作。

```c
djiStat = psdk_simpleHoistEscapeCmdAction(DJI_SIMPLE_HOIST_ESCAPE_CMD);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("simple hoist escape cmd action error: 0x%08llX.", djiStat);
}
```

### 状态获取

根据空吊类型调用对应的状态获取接口。标准空吊可获取卷扬机状态和挂钩状态，简易空吊可获取力传感器和角度状态。此外，可通过 `DjiHoistController_flightAvoidStatus()` 获取飞行避障状态（最高 10Hz）。

**标准空吊状态获取**

```c
// 获取卷扬机状态
djiStat = DjiHoistController_hoistStatus(&hoist_status);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    return djiStat;
}

USER_LOG_INFO("hoist status:cab_s:%d ,can_s:%d, g_w:%d, mg_w:%d, c_s_s:%d, cc_l:%d",
    hoist_status.cable_state, hoist_status.can_status, hoist_status.goods_weight, hoist_status.max_goods_weight,
    hoist_status.cargo_swing_speed, hoist_status.cur_cable_length);
USER_LOG_INFO("hoist status: c_f:%d, c_an:%d, is_r_t:%d, is_rmr:%d, cdcs:%d",
    hoist_status.cable_force, hoist_status.cable_angle, hoist_status.is_reach_top, hoist_status.is_reach_max_round,
    hoist_status.cable_direction_check_state);

// 获取挂钩状态
djiStat = DjiHoistController_hookStatus(&hook_status);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    return djiStat;
}

USER_LOG_INFO("hook status: steer_state:%d, weight:%d, warning:%d",
    hook_status.steer_state, hook_status.cargo_weight, hook_status.cargo_warnig);
USER_LOG_INFO("hook status: error:%d, ctr_state:%d", hook_status.cargo_error, hook_status.ctrl_state);
```

**简易空吊状态获取**

```c
psdk_receive_simple_hoist_status_t simple_hoist_status;

djiStat = DjiHoistController_simpleHoistStatus(&simple_hoist_status);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    return djiStat;
}

USER_LOG_INFO("simple hoist status: f_kg:%d, angle_z:%d",
    simple_hoist_status.force_kg, simple_hoist_status.angle_deg);
```

**飞行避障状态获取**

```c
psdk_receive_avoid_status_t avoid_status;

djiStat = DjiHoistController_flightAvoidStatus(&avoid_status);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    return djiStat;
}

USER_LOG_INFO("avoid status: is_cargo_avoid:%d, is_avoid_stop_finish:%d, is_start_avoid:%d",
    avoid_status.is_cargo_avoid, avoid_status.is_avoid_stop_finish, avoid_status.is_start_avoid);
```
