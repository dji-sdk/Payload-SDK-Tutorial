## 概述

系留电池是一种用于系留无人机系统的电源电池，主要作为备用和缓冲电源使用。当无人机通过系留线缆由地面电源持续供电时，系留电池可在供电波动或中断时提供临时电力，以保证飞行安全并支持安全降落。

Matrice 400 无人机支持系留模式。在系留模式下，开发者可以通过 PSDK 向飞行器推送系留线缆的长度信息，飞行器根据剩余线缆长度进行安全提示和飞行限速，从而保障系留作业的安全性。

:::warning 注意：
系留电池功能仅适用于 Matrice 400 无人机，且需要基于 E-Port V2 同轴线开发的负载设备。系留电池的硬件接口、接线及工作模式说明请参见 <a href="../../payload-quick-start/configure-the-hardware-environment/payload-develop-criterion.html#系留电池" target="_blank" rel="noopener noreferrer">系留电池</a>。
:::

## 功能介绍

:::warning 注意：
以下代码均为参考示例，旨在帮助开发者理解各功能的调用流程和实现思路。开发者可根据自身负载设备的实际硬件特性和应用场景进行适配和调整。
:::

### 初始化

使用系留电池功能前，需要先初始化系留电池模块。

```c
returnCode = DjiTetheredBattery_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Dji tethered battery init failed, errno = 0x%08llX", returnCode);
    return returnCode;
}
```

### 推送系留线缆长度

当无人机处于系留模式下时，开发者可以创建系留电缆长度推送线程，定频推送线长，建议推送频率不超过数据更新频率，最高不超过 10Hz，线长范围 0-300m。当剩余线缆长度为 15m 和 5m 时，Pilot 会进行安全飞行提示，并对飞行器进行限速。

系留线缆长度信息由 `T_DjiTetherLineStatus` 结构体描述：

| 成员 | 说明 |
|------|------|
| totalLength | 系留线缆总长度，范围 0-300，单位：米 |
| usedLength | 系留线缆已使用长度，范围 0-300，单位：米，该值必须小于或等于总长度 |

开发者构造好线缆长度信息后，调用 `DjiTetheredBattery_PushTetherLineStatus()` 接口定频推送即可：

```c
T_DjiTetherLineStatus tetherLineStatus = {0};

tetherLineStatus.usedLength = 0;
tetherLineStatus.totalLength = 150;

while (1) {
    returnCode = DjiTetheredBattery_PushTetherLineStatus(tetherLineStatus);
    if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
        USER_LOG_ERROR("Push tether line status error, stat = 0x%08llX", returnCode);
    }

    osalHandler->TaskSleepMs(100);
}
```

### 反初始化

当不再使用系留电池功能时，可调用 `DjiTetheredBattery_DeInit()` 接口释放模块资源。

```c
returnCode = DjiTetheredBattery_DeInit();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Dji tethered battery deinit failed, errno = 0x%08llX", returnCode);
    return returnCode;
}
```
