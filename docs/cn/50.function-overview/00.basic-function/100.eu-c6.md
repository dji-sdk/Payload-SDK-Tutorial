## 概述

为确保无人机符合基本安全要求，欧盟发布了无人机 EU 2019/945 UAS 认证法规要求。其中 C5 和 C6 级别无人机，作为特许类别无人机需要进行不同的合规性测试，以确认其功能，无人机系统通过认证实验室进行一系列合规性测试，才能进入欧洲市场。

为了满足欧盟 C6 合规认证，PSDK 为用户提供了 GEO Caging 功能，无人机在三个区域内有对应不同的飞行表现。
GEO Caging 包括可作业区域、应急区域。飞行器应在作业区域内作业，如进入应急区域飞行器将悬停，并有持续告警，需要手动飞行回作业区域。如飞出应急区域，飞行器将触发 FTS 飞行终止系统，若飞行器安装降落伞，直接使用降落伞降落，紧急迫降。请在作业前检测作业目标点或在飞行过程中注意飞行器的提示。

## 基础概念

### 名词解释

**作业区域 (FG, Flight Geography Area)**

在此区域内，飞行器可正常起飞、降落以及进行飞行作业。

**应急区域 (CA, Contingency Area)**

在此区域内，飞行器无法起飞、降落，且无法使用包括返航、指点飞行等智能功能。若飞行器进入应急区域边缘，飞行器将刹车悬停。

**飞行区域 (OV, Operation Volume)**

飞行区域包括作业区域 (FG) 和应急区域 (CA)。如飞行器飞出飞行区域，会触发飞行终止系统 (FTS)，将直接使用降落伞降落。

**飞行终止系统 (FTS, Flight Termination System)**

在飞行出现安全隐患时主动强制停止飞行并独立于飞行器自身控制系统的一套设备和软件。

**硬件飞行终止系统 (EFTS, External Flight Termination System)**

EFTS 是 FTS 的硬件实现方式。负载设备通过接口向飞行平台主动输出符合规格的 PWM 信号，飞行平台检测到信号满足条件后立即执行电机停桨操作，不依赖软件指令链路。

### FTS 与 EFTS 对比

| 对比项 | FTS（软件回调） | EFTS（硬件触发） |
|--------|----------------|-----------------|
| 触发方向 | 飞控 → 通知负载（下行） | 负载 → 触发飞行平台停桨（上行） |
| 实现方式 | 飞控触发 FTS 事件后，SDK 调用开发者注册的回调函数，开发者在回调中执行停桨动作 | 负载主动向飞行平台 FTS 引脚输出符合规格的 PWM 信号，飞行平台硬件检测后直接停桨 |
| 依赖链路 | 依赖软件指令链路（SDK 回调） | 不依赖软件链路，纯硬件级别触发 |
| 可靠性 | 回调失败时飞控会持续重试 | 硬件直接响应，无需重试机制 |
| 典型场景 | 飞行器飞出 GEO Caging 区域时由飞控主动触发 | 负载设备检测到紧急情况后主动触发停桨 |

## 功能介绍

:::warning 注意：
以下代码均为参考示例，旨在帮助开发者理解各功能的调用流程和实现思路。开发者可根据自身负载设备的实际硬件特性和应用场景进行适配和调整。
:::

### 使用 FTS 功能

开发者需要提供 FTS 信号回调函数，在回调函数里面实现 FTS 信号的触发，并返回正确的执行结果。若返回值不正确，FTS 回调将会被持续触发执行，保证通知到位。

:::warning 注意：
- 因为 FTS 触发是飞行周期一次性行为，所以只提供回调函数的注册接口，不提供注销接口。
- 对于 Matrice 3D 机型，请使用此 FTS 软件回调方式。
- Matrice 5TD、Matrice 400、Matrice 4D/4TD/4E/4T 机型不支持 FTS 软件回调，请使用下方"使用 EFTS 功能"章节中的硬件触发方式。
:::

下图展示了 FTS 软件回调的完整流程：开发者先初始化飞行控制模块并注册回调函数，当飞控触发 FTS 事件时，SDK 会调用已注册的回调函数，若回调返回失败，飞控将持续重新触发直到成功。

#### 初始化飞行控制模块

在使用飞行控制功能的相关接口之前，需要先调用 DjiTest_FlightControlInit 接口初始化飞行控制模块。

```c
returnCode = DjiTest_FlightControlInit(ridInfo);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Init flight Control sample failed,error code:0x%08llX", returnCode);
    return returnCode;
}
```

#### 实现 FTS 回调函数

在实际环境中，开发者需要在回调中实现 FTS 信号的触发动作（如输出 PWM 停桨信号），并返回执行结果。若返回失败，飞控将再次触发该回调。以下示例代码模拟了首次触发失败、飞控重试后成功的场景，供开发者参考：

```c
static uint32_t s_ftsTriggerCount = 0;

T_DjiReturnCode DjiTest_TriggerFtsEventCallback(void)
{
    USER_LOG_INFO("Received FTS Trigger event, count = %d.", s_ftsTriggerCount);

    if (s_ftsTriggerCount == 0) {
        /* 模拟首次触发失败场景：返回错误值，飞控将再次调用此回调 */
        USER_LOG_WARN("Note: Simulate a trigger failure scenario and return an error value, "
                      "this function will be invoked again.");
        s_ftsTriggerCount++;
        return DJI_ERROR_SYSTEM_MODULE_CODE_SYSTEM_ERROR;
    } else {
        /* 实际开发中，在此处通过 PWM 信号触发 FTS 停桨动作 */
        USER_LOG_WARN("Note: This is an empty implementation, and the FTS signal "
                      "needs to be triggered by the PWM signal.");
        return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
    }
}
```

#### 注册回调函数

```c
returnCode = DjiFlightController_RegTriggerFtsEventCallback(DjiTest_TriggerFtsEventCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Register trigger FTS event callback failed.");
    return returnCode;
} else {
    s_isFtsCallbackRegistered = true;
    USER_LOG_INFO("Register trigger FTS event callback successfully."
                    "Please wait for the aircraft to trigger the payload to execute FTS action.");
}
```

### 使用 EFTS 功能

EFTS 通过负载接口向飞行平台输出特定规格的硬件 PWM 信号，在满足电压、频率和占空比等要求时，飞行平台会立即执行 **电机停桨/停转** 操作，而不依赖于软件指令链路。

#### 机型支持与硬件信号要求

| 机型 | 支持接口 | PWM 频率 | 占空比 | 电压 |
|------|---------|---------|--------|------|
| Matrice 5TD | E-Port V3 接口 FTS 引脚 | 400 Hz | 50% | 3.3 V |
| Matrice 400 | 第 4 个 E-Port V2 接口 FTS 引脚 | 400 Hz | 50% | 3.3 V |
| Matrice 4D / 4TD | E-Port Lite 接口 | 200 Hz | 50% | 3.3 V |
| Matrice 4E / 4T | E-Port 接口、E-Port Lite 接口 | 200 Hz | 50% | 3.3 V |

:::warning 注意：
- 负载设备需根据上表中对应机型的参数，向指定接口的 FTS 引脚输出合规的 PWM 信号。
- Matrice 5TD 机型约束：
  - EFTS 功能不能与基于 PPS 信号的功能（如时间同步）同时使用。若已启用基于 PPS 信号的功能，需先关闭该功能并重新插拔负载后，方可使用 EFTS 功能。
  - 同一时刻只能有一个负载口向飞机发送 PWM 波触发 EFTS 功能，否则紧急制动功能可能无法正常实现。
:::

下图展示了 EFTS 硬件触发的完整流程：开发者先在地面使能 FTS PWM 触发端口，飞行中由负载输出符合规格的 PWM 信号触发飞行平台停桨，最后通过订阅 ESC 数据确认停桨结果。

#### 使能 EFTS 功能触发源

在地面端使能 EFTS 功能触发源，选择/启用飞控侧的 FTS（电机停止）PWM 触发端口。

```c
T_DjiReturnCode DjiFts_SelectFtsPwmTrigger(E_DjiMountPosition position);
```

#### 触发停桨

负载通过输出符合规格的 FTS 硬件 PWM 信号触发飞行平台停桨。触发后，可通过订阅 `DJI_FC_SUBSCRIPTION_TOPIC_ESC_DATA` 获取各电调的转速和状态，以确认停桨是否生效。当所有电调的 `speed` 为 0 时，表示停桨成功。

```c
T_DjiFcSubscriptionEscData escData;

/* 订阅 ESC 数据，确认停桨结果 */
returnCode = DjiFcSubscription_GetLatestValueOfTopic(
    DJI_FC_SUBSCRIPTION_TOPIC_ESC_DATA,
    (uint8_t *)&escData,
    sizeof(T_DjiFcSubscriptionEscData),
    NULL);

if (returnCode == DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    for (int i = 0; i < 8; i++) {
        USER_LOG_INFO("ESC[%d]: speed=%d rpm, current=%d mA", 
                      i, escData.esc[i].speed, escData.esc[i].current);
    }
}
```

### 电机慢转检测（可选）

在 EFTS 场景下，开发者可通过电机慢转接口在地面预检阶段验证 FTS 信号链路是否正常。慢转检测流程为：启动慢转 → 查询 ESC 状态确认进入慢转模式 → 停止慢转。

#### 启动电机慢转

```c
returnCode = DjiFlightController_StartSlowRotateMotor();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Start slow rotate motor failed: 0x%08llX", returnCode);
    return returnCode;
}
```

#### 获取 ESC 慢转状态

启动慢转后，通过 `DjiFlightController_GetElectronicSpeedControllerStatus()` 查询电调状态，确认所有电机是否已进入慢转模式：

| 状态值 | 说明 |
|--------|------|
| DJI_FLIGHT_CONTROLLER_NO_MOTOR_IN_SLOW_ROTATE_MODE | 无电机处于慢转模式 |
| DJI_FLIGHT_CONTROLLER_SOME_MOTOR_IN_SLOW_ROTATE_MODE | 部分电机处于慢转模式 |
| DJI_FLIGHT_CONTROLLER_ALL_MOTOR_IN_SLOW_ROTATE_MODE | 所有电机均已进入慢转模式 |

```c
E_DjiFlightControllerElectronicSpeedControllerStatus escStatus;

returnCode = DjiFlightController_GetElectronicSpeedControllerStatus(&escStatus);
if (returnCode == DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_INFO("ESC slow rotate status: %d", escStatus);
    if (escStatus == DJI_FLIGHT_CONTROLLER_ALL_MOTOR_IN_SLOW_ROTATE_MODE) {
        USER_LOG_INFO("All motors are in slow rotate mode, FTS signal chain verified.");
    }
}
```

#### 停止电机慢转

```c
returnCode = DjiFlightController_StopSlowRotateMotor();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Stop slow rotate motor failed: 0x%08llX", returnCode);
    return returnCode;
}
```
