## 概述
基于 PSDK 开发的负载设备具有机型信息获取功能，能够主动获取飞行器的型号、负载设备挂载的位置以及用户使用的移动端 App 等信息，加载不同的配置文件，方便用户使用负载设备。

:::tip 说明：
 将使用 PSDK 开发的负载设备安装到飞行器上，在开机初始化 5s 后才能够获取到飞行器正确的数据信息。
:::

## 基础概念

### 信息获取
信息获取是指负载设备能够**主动获取并记录**飞行器上如飞行器型号、硬件平台类型和负载设备挂载位置等数据信息。

使用 PSDK 开发的负载设备在初始化后，即可获取到如下信息：
* 基本信息：飞行器型号、硬件平台类型和负载挂载位置
* 移动端 App 信息：App 的系统语言和 App 的屏幕类型

### 获取飞行器基本信息

通过 `DjiAircraftInfo_GetBaseInfo()` 接口可获取飞行器的型号和负载设备的挂载位置等基本信息。

```c
T_DjiAircraftInfoBaseInfo aircraftInfoBaseInfo;
djiStat = DjiAircraftInfo_GetBaseInfo(&aircraftInfoBaseInfo);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("get aircraft base info error");
    return DJI_ERROR_SYSTEM_MODULE_CODE_SYSTEM_ERROR;
}

USER_LOG_INFO("aircraft type: %d, mount position: %d.", 
              aircraftInfoBaseInfo.aircraftType, aircraftInfoBaseInfo.mountPosition);
```

### 获取移动端 App 信息

通过 `DjiAircraftInfo_GetMobileAppInfo()` 接口可获取当前连接的移动端 App 的系统语言和屏幕类型。

```c
T_DjiMobileAppInfo mobileAppInfo;
djiStat = DjiAircraftInfo_GetMobileAppInfo(&mobileAppInfo);
if (djiStat != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("get mobile app info error");
} else {
    USER_LOG_INFO("app language: %d, screen type: %d.", 
                  mobileAppInfo.appLanguage, mobileAppInfo.appScreenType);
}
```

:::tip 说明：
 若遥控器或 App 未连接飞行器，获取到的 App 语言和屏幕类型将返回 unknown。
:::
