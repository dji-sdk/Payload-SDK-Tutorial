## 概述

基于 PSDK 负载与 Matrice 400 搭配进行运载模式开发，可设置 Matrice 400 的运载模式，从而实现更安全、更可靠的长距离运输作业控制。

:::tip 说明：
* 目前仅 Matrice 400 支持。
* 使用对象：1 个 PSDK 设备和 1 台 Matrice 400 飞行器。其中，E1 至 E4 接口支持连接 E-Port V2 和 SkyPort V3；若在 E4 接口外接扩展坞，则 E-Port V2 开发板最多可扩展支持 7 个接口。
* 使用范围：可通过 PSDK 设置运载模式。
* 使用约束：PSDK 设备需通过认证。Matrice 400 搭载的运载箱尺寸请遵循 DJI 官方要求，以确保系统处于安全、可靠的运行状态，具体尺寸要求详见 [附件](https://terra-1-g.djicdn.com/6189933d30024fc1b331bffe4fe41837/matrice-400/DJI_Matrice_400_Transport_Case_Drawing_Delivery_Mode_Application_Guide_CN.zip)。
:::

### 设置负载类型

开发者可以通过 `DjiCore_SetSdkDeviceType()` 设置 PSDK 设备的负载类型，以使飞行器进入运载模式。当负载类型为运载脚架时需要进行设置，并且必须在执行 `DjiCore_Init` 之前调用。

```c
// 必须在 DjiCore_Init() 之前调用
returnCode = DjiCore_SetSdkDeviceType(DJI_SDK_DEVICE_TYPE_TRANSPORT_BOX);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set SDK device type error: 0x%08llX", returnCode);
    return returnCode;
}

// 然后再初始化 PSDK 核心模块
returnCode = DjiCore_Init(&userInfo);
```
