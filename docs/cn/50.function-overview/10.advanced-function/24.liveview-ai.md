## 概述

PSDK 提供了基于妙算3的 AI 识别功能，支持开发者获取相机码流解码后的图像数据，利用妙算3的 AI 算力进行目标识别，并将识别结果回传至 DJI Pilot 进行渲染显示。

:::warning 注意：
* 当前仅在 Matrice 400 无人机挂载 H30 相机和 DJI 妙算3 场景下支持该功能。
* 编解码回调函数中均不允许进行阻塞耗时操作，推荐创建独立线程进行目标识别等功能。
:::

## 基础概念

### AI 识别流程

妙算3支持获取挂载在 Matrice 400 飞机上的 H30/H30T 相机实时码流（1080P/4K）解码后的图像数据，并利用自身 AI 算力进行目标识别。识别结果有两种回传方式：

| 回传方式 | 说明 |
|---------|------|
| 编码到码流 | 将识别结果元数据通过 DjiLiveview_EncodeAFrameToH264 编码到 H.264 码流中，再通过 DjiPayloadCamera_SendVideoStream 推送至 Pilot |
| 直接推送 | 通过 DjiLiveview_SendAiMetaToPilot 直接将识别结果推送至 Pilot，渲染在 H30 相机图传页面 |

### 目标类型

SDK 预定义了以下目标类型（`E_DjiLiveViewTargetObjectType`）：

| 类型 | 说明 |
|------|------|
| Person | 行人 |
| Car | 汽车 |
| Boat | 船只 |
| Human Face | 人脸 |
| Bird | 鸟类 |
| Beacon | 信标 |
| GPS | GPS 标记 |
| Moving Target | 移动目标 |

开发者也可以通过 `DjiLiveview_RegUserAiTargetLableList` 注册自定义的目标类别。

### 目标跟踪状态

识别到的目标具有跟踪状态（`E_DjiLiveViewTargetObjectState`），包括：已跟踪（Tracked）、丢失（Lost）、重新检测到（Redetected）等。

### 识别结果数据格式

AI 识别结果使用 `T_DjiLiveViewStandardMetaData` 格式，包含一组 `T_DjiLiveViewBoundingBox` 边界框信息，每个边界框包含目标 ID、类型、状态和 2D 坐标（中心点、宽高、距离）。

### 注册目标类别信息

调用 `DjiLiveview_RegUserAiTargetLableList` 接口，向 DJI Pilot 注册用户自定义的目标类别信息，用于 AI 识别结果渲染。

```c
returnCode = DjiLiveview_RegUserAiTargetLableList(YOLO_LABLES_NUM, s_classLables);
```

### 获取解码图像数据

DJI PSDK 支持用户获取相机码流解码后的 NV12、RGB PLANAR、RGB PACKED 格式的图像数据。调用 `DjiLiveview_StartImageStream` 接口，指定挂载位置、码流 ID、像素格式和回调函数，即可订阅解码后的图像数据。

```c
returnCode = DjiLiveview_StartImageStream(CameraPostion, MediaResource,
                                          PIXFMT_RGB_PACKED, DjiLiveview_RcvImageCallback);
```

### 初始化硬件编码器

调用 `DjiLiveview_RegEncoderCallback` 接口初始化妙算3内置硬件编码器，并注册回调函数接收编码器输出的 H.264 码流数据。

```c
returnCode = DjiLiveview_RegEncoderCallback(DjiLiveview_EncoderUseCallback);
```

### AI 识别结果编码

将 AI 识别的目标信息填写为 `T_DjiLiveViewStandardMetaData` 格式，通过 `DjiLiveview_EncodeAFrameToH264` 接口将原始图像与识别结果编码为 H.264 码流数据，再使用 `DjiPayloadCamera_SendVideoStream` 将码流回传至 Pilot 进行识别结果显示。

```c
returnCode = DjiLiveview_EncodeAFrameToH264(buf, len, imageInfo, metaData);
```

### AI 识别结果推送

也可以通过 `DjiLiveview_SendAiMetaToPilot` 接口，直接将 `T_DjiLiveViewStandardMetaData` 格式的 AI 识别结果推送至 Pilot，该结果会直接渲染在 H30 相机图传页面。

```c
returnCode = DjiLiveview_SendAiMetaToPilot(metaData);
```

### 注销与清理

使用完毕后，按顺序注销目标类别、停止图像订阅、注销编码器回调。

```c
DjiLiveview_UnregUserAiTargetLableList();
DjiLiveview_StopImageStream(CameraPostion, MediaResource);
DjiLiveview_UnregEncoderCallback();
```

## 示例教程

在 `samples/sample_c++/module_sample/liveview/dji_liveview_object_detection.cpp` 中，`DjiUser_RunCameraAiDetectionSample` 示例演示了以下完整流程：

1. 获取 H30T 相机 1080P 实时码流并解码；
2. 使用 YOLO 算法进行目标识别；
3. 将识别结果填写为 `T_DjiLiveViewStandardMetaData`；
4. 通过两种方式推送结果至 Pilot 进行渲染。
