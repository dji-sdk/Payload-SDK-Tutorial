## 概述

开放 AR 能力接口提供对码流的 AR 图形绘制能力，可以在 DJI Pilot 码流界面上绘制出点、线、立体多边形、圆柱体和锥体旋转轴，实现码流画面上的增强现实信息叠加。

:::warning 注意：
该功能需搭载妙算3使用。
:::

## 基础概念

### AR 图形类型

AR 图形绘制能力包括以下几种类型：

| 图形类型 | 说明 |
|---------|------|
| 点 | 支持批量绘制，一次性最多绘制 16 个点。可附带文字标注和图标属性 |
| 线 | 将多个坐标点连接绘制成线段 |
| 立体多边形 | 在三维空间中绘制立体多边形，支持顶面、侧面、底面的独立控制 |
| 圆柱体 | 在三维空间中绘制圆柱体，通过圆心、半径和法向量定义 |
| 锥体旋转轴 | 在三维空间中绘制 3D 锥体旋转轴 |

每种图形均支持完整的 CRUD 操作（设置/更新/删除/清空）。

### AR 坐标系

AR 图形使用经纬度和高度坐标系（`T_DjiOpenArCoordinate`），通过经度（longitude）、纬度（latitude）和高度（altitude）定义图形在空间中的位置。

### 样式与资源配置

AR 图形的样式通过 `widget_config.json` 文件中的 `style_id` 进行关联配置。每个图形元素通过 `T_DjiOpenArIds` 结构体中的 `uuid` 唯一标识，`style_id` 关联在 `widget_config.json` 中描述的样式。

:::warning 注意：
下述代码中 "//" 后的内容为代码注释，在实际的 JSON 配置文件请勿添加该内容。
:::

`widget_config.json` 是一个用于配置控件静态属性的文件，其中包含 AR 图形绘制的样式配置，开发者可以根据需要更改配置的属性值。修改配置时，请务必严格遵守 [JSON](https://www.json.org/) 的语法规则，否则配置文件将无法使用。

### 重绘机制

在 Pilot 退出 Liveview 界面后再次进入时，原有的 AR 绘制图形会丢失。开发者应通过注册 `DjiLiveview_ArRegRefleshAllCallback` 回调函数，在收到重刷新通知时重新调用 AR 绘制接口进行重绘。

## 功能介绍

:::warning 注意：
以下代码均为参考示例，旨在帮助开发者理解各功能的调用流程和实现思路。开发者可根据自身负载设备的实际硬件特性和应用场景进行适配和调整。
:::

### 注册重绘通知回调

在开始绘制 AR 图形前，建议先注册重绘通知回调函数，确保在 Pilot 重新进入 Liveview 界面时能够重新绘制所有 AR 图形。

```c
T_DjiReturnCode DjiLiveview_ArRegRefleshAllCallback(DjiLiveview_ArRefleshAllCallback callback);
```

### 点的绘制

支持对点的批量绘制、更新、删除、清除操作。

:::tip 说明：
一次性最多绘制 16 个点。
:::

使用设置接口批量绘制点，点的样式在 `style_id` 参数中标识，关联在 `widget_config.json` 中描述。

```c
T_DjiReturnCode DjiLiveview_ArSetPoint(const T_DjiOpenArPointArray* entry);
```

通过更新接口，批量更新已经绘制的点：

```c
T_DjiReturnCode DjiLiveview_ArUpdatePoint(const T_DjiOpenArPointArray* entry);
```

通过删除接口，批量删除已经绘制的点：

```c
T_DjiReturnCode DjiLiveview_ArDeletePoint(const T_DjiOpenArDeletePointEntry* entry);
```

通过清空接口，按 resource_id 清空已经绘制的点：

```c
T_DjiReturnCode DjiLiveview_ArClearPoint(uint32_t resource_id);
```

### 线的绘制

支持对线进行设置、更新、删除、清除操作。

通过设置接口，将多个坐标点连接绘制成线：

```c
T_DjiReturnCode DjiLiveview_ArSetLine(const T_DjiOpenArLine* entry);
```

通过更新接口，重新绘制已有的线：

```c
T_DjiReturnCode DjiLiveview_ArUpdateLine(const T_DjiOpenArLine* entry);
```

通过删除接口，批量删除已绘制的线：

```c
T_DjiReturnCode DjiLiveview_ArDeleteLine(const T_DjiOpenArDeleteLineEntry* entry, uint32_t entry_len);
```

通过清除接口，清空所有已绘制的线：

```c
T_DjiReturnCode DjiLiveview_ArClearLine();
```

通过更新接口，重新绘制已有的多边形：

通过清除接口，清空所有已绘制的多边形：
