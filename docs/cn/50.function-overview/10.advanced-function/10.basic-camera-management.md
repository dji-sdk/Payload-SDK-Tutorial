## 概述

为方便开发者在 PSDK 的基础上快速开发出控制 DJI 无人机上相机的功能，DJI PSDK 提供了相机管理功能，开发者基于相机管理的接口能够同时设置并获取无人机上多个相机的感光度、光圈、快门和曝光等参数的值，控制相机实现拍照、录像及指点变焦等功能。
:::tip 说明：
Matrice 400、Matrice 4、Matrice 4D 及未来机型，使用该功能需搭配妙算3。
:::
开发者能够：
- 获取相机基础信息（类型、固件版本、连接状态）
- 控制拍摄功能（单拍、连拍、定时拍、录像、重置相机设置）
- 设置曝光参数（曝光模式、ISO、光圈、快门速度、曝光补偿、AE 锁定）
- 控制变焦功能（光学变焦、指点变焦、红外变焦、联动变焦）
- 控制对焦功能（对焦模式、对焦目标点、对焦环）
- 设置拍摄格式与存储（照片/视频格式、多镜头存储、夜景模式、自定义文件扩展名）
- 管理媒体文件（下载文件列表、下载和删除文件）
- 管理存储（获取存储信息、格式化 SD 卡、SD 卡加密）
- 设置测光功能（测光模式、点测光）
- 使用红外相机功能（红外测温、FFC 校准、增益模式、激光测距）
- 使用点云功能（点云录制、订阅点云数据）

## 基础概念

### 相机挂载位置

相机管理模块通过挂载位置（`E_DjiMountPosition`）来指定操作目标，无人机上可同时安装多个相机。所有接口的第一个参数均为 `position`，用于指定要操作的相机挂载位置。

### 工作模式

相机支持以下工作模式，不同模式下可执行的操作不同：

| 工作模式 | 说明 |
|---------|------|
| 拍照模式（SHOOT_PHOTO） | 用于拍摄照片 |
| 录像模式（RECORD_VIDEO） | 用于录制视频 |
| 回放模式（PLAYBACK） | 用于预览和删除已有照片/视频 |
| 下载模式（MEDIA_DOWNLOAD） | 用于下载媒体文件到外部设备 |

### 曝光模式

相机支持以下曝光模式，部分参数仅在特定曝光模式下可设置：

| 曝光模式 | 可手动设置的参数 |
|---------|---------------|
| 自动曝光（PROGRAM_AUTO） | 曝光补偿（EV） |
| 快门优先（SHUTTER_PRIORITY） | 快门速度、曝光补偿 |
| 光圈优先（APERTURE_PRIORITY） | 光圈、曝光补偿 |
| 手动曝光（EXPOSURE_MANUAL） | ISO、光圈、快门速度 |

### 拍照模式

| 拍照模式 | 说明 |
|---------|------|
| 单拍（SINGLE） | 拍摄单张照片 |
| HDR（HDR） | 拍摄 HDR 合成照片 |
| 连拍（BURST） | 一次拍摄多张照片 |
| AEB（AEB） | 自动包围曝光，快速拍摄多张不同曝光的照片 |
| 定时拍（INTERVAL） | 按设定时间间隔持续拍照 |

### 对焦模式

| 对焦模式 | 说明 |
|---------|------|
| 手动对焦（MANUAL） | 通过设置对焦环值调整焦距 |
| 自动对焦（AUTO） | 根据对焦目标点自动计算焦距 |
| 连续自动对焦（AFC） | 持续自动追踪对焦 |

### 变焦方式

| 变焦方式 | 说明 |
|---------|------|
| 光学变焦 | 通过设置焦距或变焦因子调整，支持连续变焦 |
| 指点变焦 | 指定屏幕上的目标点和倍率，相机自动变焦到目标 |
| 红外变焦 | 设置红外镜头的变焦因子 |
| 联动变焦 | 分屏显示时红外和可见光镜头同步变焦 |

## 功能介绍

:::tip 说明：
建议在 Linux 平台上开发和验证相机管理功能。部分功能（如媒体文件下载、点云数据订阅）不支持 RTOS 平台。
:::

:::warning 注意：
以下代码均为参考示例，旨在帮助开发者理解各功能的调用流程和实现思路。开发者可根据自身负载设备的实际硬件特性和应用场景进行适配和调整。
:::

### 初始化

使用相机管理功能前，需要先调用 `DjiCameraManager_Init()` 接口初始化相机管理模块。

```c
USER_LOG_INFO("--> Step 1: Init camera manager module");
DjiTest_WidgetLogAppend("--> Step 1: Init camera manager module");
returnCode = DjiCameraManager_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Init camera manager failed, error code: 0x%08X\r\n", returnCode);
    goto exitCameraModule;
}
```

### 获取相机基础信息

初始化完成后，开发者可通过调用对应接口获取无人机上指定挂载位置的相机类型、固件版本和连接状态。

#### 获取相机类型和版本

```c
USER_LOG_INFO("--> Step 2: Get camera type and version");

if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get mounted position %d camera's type failed, error code: 0x%08X\r\n",
                   mountPosition, returnCode);
    goto exitCameraModule;
}
USER_LOG_INFO("Mounted position %d camera's type is %s",
              mountPosition,
              s_cameraTypeStrList[DjiTest_CameraManagerGetCameraTypeIndex(cameraType)].cameraTypeStr);

returnCode = DjiCameraManager_GetFirmwareVersion(mountPosition, &firmwareVersion);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get mounted position %d camera's firmware version failed, error code: 0x%08X\r\n",
                   mountPosition, returnCode);
    goto exitCameraModule;
}
USER_LOG_INFO("Mounted position %d camera's firmware is V%d.%d.%d.%d\r\n", mountPosition,
              firmwareVersion.firmware_version[0], firmwareVersion.firmware_version[1],
              firmwareVersion.firmware_version[2], firmwareVersion.firmware_version[3]);
```

### 设置曝光参数

相机管理提供一系列的 Set/Get 接口，可以设置或获取指定挂载位置的相机曝光参数。设置 ISO、光圈、快门速度等参数前，需先设置对应的曝光模式。

#### 设置曝光模式

```c
returnCode = DjiCameraManager_SetExposureMode(mountPosition,
                                               DJI_CAMERA_MANAGER_EXPOSURE_MODE_EXPOSURE_MANUAL);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set camera exposure mode failed, error code: 0x%08X\r\n", returnCode);
}
```

#### 设置 ISO

需先将曝光模式设为手动模式（`EXPOSURE_MANUAL`），再设置 ISO 值。

```c
T_DjiReturnCode returnCode;
E_DjiCameraManagerISO isoDataTemp;

returnCode = DjiCameraManager_GetISO(position, &isoDataTemp);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS &&
    returnCode != DJI_ERROR_CAMERA_MANAGER_MODULE_CODE_UNSUPPORTED_COMMAND) {
    USER_LOG_ERROR("Get mounted position %d camera's iso failed, error code: 0x%08X.",
                   position, returnCode);
    return returnCode;
}

if (isoDataTemp == isoData) {
    USER_LOG_INFO("The mounted position %d camera's iso is already what you expected.",
                  position);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}

returnCode = DjiCameraManager_SetISO(position, isoData);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS &&
    returnCode != DJI_ERROR_CAMERA_MANAGER_MODULE_CODE_UNSUPPORTED_COMMAND) {
    USER_LOG_ERROR("Set mounted position %d camera's iso %d failed, "
                   "error code: 0x%08X.", position, isoData, returnCode);
}

return returnCode;
```

#### 设置快门速度

需先将曝光模式设为手动模式或快门优先模式，再设置快门速度。部分较新机型（H20/H20T/M30 系列等）仅支持手动模式下设置快门速度。

```c
returnCode = DjiCameraManager_SetShutterSpeed(mountPosition,
                                               DJI_CAMERA_MANAGER_SHUTTER_SPEED_1_100);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set camera shutter speed failed, error code: 0x%08X\r\n", returnCode);
}
```

#### 设置光圈

需先将曝光模式设为手动模式或光圈优先模式，再设置光圈值。

```c
returnCode = DjiCameraManager_SetAperture(mountPosition, DJI_CAMERA_MANAGER_APERTURE_F_4);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set camera aperture failed, error code: 0x%08X\r\n", returnCode);
}
```

#### 设置曝光补偿（EV）

需先将曝光模式设为自动模式（`PROGRAM_AUTO`），再设置 EV 值。

```c
returnCode = DjiCameraManager_SetExposureCompensation(mountPosition,
                                                       DJI_CAMERA_MANAGER_EXPOSURE_COMPENSATION_P_0_3);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set camera EV failed, error code: 0x%08X\r\n", returnCode);
}
```

#### AE 锁定

自动曝光锁定可锁定当前的曝光参数，锁定后即使画面亮度变化，曝光参数也不会自动调整。

```c
/*!< Enable AE lock */
returnCode = DjiCameraManager_SetAELockEnabled(mountPosition, true);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set AE lock enabled failed, error code: 0x%08X\r\n", returnCode);
}

/*!< Check AE lock status */
bool aeEnable;
returnCode = DjiCameraManager_GetAELockEnabled(mountPosition, &aeEnable);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get AE lock status failed, error code: 0x%08X\r\n", returnCode);
}
USER_LOG_INFO("The camera ae lock mode now is %d", aeEnable);

/*!< Disable AE lock */
returnCode = DjiCameraManager_SetAELockEnabled(mountPosition, false);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set AE lock disabled failed, error code: 0x%08X\r\n", returnCode);
}
```

### 变焦功能

#### 光学变焦

通过 `DjiCameraManager_SetOpticalZoomParam()` 设置焦距参数实现光学变焦，或通过 `DjiCameraManager_StartContinuousOpticalZoom()` 进行持续变焦。

```c
/*!< Start continuous zoom in */

                                                          DJI_CAMERA_ZOOM_SPEED_NORMAL);

    USER_LOG_ERROR("Start continuous zoom failed, error code: 0x%08X\r\n", returnCode);

osalHandler->TaskSleepMs(8000);

/*!< Stop continuous zoom */
returnCode = DjiCameraManager_StopContinuousOpticalZoom(mountPosition);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Stop continuous zoom failed, error code: 0x%08X\r\n", returnCode);
}
```

#### 指点变焦

使用指点变焦前，需先启用指点变焦功能并设置变焦倍率，再指定目标点坐标执行变焦。

```c
    USER_LOG_ERROR("Enable tap zoom failed, error code: 0x%08X\r\n", returnCode);

/*!< Set tap zoom multiplier */

    USER_LOG_ERROR("Set tap zoom multiplier failed, error code: 0x%08X\r\n", returnCode);

/*!< Execute tap zoom at target */
T_DjiCameraManagerTapZoomPosData tapZoomPos = {0.3f, 0.3f};
returnCode = DjiCameraManager_TapZoomAtTarget(mountPosition, tapZoomPos);

    USER_LOG_ERROR("Tap zoom at target failed, error code: 0x%08X\r\n", returnCode);

```

#### 红外变焦

设置红外镜头的变焦因子。

```c
/*!< Set infrared zoom factor to 4x */
returnCode = DjiCameraManager_SetInfraredZoomParam(mountPosition, (dji_f32_t) 4);
```

在手动对焦模式下，通过设置对焦环值来调整焦距。先获取对焦环取值范围，再设置合法的对焦环值。

```c
/*!< Set focus mode to manual */

returnCode = DjiCameraManager_SetFocusRingValue(mountPosition, focusRingRange.minValue);

    USER_LOG_ERROR("Set focus ring value failed, error code: 0x%08X\r\n", returnCode);

/*!< Read back focus ring value */
uint16_t focusRingValue;
returnCode = DjiCameraManager_GetFocusRingValue(mountPosition, &focusRingValue);

    USER_LOG_ERROR("Get focus ring value failed, error code: 0x%08X\r\n", returnCode);

USER_LOG_INFO("Current focus ring value is %d", focusRingValue);
```

#### 多镜头拍摄/录像存储设置

```c
T_DjiCameraManagerStreamList streamList;

/*!< Get supported stream storage range */

    USER_LOG_ERROR("Get stream storage range failed, error code: 0x%08X\r\n", returnCode);

/*!< Set all streams to be stored for capture */
for (uint32_t i = 0; i < streamStorageRange.size; i++) {
    streamList.streamStorage[i] = streamStorageRange.streamStorage[i];
}
streamList.size = streamStorageRange.size;

returnCode = DjiCameraManager_SetCaptureRecordingStreams(mountPosition,
                                                          DJI_CAMERA_MANAGER_CAPTURE_OR_RECORDING_CAPTURE,
                                                          &streamList);

    USER_LOG_ERROR("Set capture storage streams failed, error code: 0x%08X\r\n", returnCode);
}

/*!< Read back capture storage streams */
```

#### 订阅点云数据

:::warning 注意：
- L2 相机支持搭载于 Matrice 300 RTK、Matrice 350 RTK 及 Matrice 400 平台。
- L3 相机支持搭载于 Matrice 400 平台。
- 在订阅实时三维点云数据时，需要关闭 DJI Pilot 2，否则 PSDK 将无法订阅相机的三维点云数据。
- 订阅实时点云数据通过 MOP 通道实现，不属于 `DjiCameraManager` 模块的接口。
:::

开发者可以通过调用以下 Sample 来订阅 L2/L3 相机的实时三维点云数据。

```c
returnCode = DjiTest_CameraManagerSubscribePointCloud(mountPosition);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Fail to download point cloud. position %d, error code 0x%08llX",
               mountPosition, returnCode);
    goto exitCameraModule;
}
```
