## 概述

使用 PSDK 的飞行器飞行控制功能，能够设置并获取飞行器各项基础参数，控制飞行器执行基础飞行动作，通过 Joystick 功能控制飞行器执行复杂的飞行动作，以及通过 FlyTo 指令飞行功能让飞行器自主飞至目标点。

:::tip 说明：
* Matrice 400、Matrice 4、Matrice 4D 及未来机型，使用该功能需搭配妙算3。
:::

## 基础概念

### 飞行器基础信息

PSDK 开放了设置飞行器基础参数的接口，开发者通过设置并获取飞行器的基础参数，能够实现对飞行器的精准控制：
* 开启或关闭 RTK 功能和避障功能（水平避障、上视觉避障、下视觉避障）
* 设置飞行器的返航点和返航高度
* 设置失控行为（Matrice 30/30T, Mavic 3 行业系列）
* 支持获取飞行器的[国家区域码](https://zh.wikipedia.org/wiki/ISO_3166-1)，便于产品适配不同国家的法规要求

具有 <a href="../basic-function/fc-subscription.html" target="_blank" rel="noopener noreferrer">数据订阅</a> 功能的应用程序，能够方便用户获取飞行器基础参数的信息：
* 获取 RTK 功能和避障功能的状态（水平避障、上视觉避障、下视觉避障）
* 获取飞行器返航点和返航高度

### Joystick 功能
Joystick 是一个飞行器综合控制功能，使用 Joystick 功能时，开发者根据实际的应用需要，通过调用 Joystick 中的接口，**同时设置飞行器使用的坐标系、水平控制的模式、垂直控制的模式、yaw 角度控制的模式和悬停模式**，才能设计出满足使用需求的飞行器飞行控制逻辑。

#### 设置坐标系
* 机体坐标系  
机体坐标系以飞行器的重心为原点，飞行器机头前进的方向为 X 轴，机头前进方向的右侧为 Y 轴，Z 轴是与 X 轴和 Y 轴在重心处相互垂直相交，并指向飞行器下方的轴（遵循 “右手法则”）。在机体坐标下，飞行器围绕 X 轴、Y 轴和 Z 轴旋转时的飞行动作，可称为横滚（飞行器仅绕 X 轴旋转）、俯仰（飞行器仅绕 Y 轴旋转）和偏航（飞行器仅绕 Z 轴旋转）。

* 大地坐标系  
大地坐标系也称世界坐标系或当地水平坐标系，在该坐标系中，飞行器指向地球正北的方向为 X 轴，正东的方向为 Y 轴，X 轴与 Y 轴相互垂直，Z 轴竖直指向飞行器下方，在满足 “右手法则” 的前提下，Z 轴将根据飞行器飞行的实际情况调节角度，因此该坐标系也称为 “北 - 东 - 地（N-E-D）坐标系”。

#### 设置水平控制模式
* 姿态角控制模式：在该模式下，水平方向的指令为飞行器的姿态角。(在机体坐标系下，该角度为 roll 和 pitch)
* 速度控制模式：在该模式下，水平方向的指令为飞行器的速度
* 位置控制模式：在该模式下，水平方向的指令为飞行器的位置
:::tip 说明：
 当位置指令的模不为 0 时，飞行器会以指定的速度向前飞行，否则，飞行器将悬停在指定的位置。
:::

* 角速度控制：在该模式下，水平方向的指令为飞行器的旋转角速度

#### 设置飞行器悬停模式
仅在**水平控制模式中的速度控制**模式下，开发者可以设置飞行器的悬停模式：
* 开启稳定模式：开启稳定模式后，飞行器将在指定的位置上悬停
* 关闭稳定模式：关闭稳定模式后，飞行器将按照速度命令飞行，当飞行器的前进速度为 0 时候，飞行器可能会随风飘动

#### 设置垂直控制模式
* 速度控制模式：控制飞行器垂直方向的速度
* 位置控制模式：控制飞行器垂直方向的位置，该位置为相对于起飞点的绝对位置
* 油门控制模式：控制飞行器的油门

#### 设置 yaw 角度控制模式
* 角度控制模式：在该模式下，yaw 方向旋转的指令为 yaw 的角度
* 角速率控制模式：在该模式下，yaw 方向旋转的指令为 yaw 的角速率

### 控制权说明
在调用飞行器控制接口之前，需要先调用`DjiFlightController_ObtainJoystickCtrlAuthority` 接口来获取飞行器的控制权，在飞行器控制权生效前，飞行器控制命令接口将无法生效。

控制权：是指当前具备控制飞行器的权限，控制对象有 MSDK、PSDK、遥控器、大疆机场等，控制权允许抢夺和主动释放；

失控行为：当飞行器在控制过程中由于各种突发因素导致的不受控状态（如遥控器断联、PSDK 程序崩溃、飞行器低电量等场景）。进入失控模式后，飞行器的控制权会发生变化（部分机型）并执行对应的预设失控行为（如返航、降落、悬停）。

#### 飞行控制权策略说明
总体策略：飞行控制权无优先级，都可以进行抢夺控制，是否进行夺取控制权，可以根据控制权状态，业务自身决策。

当前涉及到的业务策略设计，主要有司空，遥控器和 PSDK，具体策略设计如下：
- 司空飞行控制：
  - 检测到遥控器具备飞行控制，则不进行抢夺控制权处理，主动放弃飞行任务。
  - 对于航线任务飞行，只会夺取一次飞行控制，如果中间被夺取，如 PSDK 获取控制权，则航线任务取消。
  - 对于驾驶舱手动飞行控制，会一直夺取控制权进行飞行控制。

- 遥控器飞行控制：只要有飞行任务需要执行，如航线或手动飞行，都会进行获取控制权，执行飞行控制。

- PSDK 飞行控制：提供控制权获取接口，由于控制权无优先级设计，随时可以进行获取控制权，进行飞行业务，如果存在遥控器、司空具备飞行任务，会出现控制权被夺取情况。

### 初始化

使用飞行控制功能前，需要先初始化飞行控制模块，同时初始化数据订阅模块，并订阅飞行状态、显示模式等关键信息，还需注册控制权切换事件回调。
<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/flight-control/fc_init.svg" width="30%" alt="初始化流程"/></span></p>
</div>

```c
T_DjiFlightControllerRidInfo ridInfo = {0};
ridInfo.latitude = 22.542812;   // 飞机当前纬度，单位：rad
ridInfo.longitude = 113.958902; // 飞机当前经度，单位：rad
ridInfo.altitude = 10;          // 飞机当前高度，单位：m

returnCode = DjiFlightController_Init(ridInfo);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Init flight controller module failed, error code:0x%08llX", returnCode);
    return returnCode;
}

// 初始化数据订阅模块
returnCode = DjiFcSubscription_Init();

// 订阅飞行状态
returnCode = DjiFcSubscription_SubscribeTopic(DJI_FC_SUBSCRIPTION_TOPIC_STATUS_FLIGHT,
                                              DJI_DATA_SUBSCRIPTION_TOPIC_10_HZ, NULL);

// 订阅显示模式（用于判断起飞/降落/返航等状态）
returnCode = DjiFcSubscription_SubscribeTopic(DJI_FC_SUBSCRIPTION_TOPIC_STATUS_DISPLAYMODE,
                                              DJI_DATA_SUBSCRIPTION_TOPIC_10_HZ, NULL);

// 注册控制权切换事件回调
returnCode = DjiFlightController_RegJoystickCtrlAuthorityEventCallback(
    DjiTest_FlightControlJoystickCtrlAuthSwitchEventCallback);
```

反初始化：

```c
DjiFlightController_DeInit();
DjiFcSubscription_DeInit();
```

在控制飞行器前，建议先设置并确认关键飞行参数，包括 RTK 开关、避障开关、返航高度、失控行为等。

### 获取与释放控制权

在调用任何飞行控制指令（起飞、降落、Joystick 等）前，必须先获取 Joystick 控制权；完成控制任务后，应主动释放控制权，以便其他设备接管。

```c
// 获取控制权
returnCode = DjiFlightController_ObtainJoystickCtrlAuthority();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Obtain joystick authority failed, error code: 0x%08X", returnCode);
    goto out;
}
s_osalHandler->TaskSleepMs(1000);

// ... 执行飞行控制 ...

// 释放控制权
returnCode = DjiFlightController_ReleaseJoystickCtrlAuthority();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Release joystick authority failed, error code: 0x%08X", returnCode);
}
```

控制权切换事件回调示例：

```c
static T_DjiReturnCode DjiTest_FlightControlJoystickCtrlAuthSwitchEventCallback(
    T_DjiFlightControllerJoystickCtrlAuthorityEventInfo eventData)
{
    switch (eventData.joystickCtrlAuthoritySwitchEvent) {
        case DJI_FLIGHT_CONTROLLER_MSDK_GET_JOYSTICK_CTRL_AUTH_EVENT:
            USER_LOG_WARN("MSDK obtains joystick control authority.");
            break;
        case DJI_FLIGHT_CONTROLLER_OSDK_GET_JOYSTICK_CTRL_AUTH_EVENT:
            USER_LOG_INFO("PSDK obtains joystick control authority.");
            break;
        case DJI_FLIGHT_CONTROLLER_RC_LOST_GET_JOYSTICK_CTRL_AUTH_EVENT:
            USER_LOG_WARN("RC lost, joystick control authority transferred.");
            break;
        default:
            USER_LOG_INFO("Joystick ctrl authority event: %d", eventData.joystickCtrlAuthoritySwitchEvent);
            break;
    }
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}
```

### Joystick 飞行控制
使用 Joystick 功能需要先设置控制模式，再循环发送控制指令。

<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/flight-control/fc_joystick.svg" width="30%" alt="Joystick 控制流程"/></span></p>
</div>

下面以**位置控制模式**飞至目标点为例：

**1. 设置 Joystick 模式**

```c
T_DjiFlightControllerJoystickMode joystickMode = {
    DJI_FLIGHT_CONTROLLER_HORIZONTAL_POSITION_CONTROL_MODE,  // 水平：位置控制
    DJI_FLIGHT_CONTROLLER_VERTICAL_POSITION_CONTROL_MODE,    // 垂直：位置控制
    DJI_FLIGHT_CONTROLLER_YAW_ANGLE_CONTROL_MODE,            // Yaw：角度控制
    DJI_FLIGHT_CONTROLLER_HORIZONTAL_GROUND_COORDINATE,      // 坐标系：大地坐标系
    DJI_FLIGHT_CONTROLLER_STABLE_CONTROL_MODE_ENABLE,        // 开启稳定模式
};

DjiFlightController_SetJoystickMode(joystickMode);
```

:::tip 说明：
若在飞行过程中不改变 Joystick 设置项，则仅在飞行任务开始时设置一次 Joystick 模式即可。
:::

**2. 循环发送控制指令**

```c
// z 轴方向的位置为相对于起飞点的绝对高度
while (elapsedTimeInMs < timeoutInMilSec) {
    T_DjiFcSubscriptionPositionFused currentGPSPosition = DjiTest_FlightControlGetValueOfPositionFused();
    T_DjiFcSubscriptionQuaternion currentQuaternion = DjiTest_FlightControlGetValueOfQuaternion();
    dji_f32_t currentHeight = DjiTest_FlightControlGetValueOfRelativeHeight();

    float yawInRad = DjiTest_FlightControlQuaternionToEulerAngle(currentQuaternion).z;

    // 计算当前位置与起始点的偏移
    T_DjiTestFlightControlVector3f localOffset = DjiTest_FlightControlLocalOffsetFromGpsAndFusedHeightOffset(
        currentGPSPosition, originGPSPosition, currentHeight, originHeightBaseHomePoint);

    // 计算剩余位移
    T_DjiTestFlightControlVector3f offsetRemaining = DjiTest_FlightControlVector3FSub(offsetDesired, localOffset);

    // 限制速度并发送指令
    T_DjiTestFlightControlVector3f positionCommand = offsetRemaining;
    DjiTest_FlightControlHorizCommandLimit(speedFactor, &positionCommand.x, &positionCommand.y);

    T_DjiFlightControllerJoystickCommand joystickCommand = {
        positionCommand.x, positionCommand.y,
        offsetDesired.z + originHeightBaseHomePoint,
        yawDesiredInDeg
    };
    DjiFlightController_ExecuteJoystickAction(joystickCommand);

    // 判断是否到达目标位置
    if (DjiTest_FlightControlVectorNorm(offsetRemaining) < posThresholdInM &&
        fabs(yawInRad / s_degToRad - yawDesiredInDeg) < yawThresholdInDeg) {
        withinBoundsCounter += cycleTimeInMs;
    }
    if (withinBoundsCounter >= withinControlBoundsTimeReqmt) break;

    s_osalHandler->TaskSleepMs(cycleTimeInMs);
    elapsedTimeInMs += cycleTimeInMs;
}
```

**速度控制模式**示例：

```c
T_DjiFlightControllerJoystickMode joystickMode = {
    DJI_FLIGHT_CONTROLLER_HORIZONTAL_VELOCITY_CONTROL_MODE,
    DJI_FLIGHT_CONTROLLER_VERTICAL_VELOCITY_CONTROL_MODE,
    DJI_FLIGHT_CONTROLLER_YAW_ANGLE_RATE_CONTROL_MODE,
    DJI_FLIGHT_CONTROLLER_HORIZONTAL_GROUND_COORDINATE,
    DJI_FLIGHT_CONTROLLER_STABLE_CONTROL_MODE_ENABLE,
};
DjiFlightController_SetJoystickMode(joystickMode);

// 以 5 m/s 速度向上飞行 2 秒
T_DjiFlightControllerJoystickCommand joystickCommand = {0, 0, 5, 0};
for (int i = 0; i < 200; i++) {   // 200 × 10ms = 2s
    DjiFlightController_ExecuteJoystickAction(joystickCommand);
    s_osalHandler->TaskSleepMs(10);
}
```

### FlyTo 指令飞行

FlyTo 指令飞行让飞行器自主飞至指定 GPS 目标点，支持自动路径规划（避障）。
<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/flight-control/fc_flyto.svg" width="30%"/></span></p>
</div>

**1. 注册回调函数**

```c
// 注册任务状态回调（推送任务进度/剩余距离/状态机）
T_DjiReturnCode DjiTest_FlightControlOpenMisInfoCallback(T_DjiFlightControllerOpenMis eventData)
{
    USER_LOG_INFO("Mission state: %d, distance remaining: %.1f m",
                  eventData.mission_state_machine, eventData.distance_remaining);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}

// 注册未来飞行轨迹回调
T_DjiReturnCode DjiTest_FlightControlCoreTrajCallback(T_DjiFlightControllerCoreTraj eventData)
{
    USER_LOG_INFO("Trajectory push: %d points", eventData.point_num);
    return DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS;
}

DjiFlightController_RegisterOpenMisInfoCallBack(DjiTest_FlightControlOpenMisInfoCallback);
DjiFlightController_RegisterCoreTrajCallBack(DjiTest_FlightControlCoreTrajCallback);
```

:::tip 说明：
`T_DjiFlightControllerOpenMis` 结构体中的 `progress` 和 `success_rate` 字段为预留字段，目前始终为 0，属正常现象。
:::

**2. 配置参数并下发目标点**

```c
// 设置路径规划模式（1：手动高度模式）
returnCode = DjiFlightController_SetPlanningAlgo(1);

// 设置最大飞行速度（单位：m/s，范围 1~15）
returnCode = DjiFlightController_SetMaxVelocity(10);

// 设置最低飞行高度（单位：m，仅手动高度模式有效）
returnCode = DjiFlightController_SetMinFlightHeight(100.0f);

// 下发目标点并启动任务
T_DjiFlightControllerStartMissionReq req = {0};
T_DjiFlightControllerStartMissionRsp rsp = {0};

req.version = 1;
req.operation = 0;             // 0：新任务
req.mea = 1.0f;                // 最低航线高度（m，相对起飞点）
req.fly_vel = 10;              // 最大飞行速度（m/s）
req.goal_num = 1;              // 目标点数量（目前仅支持 1 个点）
req.cmd_mode_point_info->lat = 0.394052f;   // 目标点纬度（rad）
req.cmd_mode_point_info->lon = 1.989871f;   // 目标点经度（rad）
req.cmd_mode_point_info->alt = 10.0f;       // 目标点高度（m，椭球高）

returnCode = DjiFlightController_SetModeStartMission(req, &rsp);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Start FlyTo mission failed, error code: 0x%08X", returnCode);
} else {
    USER_LOG_INFO("FlyTo mission started, ret_code: %d", rsp.ret_code);
}
```

**3. 获取退出原因**

```c
uint16_t exit_reason;
returnCode = DjiFlightController_GetExitReason(&exit_reason);
if (returnCode == DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_INFO("FlyTo exit reason: %d", exit_reason);
}
```

### 电机与安全控制

#### 电机解锁与上锁

```c
// 解锁电机（螺旋桨开始怠速旋转）
returnCode = DjiFlightController_TurnOnMotors();

// 上锁电机（螺旋桨停止旋转）
returnCode = DjiFlightController_TurnOffMotors();
```

#### 紧急刹停

`ArrestFlying` 在地面时会停桨，在空中时仅在 App 上显示告警，飞行器继续飞行：

```c
// 触发紧急刹停
returnCode = DjiFlightController_ArrestFlying();

// 取消紧急刹停（恢复后才能继续飞行）
returnCode = DjiFlightController_CancelArrestFlying();
```

#### 紧急停桨

:::warning 注意：
`EmergencyStopMotor` 在空中使用会导致飞行器坠毁，请仅在地面或确认安全的情况下使用！
:::

```c
returnCode = DjiFlightController_EmergencyStopMotor(
    DJI_FLIGHT_CONTROLLER_ENABLE_EMERGENCY_STOP_MOTOR, "debug_msg");
```
