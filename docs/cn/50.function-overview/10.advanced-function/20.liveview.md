## 概述

PSDK 提供了获取相机码流的功能，开发者可以通过 Liveview 模块订阅无人机上 FPV 相机或云台相机的实时视频流，获取 H.264 码流或解码后的 RGB 图像数据，用于存储、转发、解码显示或 AI 识别等场景。

:::tip 说明：
* 仅使用 Linux 和 RTOS 系统开发的应用程序支持使用获取相机码流功能。
* 使用该功能时，需使用 USB 线接收无人机相机的码流数据。
* Matrice 400、Matrice 4、Matrice 4D 及未来机型，使用该功能需搭配妙算3。
:::

## 基础概念

### 相机码流
为满足开发者使用 PSDK 开发的应用程序对获取相机码流的功能，PSDK 提供了获取相机码流的功能，支持获取 FPV 相机或获取 1 号云台相机 H.264 码流和 RGB 图像。

:::tip 说明：
* 无人机**支持获取 FPV 相机和所有云台相机的 H.264 码流**。
* 由于获取 FPV 相机码流和获取 1 号云台上相机码流的回调函数在各自独立的线程中运行，OpenCV 的 imshow 模块仅支持在一个线程中运行，因此仅支持开发者获取 FPV 相机或获取 1 号云台相机 H.264 码流和 RGB 图像。
* 获取相机码流后，请安装 FFmpeg 等解码器解码。
* 有关 H.264 标准码流的相关参考请参见 <a href="https://www.itu.int/rec/T-REC-H.264-201906-S/en">H.264 码流标准</a>。
:::


#### 相机 H.264 码流

开发者通过调用 `DjiLiveview_StartH264Stream()` 接口并注册回调函数，即可接收指定相机的 H.264 码流。SDK 收到码流数据后会自动触发回调函数，开发者在回调函数中对码流执行存储、解码或转发等处理。

:::tip 说明：
有关无人机视觉感知系统（感知灰度图码流、激光雷达点云、毫米波雷达点云等）的详细说明，请参见 <a href="./perception-data.html" target="_blank" rel="noopener noreferrer">感知数据</a>。
:::

### 编码策略

通过 `DjiLiveview_SetEncodingStrategy()` 可设置码流的编码策略和目标码率。支持的编码策略如下：

| 编码策略 | 说明 |
|---------|------|
| OnDemand I 帧 | 仅在主动请求时发送 I 帧（默认策略） |
| GDR 编码 | 使用渐进式解码刷新（Gradual Decoder Refresh），无需完整 I 帧即可恢复画面，适用于弱网或对延迟敏感的场景 |
| 周期 I 帧 | 按固定周期自动插入 I 帧 |

:::tip 说明：
* 建议先调用 `DjiLiveview_StartH264Stream()` 开始码流后再设置编码策略。
* 不同视频流和分辨率的可配置码率范围可能不同，实际码率可能在配置值基础上浮动 20%。
:::

## 功能介绍

:::tip 说明：
 使用 PSDK 开发获取相机码流功能时，请使用 **Linux** 或 **RTOS** 平台。
:::

:::warning 注意：
以下代码均为参考示例，旨在帮助开发者理解各功能的调用流程和实现思路。开发者可根据自身负载设备的实际硬件特性和应用场景进行适配和调整。
:::

### H.264 码流获取

调用 `DjiLiveview_StartH264Stream()` 接口，指定相机位置、子相机源和回调函数，SDK 在收到 H.264 码流数据时会自动调用回调函数推送数据。调用 `DjiLiveview_StopH264Stream()` 停止接收。

```c
// 构造 H.264 码流接收回调函数
static void DjiTest_PayloadCameraStreamCallback(E_DjiLiveViewCameraPosition position, const uint8_t *buf,
                                                uint32_t bufLen)
{
    FILE *fp = NULL;

    fp = fopen(s_payloadCameraStreamFilePath, "ab+");
    if (fp == NULL) {
        return;
    }

    fwrite(buf, 1, bufLen, fp);
    fflush(fp);
    fclose(fp);
}

// 开始接收 H.264 码流
returnCode = DjiLiveview_StartH264Stream(DJI_LIVEVIEW_CAMERA_POSITION_NO_1,
                                         DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT,
                                         DjiTest_PayloadCameraStreamCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Request h264 of payload failed, error code: 0x%08X", returnCode);
}

// 停止接收 H.264 码流
returnCode = DjiLiveview_StopH264Stream(DJI_LIVEVIEW_CAMERA_POSITION_NO_1,
                                        DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Stop h264 stream failed, error code: 0x%08X", returnCode);
}
```

:::tip 说明：
* 开发者获取 H.264 码流后，使用 **ffplay -flags2 showall xxx.h264** 命令即可播放所获取的 H.264 文件。
* 使用 Sample `test_liveview` 可获取 H.264 码流数据并保存为本地 .h264 文件。
* 使用 Sample `camera-stream-callback-sample` 和 `camera-stream-poll-sample` 可借助 FFmpeg 对 H.264 码流解码。
:::

### RGB 图像获取

调用 `DjiLiveview_StartImageStream()` 接口，指定相机位置、子相机源、像素格式和回调函数，即可接收解码后的 RGB 图像数据。调用 `DjiLiveview_StopImageStream()` 停止接收。

:::tip 说明：
* 该接口仅在妙算 3 平台上支持。
* 支持的像素格式包括 NV12、RGB Planar 和 RGB Packed。
:::

```c
// 构造图像数据接收回调函数
static void DjiTest_ImageCallback(E_DjiLiveViewCameraPosition position, const uint8_t *buf,
                                  uint32_t len, T_DjiLiveviewImageInfo imageInfo)
{
    USER_LOG_INFO("Received image: position=%d, width=%d, height=%d, frameId=%d",
                  position, imageInfo.width, imageInfo.height, imageInfo.frameId);
    // 开发者可在此处对图像数据进行处理，如保存、显示或分析
}

// 开始接收 RGB 图像
returnCode = DjiLiveview_StartImageStream(DJI_LIVEVIEW_CAMERA_POSITION_NO_1,
                                          DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT,
                                          PIXFMT_RGB_PACKED,
                                          DjiTest_ImageCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Start image stream failed, error code: 0x%08X", returnCode);
}

// 停止接收 RGB 图像
returnCode = DjiLiveview_StopImageStream(DJI_LIVEVIEW_CAMERA_POSITION_NO_1,
                                         DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT);
```

### I 帧请求

在 H.264 码流传输过程中，可通过 `DjiLiveview_RequestIntraframeFrameData()` 主动请求 I 帧数据，帮助解码器快速刷新画面。适用于解码出错或画面花屏时主动请求关键帧恢复。

```c
returnCode = DjiLiveview_RequestIntraframeFrameData(DJI_LIVEVIEW_CAMERA_POSITION_NO_1,
                                                    DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Request I frame failed, error code: 0x%08X", returnCode);
}
```

### 编码策略配置

调用 `DjiLiveview_SetEncodingStrategy()` 可设置相机码流的编码策略和目标码率。建议在 `DjiLiveview_StartH264Stream()` 之后再调用此接口。

```c
T_DjiLiveviewCodecParamItem codecParam;
codecParam.strategy = DJI_LIVEVIEW_CODEC_STRATEGY_GDR;
codecParam.bitrate_kbps = 16000;  // 目标码率 16 Mbps

returnCode = DjiLiveview_SetEncodingStrategy(DJI_LIVEVIEW_CAMERA_POSITION_NO_1,
                                             DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT,
                                             &codecParam);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set encoding strategy failed, error code: 0x%08X", returnCode);
}
```

### 图传模式配置

调用 `DjiLiveview_SetHdvtSdrMode()` 可停止或恢复无人机原生的图传码流。飞机重启后将自动恢复为默认开启状态。

:::tip 说明：
该接口仅 M4T 机型支持。
:::

```c
// 静默模式 - 停止原生图传码流
returnCode = DjiLiveview_SetHdvtSdrMode(DJI_LIVEVIEW_HDVT_SDR_MODE_SILENCE_ALL);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Set HDVT SDR mode failed, error code: 0x%08X", returnCode);
}

// 正常模式 - 恢复原生图传码流
returnCode = DjiLiveview_SetHdvtSdrMode(DJI_LIVEVIEW_HDVT_SDR_MODE_NORMAL);
```

## 示例教程

以下以 SDK 示例代码 `test_liveview.c` 为基础，展示获取相机 H.264 码流的完整调用流程。

### 初始化 Liveview 模块

在使用码流功能前，需先调用 `DjiLiveview_Init()` 初始化 Liveview 模块。

```c
returnCode = DjiLiveview_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Liveview init failed, error code: 0x%08X", returnCode);
}
```

### 开始接收 H.264 码流

分别启动 FPV 相机和云台相机的 H.264 码流接收，SDK 将通过回调函数持续推送码流数据。

```c
// 开始接收 FPV 相机码流
returnCode = DjiLiveview_StartH264Stream(DJI_LIVEVIEW_CAMERA_POSITION_FPV,
                                         DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT,
                                         DjiTest_FpvCameraStreamCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Request h264 of fpv failed, error code: 0x%08X", returnCode);
}

// 开始接收云台相机码流
returnCode = DjiLiveview_StartH264Stream((E_DjiLiveViewCameraPosition)mountPosition,
                                         DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT,
                                         DjiTest_PayloadCameraStreamCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Request h264 of payload failed, error code: 0x%08X", returnCode);
}
```

### 定时请求 I 帧

在码流接收过程中，示例代码每隔 5 秒主动请求一次 I 帧，确保解码器能够定期刷新画面。

```c
for (int i = 0; i < TEST_LIVEVIEW_STREAM_STROING_TIME_IN_SECONDS; ++i) {
    USER_LOG_INFO("Storing camera h264 stream, second: %d.", i + 1);
    if (i % TEST_LIVEVIEW_STREAM_REQUEST_I_FRAME_TICK_IN_SECONDS == 0) {
        returnCode = DjiLiveview_RequestIntraframeFrameData((E_DjiLiveViewCameraPosition)mountPosition,
                                                            DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT);
        if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
            USER_LOG_ERROR("Request stream I frame failed, error code: 0x%08X", returnCode);
        }
    }
    osalHandler->TaskSleepMs(1000);
}
```

### 停止接收并反初始化

完成码流采集后，依次停止各相机的码流接收，并反初始化 Liveview 模块释放资源。

```c
// 停止 FPV 码流
returnCode = DjiLiveview_StopH264Stream(DJI_LIVEVIEW_CAMERA_POSITION_FPV,
                                        DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT);

// 停止云台相机码流
returnCode = DjiLiveview_StopH264Stream((E_DjiLiveViewCameraPosition)mountPosition,
                                        DJI_LIVEVIEW_CAMERA_SOURCE_DEFAULT);

// 反初始化 Liveview 模块
returnCode = DjiLiveview_Deinit();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Liveview deinit failed, error code: 0x%08X", returnCode);
}
```

## 常见问题

### 解码器解码时出现错误

受计算平台算力的制约，基于 PSDK 开发的应用程序在编解码时可能会出现如下问题：
* 解码速度较慢：解码器在解码第一帧时需要一段时间
* 帧丢失：计算平台算力不足
* 使用 FFmpeg 解码时出现报错：请在 Ubuntu 16.04 上尝试解码，且确认运行解码器的应用程序正确安装了 RNDIS、USB 及网口驱动，确保应用程序能够正确识别无人机。

### GDR 编码格式的 H20/H20T H.264 码流有时出现 I 帧

H20/H20T 为多镜头负载相机。在 DJI Pilot 切换镜头画面时，相机的 H.264 码流会插入 I 帧帮助 DJI Pilot 图传画面进行画面构建，因此在 H.264 码流中会出现 I 帧，不影响 GDR 格式的解码过程。
