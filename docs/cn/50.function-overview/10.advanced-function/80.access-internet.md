## 概述

负载设备可通过机载网络访问互联网。当无人机搭配 DJI 增强图传模块后，挂载在 EPort 口的妙算3可以利用增强图传模块的 4G 网络能力接入互联网，实现远程数据传输、云端通信等应用场景。

默认情况下，负载网络访问功能已经开启，无需进行额外操作（依赖增强图传模块安装在飞机上，且 4G 网络功能正常）。

:::tip 说明：
* 此功能目前仅妙算3支持。
* 环境准备：需要 Matrice 400 飞机、妙算3、DJI 增强图传模块和 DJI 遥控器。增强图传模块安装在飞机上并确保 4G 网络功能正常，妙算3接在 Matrice 400 的 EPort 口（支持 E1/E2/E3）。
:::

## 基础概念

### 支持机型

| 机型 | 说明 |
|------|------|
| Matrice 400 | 需搭配增强图传模块和妙算3 |
| Matrice 4TD / Matrice 4D | 需搭配增强图传模块和妙算3 |
| Matrice 4T / Matrice 4E | 需搭配增强图传模块和妙算3 |

### 增强图传状态

增强图传模块的开关状态可通过接口查询，返回值含义如下：

| 状态值 | 枚举 | 说明 |
|--------|------|------|
| 0 | DJI_ENHANCEED_TRANSMISSION_STATE_DISABLED | 增强图传已关闭 |
| 3 | DJI_ENHANCEED_TRANSMISSION_STATE_ENABLED | 增强图传已开启 |

### 查询增强图传状态

通过 `DjiAircraftInfo_GetEnhancedTransmission()` 接口查询增强图传模块的开关状态：

```c
E_DjiEnhancedTransmissionState state;
T_DjiReturnCode returnCode;

returnCode = DjiAircraftInfo_GetEnhancedTransmission(&state);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get enhanced transmission state failed, error code: 0x%08X", returnCode);
}

if (state == DJI_ENHANCEED_TRANSMISSION_STATE_ENABLED) {
    USER_LOG_INFO("Enhanced transmission is enabled.");
} else {
    USER_LOG_WARN("Enhanced transmission is disabled.");
}
```

### 网络状态告警

根据获取到的增强图传状态，可通过自定义 HMS 消息在 Pilot 上进行告警显示。例如当发现网络质量差且增强图传已开启时，可注入 HMS 告警提示用户，具体使用方法参考 <a href="../basic-function/hms-customization.html" target="_blank" rel="noopener noreferrer">自定义 HMS 功能</a>。

HMS 文本配置示例：
```json

```

## 常见问题

### 负载设备无法通过机载网络上网要怎么排查？

1. 确保飞机已经连接上增强图传模块，且 4G 网络正常，dongle 模块绿灯应常亮（也可在遥控器上查看网络配置是否正常）。
2. 确保飞机已经连接上妙算3，且接触良好，如果接触不良，请重新连接。
3. 重启飞机，重启妙算3后重试。
4. 如果以上步骤均无法解决，请咨询 DJI 技术支持。
