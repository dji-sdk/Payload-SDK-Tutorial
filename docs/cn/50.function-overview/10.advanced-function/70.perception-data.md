## 概述

为帮助开发者在没有 GPS 或 RTK 卫星的应用场景中实现无人机的自动化飞行控制，实现如精准悬停和避障等功能，DJI 开放了无人机视觉感知系统，包括视觉系统、六向红外感知系统，以及 Matrice 400 搭载的激光雷达感知系统和六向毫米波雷达感知系统。开发者通过 PSDK 提供的 API，可获取感知灰度图码流、激光雷达点云和毫米波雷达点云数据，结合感知与定位算法，开发出满足特定应用场景需求的高级应用程序。

:::tip 说明：
* 仅通过 Linux 和 RTOS 系统开发的应用程序支持感知数据获取功能。
* 使用感知数据获取功能时，需通过 USB 线或网线接收无人机视觉感知系统的原始数据。
* 开发者可在[大疆官网下载中心](https://www.dji.com/cn/downloads?site=brandsite&from=nav)获得对应机型的用户手册，查看视觉感知系统的组成及相机位置。
* Matrice 400、Matrice 4、Matrice 4D 及未来机型，使用该功能需搭配妙算 3。
* 要获取无人机感知数据，需将无人机解锁起飞，或连接 DJI Assistant 2 在模拟器中将无人机解锁起飞。
:::

## 基础概念

### 无人机感知系统

DJI 无人机的视觉感知系统主要由感知传感器和视觉感知算法构成。飞行过程中，感知传感器获取周围环境状态，协助无人机刹车、避障和精确悬停。

- Mavic 3E/3T、Matrice 30/30T、Matrice 300 RTK/350 RTK、Matrice 4D/4T/4E、Matrice 400 均支持获取所有感知传感器的灰度图码流。
- Matrice 400 额外支持获取激光雷达点云和毫米波雷达点云数据。

:::tip 说明：
* 悬停期间若无人机受到外部干扰，将自动返回原悬停点。
* 使用感知图像获取功能时，若无人机与遥控器断开连接，无人机将悬停。
:::

### 感知图像类型与分辨率

| 机型 | 方向 | 帧率 | 分辨率 |
|------|------|------|--------|
| Matrice 400 | 下 | 20 FPS | 512 × 640 |
| Matrice 400 | 前、左、右 | 20 FPS | 704 × 704 |
| Matrice 400 | 后 | 20 FPS | 704 × 896 |
| Matrice 400 | 上 | 20 FPS | 640 × 512 |
| Matrice 4D/4TD/4E/4T | 下 | 20 FPS | 640 × 512 |
| Matrice 4D/4TD/4E/4T | 前、后、左、右 | 20 FPS | 704 × 704 |

:::tip 说明：
* 由于链路带宽限制，目前所有机型只支持**同时订阅两路**灰度图像，且订阅两路后帧率会有所下降。
:::

### 感知图像元数据

视觉传感器产生的图像包含以下元数据：
- **时间戳**：所有视觉传感器共享同一计时器。有关时间同步的详细说明，请参见<a href="../basic-function/time-syn.html" target="_blank" rel="noopener noreferrer">时间同步</a>。
- **帧索引**：订阅感知灰度图后图像将附带帧索引，订阅或取消订阅不会改变或中断帧索引序号。

### 激光雷达点云元数据


飞行器起飞后，PSDK 可订阅 10 Hz 频率的激光雷达数据帧（`T_DjiLidarFrame`）。每一帧包含：
- 当前时间戳及无人机姿态信息
- 多个激光雷达数据包（`T_DjiPerceptionLidarDecodePkg`），每个数据包由数据包头（`T_DJIPerceptionLidarDataHeader`）和最多 96 个点（`T_DJIPerceptionLidarPoint`）组成

:::tip 说明：
激光雷达到机身 IMU 外参如下：<br>
旋转（四元数 w x y z）：`[ 0.0124277, -0.7083339, -0.70558153, 0.01622773 ]`<br>
平移（x y z，单位 m）：`[ 0.12922, 0, -0.234352 ]`
:::

## 功能介绍

:::tip 说明：
- 感知功能相关代码可参考 [GitHub 示例](https://github.com/dji-sdk/Payload-SDK/tree/master/samples/sample_c/module_sample/perception)。
- 建议安装 OpenCV 以显示感知灰度图像。
- 为避免处理视觉传感器图像的工作阻塞主线程，请创建一个独立的线程处理无人机视觉传感器的图像。
:::

:::warning 注意：
以下代码均为参考示例，旨在帮助开发者理解各功能的调用流程和实现思路。开发者可根据自身负载设备的实际硬件特性和应用场景进行适配和调整。
:::

### 初始化与反初始化

调用 `DjiPerception_Init()` 初始化感知模块，该接口需在 `DjiCore_Init()` 之后调用：

```c
returnCode = DjiPerception_Init();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Perception init failed, error code: 0x%08X", returnCode);
}
```

使用完毕后调用 `DjiPerception_Deinit()` 释放资源：

```c
returnCode = DjiPerception_Deinit();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Perception deinit failed, error code: 0x%08X", returnCode);
}
```

### 获取相机参数

调用 `DjiPerception_GetStereoCameraParameters()` 获取所有立体相机的内参与外参：

```c
T_DjiPerceptionCameraParametersPacket cameraParametersPacket = {0};
returnCode = DjiPerception_GetStereoCameraParameters(&cameraParametersPacket);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Get stereo camera parameters failed, error code: 0x%08X", returnCode);
}

// 遍历各方向相机参数
for (int i = 0; i < cameraParametersPacket.directionNum; i++) {
    // 左目内参矩阵（3x3，行优先）
    float *leftK = cameraParametersPacket.cameraParameters[i].leftIntrinsics;
    // 右目内参矩阵
    float *rightK = cameraParametersPacket.cameraParameters[i].rightIntrinsics;
    // 左相机到右相机的旋转矩阵（3x3，行优先）
    float *R = cameraParametersPacket.cameraParameters[i].rotationLeftInRight;
    // 左相机到右相机的平移向量（x y z，单位 m）
    float *T = cameraParametersPacket.cameraParameters[i].translationLeftInRight;
}
```

### 感知图像订阅

使用感知图像获取功能时，开发者需要调用指定的 API 通过 USB 或 Socket 接口在应用程序运行的周期内订阅（或退订）相机视觉传感器的图像，并使用回调函数在专用的读取线程内获取订阅的图像。

<div style="text-align: center"><p><span>
      <img src="https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/function-overview/perception-data/perception_image.svg" width="30%" alt="感知图像订阅流程"/></span></p>
</div>

**创建感知码流处理线程**

创建感知码流处理线程，用于读取感知传感器原始码流并解码成图像：

```c
T_DjiOsalHandler *osalHandler = DjiPlatform_GetOsalHandler();
osalHandler->TaskCreate("user_perception_task", DjiTest_StereoImagesDisplayTask,
                        USER_PERCEPTION_TASK_STACK_SIZE, &s_stereoImagePacket, &s_stereoImageThread);
```

:::tip 说明：
若安装了 OpenCV 库，可在处理线程中调用 `cv::imshow()` 显示解码后的感知灰度图像。
:::

**订阅指定方向的感知图像**

订阅指定方向的感知图像，并注册回调函数处理接收到的码流：

```c
// 以前视方向为例
returnCode = DjiPerception_SubscribePerceptionImage(DJI_PERCEPTION_RECTIFY_FRONT,
                                                    DjiTest_PerceptionImageCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Subscribe perception image failed, error code: 0x%08X", returnCode);
}
```

回调函数示例：

```c
static void DjiTest_PerceptionImageCallback(T_DjiPerceptionImageInfo imageInfo,
                                            uint8_t *imageRawBuffer, uint32_t bufferLen)
{
    // imageInfo.rawInfo.width  — 图像宽度（像素）
    // imageInfo.rawInfo.height — 图像高度（像素）
    // imageInfo.timeStamp      — 时间戳
    // imageRawBuffer           — 原始图像数据指针
    // bufferLen                — 数据长度（字节）

    // 将图像数据保存到文件或做进一步处理
}
```

**取消订阅感知图像**

```c
returnCode = DjiPerception_UnsubscribePerceptionImage(DJI_PERCEPTION_RECTIFY_FRONT);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Unsubscribe perception image failed, error code: 0x%08X", returnCode);
}
```

**销毁处理线程**

```c
osalHandler->TaskDestroy(s_stereoImageThread);
```

### 激光雷达点云订阅

使用激光雷达点云数据获取功能时，开发者需要调用指定的 API 通过 USB 或 Socket 接口在应用程序运行的周期内订阅（或退订）机载激光雷达数据，并使用回调函数接收。无人机起飞状态下可订阅到机身点云数据。

:::tip 说明：
* 参考感知相机数据订阅，为避免处理点云数据的工作阻塞主线程，请创建一个独立的线程处理无人机激光雷达点云数据。
:::

订阅机载激光雷达点云数据，并注册回调函数接收点云信息：

```c
returnCode = DjiPerception_SubscribeLidarData(DjiTest_PerceptionLidarCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Subscribe lidar data failed, error code: 0x%08X", returnCode);
}
```

回调函数中解析点云帧数据：

```c
static void DjiTest_PerceptionLidarCallback(uint8_t *lidarDataBuffer, uint32_t bufferLen)
{
    T_DjiLidarFrame *lidarFrame = (T_DjiLidarFrame *)lidarDataBuffer;
    // lidarFrame->timeStampNs  — 帧首点时间戳（ns）
    // lidarFrame->frameCnt     — 帧计数（从 0 递增）
    // lidarFrame->pkgNum       — 当前帧有效数据包数量
    // lidarFrame->naviPos      — 无人机 IMU 到导航坐标系的平移向量
    // lidarFrame->naviQuat     — 无人机 IMU 到导航坐标系的四元数

    for (int i = 0; i < lidarFrame->pkgNum; i++) {
        T_DjiPerceptionLidarDecodePkg *pkg = &lidarFrame->pkgs[i];
        for (int j = 0; j < pkg->header.dotNum; j++) {
            // pkg->points[j].x / y / z — 点坐标（单位：米）
            // pkg->points[j].intensity  — 反射强度
            // pkg->points[j].label      — 噪点过滤结果（0: 目标点; 1: 噪点）
        }
    }
}
```

取消订阅：

```c
returnCode = DjiPerception_UnsubscribeLidarData();
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Unsubscribe lidar data failed, error code: 0x%08X", returnCode);
}
```

### 毫米波雷达点云订阅

飞行器起飞后，PSDK 可以订阅到 20 Hz 频率的毫米波雷达点云信息。使用毫米波雷达点云数据获取功能时，开发者需要调用指定的 API 通过 USB 或 Socket 接口在应用程序运行的周期内订阅（或退订）指定位置的毫米波雷达数据，并使用回调函数接收。

:::tip 说明：
参考感知相机数据订阅，为避免处理点云数据的工作阻塞主线程，请创建一个独立的线程处理无人机毫米波雷达点云数据。
:::

订阅指定位置的毫米波雷达点云数据，并注册回调函数接收点云信息：

```c
// 以前向毫米波雷达为例
returnCode = DjiPerception_SubscribeRadarData(RADAR_POSITION_FRONT, DjiTest_PerceptionRadarCallback);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Subscribe radar data failed, error code: 0x%08X", returnCode);
}
```

回调函数中解析毫米波雷达数据帧：

```c
static void DjiTest_PerceptionRadarCallback(E_DjiPerceptionRadarPosition radarPosition,
                                            uint8_t *radarDataBuffer, uint32_t bufferLen)
{
    T_DjiRadarDataFrame *radarFrame = (T_DjiRadarDataFrame *)radarDataBuffer;
    // radarFrame->headInfo.dataLen — 数据长度
    // radarFrame->headInfo.packNum — 当圈总包数

    // 逐点解析（azimuth / elevation / radius 需按公式换算实际值）
    // azimuth（方位角，rad）= radarFrame->data[i].azimuth / 1000 - 2π（若结果 > π 则减 2π）
    // elevation（俯仰角，rad）= radarFrame->data[i].elevation / 1000 - 2π
    // radius（径向距离，m）= radarFrame->data[i].radius * 0.01
    // velocity（m/s）= (radarFrame->data[i].base_info.velocity - 32767) / 100
}
```

取消订阅：

```c
returnCode = DjiPerception_UnsubscribeRadarData(RADAR_POSITION_FRONT);
if (returnCode != DJI_ERROR_SYSTEM_MODULE_CODE_SUCCESS) {
    USER_LOG_ERROR("Unsubscribe radar data failed, error code: 0x%08X", returnCode);
}
```
